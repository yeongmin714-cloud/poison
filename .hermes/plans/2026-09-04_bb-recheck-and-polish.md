## 2. 확인된 미수리 항목 (새 코드 필요)

### BB1. 잔디 밀도 상향 (예시 8 수준)
- 현재: 일반 지면 0.5/㎡ → **1.2/㎡**, 꽃밭/숲 내부 2~3 → **4/㎡**
- cap 4,500/국가 → **8,000/국가** (총 32,000 — IdyllicGrassCuller 60m 컬링 전제)
- 배치 간격 10m → 6m

### BB2. 북쪽 더 하얗게
- north_snow 알베도 자체를 재생성: 채도 −80%→−95%, 밝기 +120%→**+160%** (순백에 가까운 눈)
- 북 tint (0.98,1.00,1.08) → **(1.02,1.02,1.12)**
- 북 L1(설원) 고도 가중치 상향: 설원이 능선/고지대를 완전히 덮도록

### BB3. RPG팩 애니 부착 검증 (코드 아님, 절차)
1. 에디터 포커스 → 재컴파일 (에러 0 확인 — CS1001/CS0029/CS1061 모두 수리됨)
2. Play → 콘솔에서 `[HumanoidClipDriver] anim=OK ... controller=Player_AC_AC mode=Player` 확인
3. 걷기/달리기가 RPG팩 모션인지 시각 확인 — 클립 6종 참조는 소스로 이미 입증
4. 만약 여전히 구 모션이면 MixamoControllerBuilder 재빌드(에디터 메뉴) 실행 — 3c9c39e6의 "기존 삭제 후 재생성" 수정이 이 경로를 담당

## 4. 왜 "수리했는데 안 됐나" — 교훈 기록

- CS1001 'base' 에러 1건이 **동일 어셈블리의 모든 신코드(AA1~AA5)를 무효화** → 에디터는 마지막 성공 컴파일 어셈블리로 Play
- 교훈: 대규모 변경 후 Play 판정 전 **콘솔 에러 0 확인이 최우선** (이미 메모리 규칙에 있으나 이번에 체감)
- 이후 세션 규칙: 컴파일 에러 발견 시 다른 작업 전에 무조건 먼저 수리
