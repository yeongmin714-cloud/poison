## 1. 완벽 분석 — 51~53에서 확정된 근본 원인

### 1.1 [확정] 잔디가 안 보이는 진짜 이유 — 밀도 수학 오류
- 로그: `GrassTusks=32000` — 배치 자체는 됐다. 그러나 **32000개를 2000×2000m 맵에 뿌리면 1개/125㎡** — 극도 희소. 눈에 안 보이는 게 정상.
- BB1의 구현이 목표(1.2/㎡)와 어긋남: spacing 6.5m 격자당 1개(비밀집) = 실제 0.024/㎡. 마스크 내부도 16개/42㎡ = 0.38/㎡ — 계획 대비 1/3.
- **구조적 결론**: 정적 3.2만 개 흩뿌리기로는 "잔디가 깔린" 느낌을 절대 못 만든다. 잔디는 **플레이어 주변 동적 커버**(GrassRenderer 방식)가 정답 — 시야 내 60m 반경에 2~3/㎡ = 활성 1.1만 개, 화면에 확실히 보인다.
- 팩 자산 확인: `Grass_01/02/03.prefab`(Vegetation 셰이더그래프 + 흰 마스크 + `_Custom_Color` 착색) — 재질은 정상. 보이지 않은 건 **밀도가 물리적으로 부족**했기 때문.

### 1.2 [확정] 호수 "사각 박스"의 정체 3판정 수정 — 물밑 지형 면패션
- 52 재판정: 박스들이 **반투명 수면 아래에 갈색으로 잠김, 격자 배열** — 이건 수면 텍스처가 아니라 **투명한 수면 아래로 비치는 분지 바닥(카브된 지형)의 면패션(faceting)**이다. 201×201 메시의 10m 쿼드가 물밑에서 각지게 보임.
- 노멀맵 문제(AA1)는 별개로 이미 수리 — 이번 박스는 "물밑 바닥이 보이는 것" 자체.
- **수리 방향**: ①수면 불투명도 상향(0.85)으로 바닥 은폐 ②BakeWorldSplat에서 호수 분지 내 픽셀을 깊이에 따라 어두운 물색으로 강제(수심 음영) — 바닥 면패션 시야 차단 + 깊이감 부여

### 1.3 [확정] 북쪽이 연두인 이유 — 설원이 "고지대만"
- 캐시는 최신(north_snow 반영)이지만, ComputeWeights가 북 L1(설)을 **고지대 전용**으로 배정 → 저지대(시야 대부분)가 L2 청록 잔디 → 연두로 보임
- 사용자 요구는 "북쪽 전체가 흰색 평지" — **설원 우세로 반전** 필요(잔디는 골짜기 포인트만)
- 추가: 캐시 무효화 문제 — 캐시 파일명은 시드만 포함 → 텍스처 교체해도 캐시가 오래된 색을 유지 가능 → **텍스처 내용 해시를 캐시 키에 추가** 필수

### 1.4 나무 방위색 통일 + 지형지물 공중부양
- 현재 나무는 국가별 수종만 다를 뿐 잎 색이 방위색과 무관(중앙 벚꽃 빨강/북 청록 침엽 등 혼재)
- 공중부양: y는 수학적으로 정확(발밑 0.04m) — 문제는 ①태양 그림자가 옆으로 치우침 ②BlobShadow가 플레이어만 적용 ③릴리프 가독성
- **수리**: 데코 전체에 BlobShadow 확장 + 나무/바위 지면 스냅은 유지

### 1.5 RPG팩 애니 — 로그로 입증된 상태
- `controller=Player_AC` + 팩 클립 6종 참조 소스 입증 — **부착은 되어 있음**
- 미확인인 것은 "Play에서 실제 재생 모션" — 컴파일 에러가 막았던 세션들이 있었음. 최근 세션은 에러 0 → **걷기/달리기 시각 확인이 남은 유일 단계** (코드 변경 불필요, 확인만)

## 2. 수리 계획 (Phase CC1~CC4, 총 2.5일)

### Phase CC1. 동적 잔디 커버 재설계 (1일, 핵심)

1. **정적 32,000개 흩뿌리기 → 플레이어 동적 커버로 전환**:
   - `IdyllicGrassCover.cs` 신규: 플레이어 주변 반경 45m 원형 영역에 Grass_01/02 풋을 **인스턴싱으로 채움(2.5/㎡ ≈ 6,300개 활성)**
   - 이동 시: 8m 이동마다 뒤쪽(45m 밖) 비활성/회수, 앞쪽 신규 생성 — 그리드 청크 방식(10m 셀 단위 캐시)으로 생성 비용 관리
   - 밀도 가중치: 꽃밭/숲 마스크 내부 ×3
   - 셰이더: 팩 Vegetation 그래프 유지(틴트 정상 렌더 확인된 경우) — 렌더 이상 시 Grass_01 마스크 텍스처 + 녹색 틴트 URP Lit 폴백
2. 기존 정적 32,000 잔디는 **cap 8,000으로 축소**(먼 곳 개활지 포인트 역할) + 컬링 유지
3. 검증: 54번 — 플레이어 발밑에 잔디가 빽빽히 보이는지

### Phase CC2. 호수 마무리 — 바닥 음영+수변 꾸미기 (0.5일)

1. **분지 바닥 음영**: BakeWorldSplat에서 호수 반경 내 픽셀 → 깊이에 따라 어두운 청록~남색으로 강제(수심 음영) — 투명 물 아래 갈색 면패션 박스 시야 차단 + 깊이감
2. **수면 불투명도 0.85** — 바닥이 덜 비치게
3. **수변 꾸미기(예시 3/6)**: ShoreReeds 631 → **1,200** (호수 14개 기준 수당 ~85), 바위 수변 클러스터 추가, 호수 인근 나무 밀도 ×1.5
4. **북쪽 호수 증가**: 호수 배치 규칙에 "북 방위각(45~135°) 영역 최소 3개 보장" 추가 — 현재 14개 중 북 배정 확인 후 부족 시 재배치 가중
5. 검증: 55번 — 박스 소멸 + 수변 풍경(예시 3/6 비교)

### Phase CC2b. 북쪽 전체 흰색 평지 (0.5일)

1. **ComputeWeights 북 분기 재설계**: 설원을 "고지대 전용"이 아니라 **기본 지배(전역 0.7 + 고도 가산)**, 청록 잔디는 저지대 포인트(0.3 이하)로 — 북 전체가 흰 평지 + 능선 밝게
2. **캐시 무효화 개선**: 캐시 파일명에 텍스처 내용 해시 추가(`WorldSplat_2048_seed{seed}_v{hash}.png`) — 텍스처 교체 시 자동 재베이크 (이번 사고 재발 방지)
3. 기존 캐시 파일 삭제 후 첫 Play에서 재베이크 (1회만)
4. 검증: 56번 — 북쪽 전체가 흰/연청 평지

### Phase CC3. 나무 방위색 + 접지감 (0.5일)

1. **나무 잎 색 국가별 틴트**: 팩 Vegetation 셰이더그래프의 `_Custom_Color` 지원 확인됨(LilyPad가 사용) — 나무 머티리얼을 런타임 인스턴스 복제 후 국가별 색 주입:
   - 동=라임 그린, 서=올리브/황록, 남=짙은 녹+붉은 포인트, 북=설빙 백청(눈 덮인 나무 느낌), 중앙=벚꽃 핑크 유지
   - `_Custom_Color` 지원 셰이더 확인 후 인스턴스별 `_Color` 세팅 (머티리얼 공유 → 국가별 1개 복제만 생성)
2. **BlobShadow 데코 확장**: 나무/바위에도 반투명 원형 그림자(나무 반경 1.2m/바위 0.9m) — 탑다운 접지감
3. 검증: 57번 — 나무 색이 방위와 어울리는지, 데코가 지면에 붙어 보이는지

### Phase CC4. RPG팩 애니 확인 + 마무리 (0.5일)

1. 애니는 로그로 이미 입증(`controller=Player_AC`, 팩 클립 6종) — Play에서 걷기/달리기/공격 시각 확인만 남음
2. 만약 구 모션이 보이면: MixamoControllerBuilder 재빌드(에디터 메뉴) 실행 — 3c9c39e6 수정이 이 경로 담당
3. QAPROGRESS + 메모리 + 커밋/푸시
