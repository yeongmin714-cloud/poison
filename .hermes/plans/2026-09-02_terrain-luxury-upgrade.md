# 지형 고급화 계획 — "단독 텍스처" → "멀티레어 스플래팅 + 질감 디테일"

> 작성일: 2026-09-02
> 목표: 메인씬 지형이 단일 PNG 타일이 아니라, 높이/경사/오차노이즈에 따라 자연스럽게 갈라지는 고급스러운 지형으로 보이게 만든다.
> 원칙: 셰이더 교체 최소화(URP Lit 유지), 절차적 생성 선호(에셋 이미지 최소), _BaseMap 소실 버그와 호환, Play 시각검증을 각 단계에서 수행.

---

## 1. 현재 상황 (진단)

- 지형 = 2000×2000m 단일 메시, `TerrainTextureApplier`가 책임.
- 각 국가(East/West/South/North/Empire/Dracula)당 **PNG 1장**을 `Resources/Models/UserProvided/terrain/textures/`에서 로드 → URP Lit `_BaseMap`에 tiling 200으로 평면 배치.
- `_DetailAlbedoMap`(extra) 블렌드는 단일 슬롯 한계로 일부 국가만 0.3 강도.
- 정점색상(vertex color)은 흙길(id 구분)에만 사용 중.
- 지형 높이는 FBM(동/서/남/북/엠파이어 다른 굴곡) + 호수 6개 + 스폰 평탄.

**단조로움의 근본 원인:**
1. **단일 텍스처 전면 반복** — 낮은 땅/높은 봉우리/경사/바위지대가 구분 없이 같은 타일.
2. **스플래팅 부재** — 높이·경사·노이즈에 따른 재질 혼합(예: 낮은 곳 펄 바닥, 경사진 곳 바위 노출) 없음.
3. **질감 디테일 부족** — 근거리에서 타일 반복이 그대로 보임.

---

## 2. 제안 접근 — 3단계 고급화

리스크를 피하려고 **셰이더 재작성 대신 "절차적 베이크 → URP Lit 재질"** 로 통일한다. 즉, 각 국가의 지형 요소(평지/경사/바위/모래/눈 등)를 **높이·경사·오차노이즈 가중치로 블렌드한 단일 스플랫 텍스처**를 코드로 생성해 `_BaseMap`에 넣고, `_DetailAlbedoMap`/`_DetailNormalMap`으로 원거리 질감을 보강한다.

### 단계 A — 지형 요소층(Layer) 데이터 (준비) — 기존 자산 100% 활용
> **2026-09-02 자산 실태 확인** (모두 1024×1024 JPEG):
> East=east_grass1~5(5장), North=north_snow1~5(5장), South=south_red1~7(7장),
> West=west_sand1,3,4,5,6(5장, 2번 없음), Empire=empire_marble(1장), 보조 extra2.png.
> **현재 코드는 각국 첫 장만 사용하고 나머지 20장+는 미활용 잉여.** ⇒ 신규 이미지 거의 불필요,
> 기존 사진 텍스처를 그대로 스플랫 레이어에 활용.
- `TerrainLayerDef`: 이름, 기존 JPEG 텍스처(들), 바이옴 매핑, 스플랫 파라미터(높이 기준/경사 기준/혼합폭/강도).
- 각 국가에 **기존 장들로** 3~4개 레이어 정의 (예: East = east_grass1(기반)/east_grass3(흙벌판)/east_grass5(바위노출)/◌느슨흙, North = north_snow1(눈덮임)/north_snow3(바위)/north_snow5(동토) …).
- 같은 국가 안 여러 장을 노이즈/무작위로 블렌드해 타일 반복 제거.
- ⚠️ west_sand2 없음: "장 번호 순서 매핑" 시 2번 생략 유의 (prefix 그룹화엔 무관).
- ⚠️ **Empire(1장) 반복감**: 여기만 절차 노이즈 + 타일링 오프셋으로 보강.
- **검증**: 단위 테스트 — 레이어 정의 정합성(모든 국가 3층 이상, 텍스처 존재).

### 단계 B — 절차적 스플랫 베이크 셰이더 로직(C#)
- 신규 `TerrainSplatBaker`:
  - 메시 정점마다 높이·노멀(경사)·오차노이즈 샘플 → 레이어 가중치 계산.
  - 각 정점의 UV 좌표에서 레이어 텍스처 색을 샘플 → **가중치 0~1로 혼합** → **스플랫 맵(단일 Texture2D)** 에 픽셀 기록.
  - 스플랫 맵 해상도 512~1024 (성능 고려), wrapMode Repeat, `_BaseMap`에 적용.
  - 기존 `TerrainTextureApplier.CreateMaterials()`의 단일 텍스처 배치를 이 베이크 결과로 대체.
- 하지만 2000×2000 전체를 1024 텍스처로 표현하면 채움 밀도가 낮아질 수 있음 → **지역 분할**: 중심~링별 2~3장으로 나누거나, 근거리 정밀 + 원거리 coarse 두 텍스처 운용. *(설계 단계에서 성능 측정으로 결정)*
- **검증**: EditMode — 특정 좌표의 스플랫 결과 색/가중치 결정성, 레이어 합 = 1.0, 경사 지점에서 바위층 가중치 상승.

### 단계 C — 질감 디테일 보강 (터치업)
- `_DetailAlbedoMap`/`_DetailNormalMap`에 절차 마이크로디테일(미세 크랙/입자) 로드 → 근거리 반복감 제거.
- 기존 `_BaseMap` tiling을 지형 스케일에 맞춰 조정(기본 200 유지).
- 물/호수 연안 펄(먼지) 밴드, 흙길 주변 흙 퍼짐은 스플랫 가중치에 반영.
- **검증**: Play에서 초록지대/경사바위/연안펄 구분이 눈에 보이는지.

### 단계 D — 분위기 통합 (고급스러움의 절반)
- 안개는 이미 `0.0006`로 정상. Global Volume에 **미세 볼류메트릭 먼지/피로** 또는 지형 주변 그라운드 헤이즈 톤을 살짝 재조정(과하지 않게).
- 라이트: Directional Light 각도/온도를 지형 질감에 맞춰 미세 튜닝(스플랫 대비가 살아나도록).
- ※ 실패 시 롤백 안전통로: 스플랫 베이크 실패하면 기존 단일 텍스처 경로로 자동 폴백(플래그).

## 4. 검증 / 테스트 대상

| 항목 | 방법 |
|:----|:-----|
| 스플랫 가중치 합 1.0 | EditMode 단위 테스트 |
| 결정성 (같은 시드 → 같은 맵) | EditMode 단위 테스트 |
| 경사 지점 바위층 증가 | 특정 좌표 가중치 단위 테스트 |
| _BaseMap 소실 없음 유지 | 기존 TerrainBaseMapFixer 가드 그대로, 스플랫도 재생성 |
| Play 시각 | 동/서/남/북/엠파이어 지형 + 경사면 + 연안 + 흙길 스크린샷, 콘솔 `[TerrainSplatBaker]` 로그 |

## 5. 리스크 / 트레이드오프

- **리스크 높음: _BaseMap 소실 재발** → 스플랫은 런타임 코드로 `_BaseMap`에 주입하므로 기존 Fixer가 `Terrain_Grass`로 덮어쓰는 충돌 가능. → 스플랫 활성 시 Fixer가 스킵하도록 가드 추가 (기존 매트 GUID 대신 코드 생성 재질 표시).
- **셰이더 미교체** → 성능/선명도 제한은 있으나 컴파일·시각 리스크 크게 감소. 1안.
- **스플랫 맵 해상도 vs 채움 밀도** → 지역 분할(근/원)로 절충.
- **부하는 정점당 계산** — 2000×2000 메시 정점 수에 따라 베이크 시간. FixMainScene 배치에서 처리하거나 초기화 시 1회로 제한.
