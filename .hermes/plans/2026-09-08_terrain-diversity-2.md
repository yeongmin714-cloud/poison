1. **지표 대부분이 "부드러운 풀돔" 하나로 구성** — 노출 암반(G1)이 없어 실루엣이 단일

3. **랜드마크 부재** — 눈에 박히는 대형 구조물(천연 아치, 대형 만, 꽃 융단 언덕)이 희소

## 3. 실행 Phase (코드 작성 = delegate_task code agent, QA = delegate_task QA agent)

### Phase T1 — 지형 형태: 노출 암반 + 분지 + 아치 (TerrainShape.cs / TerrainGenerator.cs)
- **T1-1 노출 암반(Outcrop) 시스템 [G1]**
  - `TerrainShape.GetOutcropMask(x, z, nation, seed)` 신규 — 결정론 해시로 방위당 4~6개 중심 배치 (반경 25~45m, 높이 8~18m 부드러운 암돔)
  - `ComputeSubBiomeVariation`에 델타 가산 (기존 패턴 유지, cliffSuppression 보호 구역 0)
  - 암돔 표면은 `terraceStep` 계단 처리 → 예시9의 "층 진 바위 단면" 재현
- **T1-2 천연 아치 [G2] 서쪽 1개**
  - 아치 자체는 메시(프리팹) 배치, 기저 지형은 아치 받침 2개 암돔(T1-1 재사용)
  - 위치: 서쪽 사막-협곡 경계 1곳, 흙길이 아치 밑을 통과하도록 경로 1세그먼트 연결
- **T1-3 대형 분지(Basin) [G7] 방위당 1개**
  - `ApplyLakeBasins` 패턴 재사용 — 반경 90~130m 완만한 분지 + 한쪽만 병풍 절벽(cliff 게이트 강제)
  - 스폰/성/호수 150m 배제, 흙길이 분지 바닥을 지나게 세그먼트 1개 추가
- **T1-4 호수 확장 [G4 보강]**
  - 대형 2개(반경 180/150)는 유지, 중형 3개를 100~120m로 승격 + 1개를 타원형 "만" 형태로 변형
  - 수변 밴드(1.0~1.45r)에 완만한 해안 사면(경사 ≤8°) 강화 — T2-2 모래 텍스처가 붙을 받침

### Phase T2 — 텍스처/색 레이어 (NationTerrainController.cs)
- **T2-1 스플랫 레이어 확장 [G1+G3]**
  - 텍스처 채널 4장 기준: ①풀(기존) ②바위/암반 ③모래(수변+사막) ④설원(북)
  - `ComputePixelColor` 확장: outcropMask>0.5 → 암반 텍스처+방위 틴트 유지, 수변 밴드 → 모래, 북=설원 우선
- **T2-2 수변 모래사장 [G3]** — 호수/만 수변 6~10m 밴드를 밝은 베이지 모래로 (예시3/10)
- **T2-3 암반 방위 틴트** — 동·북=회청+이끼 녹 얼룩 / 서·남=적갈 사암·현무암 / 황제국=밝은 석회암
- **T2-4 대형 꽃 융단 [G5]** — `GetFlowerPatchMask` 패치 반경 140m 유지하되 황제국+동에 **핑크/마젠타 대형 패치 4~6개(반경 180m)** 추가, 텍스처 얼룩+데코 밀도 ×2 (예시12/13)

### Phase T3 — 데코 배치 (IdyllicDecoPlacer.cs)
- **T3-1 수종 3종 규칙 배치 [G6]**
  - 능선/고지=침엽수(사이프러스형) / 수변 20m=수양버들 / 일반=둥근 활엽수 — 기존 SpatialHash 유지
- **T3-2 바위 위성 군집 [G1]**
  - 각 outcrop 중심 주위 rockBig 2~4 + rockMed 4~8 클러스터, 이끼 틴트(Vegetation _Custom_Color 규약 재사용)
- **T3-3 수면 데코 [G4]**
  - 연잎/연꽃 프리팹 군집(호수당 3~6군락, 수심 얕은 쪽) — IdyllicPrefabs에 없으면 기존 꽃 프리팹 대용 배치
- **T3-4 야생화 방위별 팔레트 [G8]** — 동=파랑+흰 / 서=노랑 / 남=빨강 / 북=흰 / 황제국=핑크+보라 (기존 6색 리스트에서 선택)
- **T3-5 능선길 데코 [G9]** — 흙길 세그먼트 중 "고도 상승" 구간(능선 타기)에 가드레일식 바위+관목 라인

### Phase T4 — 검증 (게이트: 배치컴파일 error CS=0 선행 필수)
1. 중괄호 균형 파이썬 검증 (변경 파일 전부)
2. 배치컴파일 (run_batch.bat) → error CS = 0 + DLL 타임스탬프 확인
3. QA agent delegate — 신규 마스크 함수의 보호구역(cliffSuppression=0) 무해성 + GetHeightAt 규약(y=1f+) 회귀 검증
4. 유저 Play → 확인 포인트: ①노출암반 실루엣 ②호수 모래사장+연꽃 ③서쪽 아치 ④황제국 꽃융단 ⑤능선 나무 ⑥스폰/성 주변 무결성
5. 판정 통과 시 ROADMAP/QAPROGRESS/메모리/git 3곳 저장

## 5. 리스크 / 규약 준수
- **GetHeightAt 단일 진실원 유지**: 모든 형태 변경은 ComputeNationHeight/SubBiomeVariation 델타로만 → 청크 64장 자동 반영, 재배치 불필요
- **cliffSuppression=0 보호구역**(스폰/성/호수/경계) 전 신규 마스크 곱하기 — 45° slopeLimit 유지
- **방위 tint 색 규약 변경 금지**(동=초록/서=노랑/남=빨강/북=흰/황제국=황금) — 텍스처 전환만
- **밀도 과다 금지**(유저: "no over-density") — 나무/바위 캡 기존 유지, 위치 선정만 개선
- 결정론 시드(FbmNoise 고정) — 재부팅 시 동일 배치, AutoCommit 데몬과 커밋 경합 주의(index.lock)
- delegate_task 600s 타임아웃 잦음 → 타임아웃 시 파일 상태 확인 후 직접 처리 전환
