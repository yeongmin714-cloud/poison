## 1. 완벽 분석 — 3개 문제 확정

### 1.1 [확정 버그] 호수가 수직으로 서 있는 원인 — Plane 프리미티브 회전 실수

**LakeGenerator.cs 323행**:
```csharp
_waterSurface.transform.localRotation = Quaternion.Euler(-90f, 0f, 0f);
```
- `_waterSurface = GameObject.CreatePrimitive(PrimitiveType.Plane)` — Unity의 **Plane 프리미티브는 이미 수평**(법선 +Y, XZ 평면에 눕혀 있음)
- 여기에 X축 −90° 회전을 더하면 **법선이 수평 방향으로 서서 "벽"이 됨** — 48에서 판이 수직으로 서 있고 지면에 90°로 교차하는 이유
- `Euler(-90,0,0)` 패턴은 **기본 수직인 Quad**용 회전이다. Plane에는 **회전 불필요(항등식)** — 단순 실수
- **수리: 323행 삭제(또는 identity)** — 수면이 즉시 수평으로 눕는다

### 1.2 북쪽이 설산이 아닌 이유 — 매핑된 텍스처가 설원이 아님

- 북 L1 = `north_grass_albedo` (X1에서 청록 시프트한 잔디), L2 = `north_forest`(숲), L3 = `north_cliff`
- Idyllic 팩에 **눈/설원 텍스처가 아예 없음**(Ground 폴더 = Grass/Forest/Rock/Dirt/Sand/Cobblestone 6종)
- 로드맵 북 컨셉은 "연청/설원" — 현재는 청록 잔디일 뿐 **설산 느낌이 없음**
- 47에서 북쪽이 주황/황토로 보인 것은 남-북 경계 그라데이션과 남쪽 적갈 틴트가 겹쳐 보인 것 + 고도가 낮아 굴곡이 안 읽히는 것

**수리 방향**: 북쪽 전용 설원 알베도를 **결정론 생성**(Grass_Albedo를 밝게 탈채도 → 눈빛 흰-연청) + 고지대(북 L3 절벽)에 밝은 설빙 틴트 → "설산" 실현

### 1.3 [지각 문제] 공중부양처럼 보임 + 평지처럼 보임

**49 실측**: 플레이어 발 y 0.6 vs 지면 0.56 — 간격 0.04m로 실제로는 착지 상태. 그림자가 태양 각도로 좌측에 길게 치우쳐 "떠 보임". 데코(나무/바위)도 y = 1+GetHeightAt로 정확히 지표 배치 — 그림자 방향 착시.

그러나 착시가 반복 지적된 이유(실제 개선 포인트):
1. **릴리프 대비 부족**: 파장 200m/진폭 7~13m의 완만한 파형이 탑다운에서 "색 띠"로만 읽힘 (47 그리드 패턴 = FBM 웨이브 밴드)
2. **그림자 부재감**: URP 그림자 120m로 올렸으나 씬뷰 원거리에선 안 보이고, 게임뷰에서도 얕은 굴곡엔 그림자가 미미
3. **데코 스냅 단일화**: 나무/바위가 경사면에서 y만 맞추면 기울기 무시 → 경사에서 벌어짐(미세)

### 1.4 단조로움 — 현재 배치 구성의 한계
- 나무 1/900㎡ 균일 분포, 꽃밭 마스크 8%, 숲 군락 없음, 흙길은 정점색만
- 예시 8: 잔디+꽃 다색, 나무 수종 다양(버드나무/침엽/활엽/벚꽃), 숲 군락, 흙길, 바위 군락의 "조합 다양성"

## 2. 수리 계획 (Phase Z1~Z4, 총 3일)

### Phase Z1. 호수 수평 복구 + 수면 정합 (0.5일, 즉시 효과)

1. **LakeGenerator 323행 삭제**: `localRotation = Euler(-90,0,0)` → `localRotation = Quaternion.identity` (Plane은 원래 수평)
2. 스케일 확인: Plane 10m × scale(r·2/10) = 지름 2r 유지
3. Enforce/Update 파동 애니는 localPosition만 조작 — 회전 불변 확인
4. 검증: 48 재현에서 수면이 수평 원판 + 분지 안에 박혀 보이는지

### Phase Z2. 북쪽 설산화 + 국가 팔레트 강화 (1일)

1. **설원 알베도 생성(결정론)**: `north_snow_albedo.png` 신규 — Grass_Albedo 기반 탈채도(채도 −80%, 밝기 +120%)로 눈빛 흰-연청
2. **TerrainLayerDef 북 매핑 교체**:
   - L1 = north_snow(설원), L2 = north_grass(청록 잔디, 해발 중간), L3 = north_cliff(설빙 바위 — 밝은 틴트), L4 = empire_dirtstone, L5 = north_moss
   - 고도 가중치 조정: 북은 L1(설)이 고지대 우세, L2(청록)가 저지대 — "설산" 실루엣
3. **고도 가중치 반영 확인**: ComputeWeights의 고도 3분위가 방위별로 북=높음을 타는지(R2 파라미터와 정합)
4. 남/서 tint 유지(적갈/황갈 정상 확인됨)

### Phase Z3. 릴리프 + 공중부양 착시 완화 (1일)

1. **릴리프 대비 강화(선택적 증폭)**:
   - 동/서/남 진폭 7~9 → 10~12 (+절벽 낙차 유지), 북 13 유지
   - FBM 파장 200 → 160m(주파수 ↑)로 언덕 밀도 증가 — 위에서 볼 때 "구릉"으로 읽히게
   - 단, 이동/착지 가드(스폰 30m/호수·성 40m 절벽 금지) 재확인
2. **정점 컬러 AO 강화**: 골짜기 하위 25% ×0.92 → **하위 30% ×0.85** + 능선(상위 10%) ×1.06 밝게 — 파형 대비 강조
3. **데코 지면 스냅 개선**: 경사면에서 나무/바위 y를 지표 + 기울기 보정(법선 기반 ±0.1)로 스냅 — 경사 부유 제거
4. **블롭 섀도우(선택 토글)**: 플레이어/데코 하단 원형 반투명 그림자 쿼드(런타임 생성) — 탑다운에서 접지감 확보(URP 그림자 보조)
5. 검증: 50번(게임뷰) — 공중부양 착시 완화, 51번(월드) — 구릉 파형 가독

### Phase Z4. 지형 다양성 — 숲/꽃밭/흙길/호수 증가 (1.5일, 방위 컨셉)

1. **숲 군락(Forest Patches) 추가**: 국가별 3~5개 군락(반경 100~180m, 결정론 시드) — 군락 내 나무 밀도 ×4(1/225㎡), 군락 밖은 기존 밀도. 숲 종류: 동=활엽수 혼합림, 서=떡갈나무림, 남=활엽수+관목, 북=침엽수밀림, 중앙=벚꽃 정원수
2. **꽃밭 확장**: 마스크 커버리지 8% → 14% + 패치당 단일 색 군락(빨강/파랑/흰/분홍 중 하나 — 예시의 단색 꽃밭) 
3. **흙길 확장**: 기존 4개 직선 → 중앙(Empire)에서 4방위 성으로 이어지는 곡선 도로망(경로 결정론) + 도로폭 8m(스플랫 L4와 동기화)
4. **호수 증가**: 6개 → **10개** (방위당 2개+중앙 제외, LCG 시드 교체 — 최소거리 250m/성·스폰 반경 150m 배제 규칙 유지) — Z1 수평 수리 후 적용
5. 바위 군락: 절벽 하단 자동 클러스터(이미 있음) + 개활지 대형 바위 단독 추가
6. 검증: 52번(월드) — 숲/꽃밭/도로/호수 10개 분포 확인 + 밀도 수치 로그
