# 이동 링 크기 + 링 품질/입체감(Fluent) + RTS 게임느낌 확장 계획 (2026-10-11, 15차 예정)

> **게이트: 계획 전용** — 사용자 "일단 계획만 세워" → 소스/테스트 수정 없음. 승인 후 Phase별 실행.

## 0. 사용자 요구

1. 이동 표시 링 = 조금만 더 크게 (현행 0.475 — 13차 절반 축소의 과소 보정)
2. 링 품질을 더 좋게 하는 방안 계획 + 더 플루언트하게 다듬기 + **입체감**
3. 추가로 RTS 게임느낌을 내는 개발 항목 추천 (조작/그래픽)

## 1. 현재 기반 (실측)

- 이동 지속 마커: `MoveMarkerScale = 0.475`(BaseScale 0.95×0.5), 타원 ~0.87×0.26m — 사용자 체감 "조금 작다"
- 셰이더(`Custom/SelectionRing`): 액센트 밴드(R±T 0.78±0.14) + 다크 백킹(내측 0.24/외측 0.05 @0.5) + 글로우 0.04 + 펄스 0.04 — 14차 상태
- **품질 한계(소스 확정)**: 에지가 고정 폭 smoothstep(0.02 단위)라 **카메라 거리에 따라 계단/흐림 변동** — 해상도 무관 AA(fwidth) 미적용. 밴드가 평면 단색 — 입체 요소 0
- 카메라: 휠 줌(15~40m)/우클릭 팬 이미 존재(TopDownCameraController/CameraZoomControllerRuntime)
- 이미 Fluent인 것: 드래그 선택 박스(RTSSelectionOverlayUTK GitHub 팔레트 ✅), HUD/UTK 창(UTKTheme ✅)

## 2. Part 1 — 이동 링 크기 (1줄)

- `MoveMarkerScale = 0.475 → 0.62`(BaseScale의 65%) — 타원 ~1.13×0.34m. 과하면 0.57/과소면 0.68로 1줄 튜닝.

## 3. Part 2 — 링 품질/입체감 (Fluent 다듬기)

### Q1. 해상도 무관 에지 AA (품질 핵심)
- smoothstep 고정 폭 → **fwidth(d) 기반 에지 폭**으로 전환: 화면 픽셀 파생 폭이라 근거리/원거리 모두 크리스프(계단/흐림 동시 제거). 액센트 밴드·백킹·글로우 전 에지 적용.

### Q2. 다중 밴드 입체 구조 (Fluent chrome — 바깥→안쪽)
1. **접지 드롭섀도 밴드(신설)** — 링 바깥 넓은 소프트 어두운 확산(알파 ~0.28): 링이 바닥에 "앉은" 느낌(부유 제거 — H2 블롭섀도우 세계관과 동일 언어)
2. **다크 백킹**(현행 유지 — 패널 톤)
3. **액센트 스트로크**(현행 유지)
4. **rim 하이라이트(신설)** — 액센트 밴드 상단에 화면-상 방향 얇은 밝은 선(백색 @~0.35): 금속 베벨 느낌 → **입체감**. (Theme.uss의 세로 그라데이션+금속 베벴 U9 입체 테마와 동일 세계관)
5. **내측 소프트 글로우**(현행 — 방향 유지)

### Q3. 명령 ack 확산 펄스 (신설)
- 명령 스폰 순간 1회: 스케일 1.0→1.25 확산 + 알파 페이드(0.4s, 1회) — 은은한 상시 펄스(현행)와 별개. "명령이 먹혔다"는 즉시 피드백.

### 구현 대상
- `SelectionRing.shader` — fwidth AA + rim + drop 밴드(속성 3종 추가, 기본값 보호)
- `CommandRingPresentation` — 신규 상수(DropAlpha/RimIntensity/AckBurst) + CreateMaterial 배선
- `CommandMarker`/`SelectionRingController` — ack burst(스폰 시 1회 코루틴/Update 누적)
- 테스트: 상수/속성 계약 갱신(RTSRingVisualTests) + 기존 회귀

## 4. Part 3 — RTS 게임느낌 확장 추천 (사용자 선택 대기 — 승인 시 별도 Phase)

### A. 조작 계열
| # | 항목 | 내용 | 효과/공수 |
|---|------|------|-----------|
| A1 | **명령 확인음(ack)** | 이동/공격 우클릭 시 짧은 확인음 — 절차 클립 폴백 패턴(AttackSoundLayerManager 선례) | RTS 필수 체감 / 小 |
| A2 | **핫키 명령군** | S=정지 / H=홀드 / A=공격이동 — ⚠️ [질문 반영] S/A는 WASD(플레이어 이동)와 겹침. 바인딩 3옵션: ①**Tab 부대 모드 한정**(권장 — IsSquadMode 중에만 지휘 소비+플레이어 이동 무시) ②Ctrl+S/H/A 조합 ③자유 키(Z/T/Y) 대체. H는 실측 소비처 0건(자유). 정지=즉시 취소+유휴 / 홀드=제자리 고정+자동 반격(상태 추가 필요, 공수 큼) | 지휘 완성도 / 中 |
| A3 | **컨텍스트 커서** | 지형=이동 커서, 적=공격 커서(Cursor.SetCursor or UTK 오버레이) | 의도 전달 / 小 |
| A4 | **미니맵 유닛 블립 + 클릭 명령** | 현재 MinimapUI(Legacy)에 아군 파랑/적 빨강 블립, 미니맵 우클릭=명령 or 카메라 점프 | RTS 핵심 / 中 |
| A5 | **선택 배지 고도화** | "1 unit selected" 텍스트 → Fluent 배지(부대 아이콘+인원수) | 小 |

### B. 그래픽 계열
| # | 항목 | 내용 | 효과/공수 |

| B1 | **선택 유닛 실루엣 하이라이트** | 선택 병사 얇은 아웃라인/리므라이트 — 원거리에서 유닛 식별성(링 보완) | 大 |
