# 실내 품질 계획 v2 — 탑다운 친화 (Indoor Quality Plan — Top-Down Friendly)

- **작성:** 2026-10-10 20:4X
- **상태:** 계획만 — 실행은 사용자 승인("진행") 시
- **전제:** 탑다운 뷰 게임. 천장 요소는 카메라-바닥 사이를 막으므로 **금지**(실내씬 7 확인 — 들보 제거 확정,
  IndoorQualityUpgradeTests에 재추가 금지 계약). "예시 이미지 무드"는 조명/질감으로 달성, 천장으로 달성하지 않는다.

## 목표

바닥·벽·소품 위주로 탑다운에서 실제로 읽히는 품질을 올린다. F1~F4(텍스처/조명/포스트)는 유지.

## Phase G1 — 바닥 존 그래픽 (체감 최대)

1. **방별 바닥 오버레이**: 방 크기 오버레이 쿼드(바닥 위 1cm, 렌더러 전용)에 방별 질감
   - 로비 = 석판 모자이크 러그 패턴 / 부엌·연금 = 타일 / 배럭 = 짚 커버 / 무기고 = 금속판 / 침실 = 카펫
   - 파일: `PlayerCastleInteriorBuilder` (GetTopologyZoneAt 기반 존 매핑) + `IndoorMaterialFactory`
   - 텍스처는 절차 생성 1종 + 제공 PNG 규약 확장(`floor_zone_<zone>.png` — 투입 시 자동 교체)
2. **걸레받이 목재 틀** (천장 대체): 벽 둘레를 따라 바닥에서 0.35m 높이의 얇은 목재 밴드
   - 탑다운에서 벽 안쪽 라인 장식으로 읽힘(방 중앙을 막지 않음), 하프팀버 무드 유지
   - D3 팀버 프레임과 동일 병합 메시 패턴 — 문 개구부 분할 회피
3. **벽 걸침 AO 데칼**: 벽 둘레 어두운 그라데이션(0.5m 폭) — 실내 깊이감(탑다운에서 벽 그림자 느낌)
- **게이트**: 컴파일 0 + IndoorQualityUpgrade focused + 캡처 승인

## Phase G2 — 벽 톱면(상단) 마감

- 탑다운에서 벽은 "두꺼운 선" — 현재 top face가 회반죽 노출
- 벽 위 **돌 캡 쿼드**(벽 두께 0.45×벽 길이, wall_stone_lower 질감) 렌더러 전용 — 벽 마감
- Exterior/Lobby/Interior 벽 전부(토폴로지 22벽), 문 개구부 스팬 분할(밴드 빌더 재용)
- **게이트**: 동일 + 캡처

## Phase G3 — 소품 밀도 (GLB 규약 확장)

- `Assets/새로운 glb/props/` 풀 규약: 항아리/화분/통/상자더미 — `IndoorFurnitureCatalog` 패턴 확장
  (예: `CreateProp("barrel", 0.6f)` — GLB 우선+절차 폴백, 로드 실패 시 절차 실린더)
- 배치: 로비 코너/복도 굽이/무기고 빈칸 — 8~12개, 기존 가구와 무충돌 좌표(배치 테이블 기반)
- 침대 GLB(`침대.glb`) 투입 시 20개 배럭침대 자동 교체(이미 배선됨 — 재안내)
- **게이트**: 동일

## Phase G4 — 그림자/조명 튜닝 (디더링 개선)

- 실내씬 7에서 지적된 그림자 점무늬(디더링) — 원인 후보: 포인트라이트 soft shadow 필터링 + 해상도
  1. URP 에셋 섀도우 세팅 점검(추가 라이트 섀도우 해상도/거리) — 저사양 기본값 보수 조정
  2. 원거리 소형 라이트(범위 ≤5)는 그림자 OFF 후보(성능+노이즈 감소) — 시각 A/B 캡처
  3. SSAO 파라미터 미세 조정(강도/반경) — 실내 접지감
- **게이트**: 캡처 전후 비교 승인(수치 고정 계약보다 시각 승인 중심)

## 우선순위 제안

G1(바닥 존) → G2(벽 톱면) → G3(소품) → G4(그림자 튜닝)
- 근거: 탑다운에서 화면 대부분은 바닥 — G1이 체감 최대. G2/G3는 공간 프레임과 밀도.

## 리스크/유의

- 모든 신규 요소 **렌더러 전용(무콜라이더)** 유지 — 이동 차단 금지 계약(CollisionAndKitchen 게이트).
- 오버레이 쿼드 z-fighting: 바닥 위 1~1.5cm + depth 오프셋 확인(짚 데칼 1.5cm 선례).
- 천장/공중 구조물 재추가 금지 — 테스트 계약으로 고정.
- 텍스처 투입 규약 유지: `Assets/Resources/Indoor/파일명불변`.
