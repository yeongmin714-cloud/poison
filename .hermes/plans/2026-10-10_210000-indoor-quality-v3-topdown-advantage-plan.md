# 실내 품질 계획 v3 — 탑다운 뷰의 장점을 살리는 방향 (Top-Down First Quality)

- **작성:** 2026-10-10 21:0X
- **상태:** 계획만 — 실행은 사용자 승인("진행") 시
- **교훈 반영(오늘 실험 3건):** 존 매트(색 바닥)✗ / 걸레받이(벽 없이 떠 있는 선)✗ / 천장 들보(시야 가로막음)✗.
  → **탑다운에서 "읽히는 것"만 한다.** 색 바닥 교체·공중 구조물·벽 없는 장식은 금지 원칙.

## 왜 이 방향인가 — 탑다운 뷰의 장점

탑다운에서 실제로 플레이어에게 보이는 것은 ①바닥 ②벽의 **톱면(윗면)** ③바닥 위 오브젝트의 **윗면** ④**빛과 그림자의 평면 구성**. 벽의 옆면/천장은 거의 안 보인다(면 컬링+시야). 품질 = 이 4개의 완성도.

## Phase H1 — 벽 톱면 캡 (벽을 "읽게" 만들기 — 최우선)

- **문제:** 벽이 위에서 보면 0.45m 폭의 얇은 회반죽 선 — 공간 구조(방 구분)가 거의 안 읽힌다.
  걸레받이가 이상하게 보였던 근본 원인도 여기(벽이 안 보이니 선만 떠 보임).
- **방법:** 모든 축정렬 벽 위에 **돌 캡(coping stone) 쿼드** — 벽 두께(0.45m)×벽 길이, wall_stone_lower 질감,
  회반죽보다 어두운 마감. 벽이 "짙은 돌 선"으로 읽혀 방 구조가 즉시 파악됨.
- 로비 8각 사선 벽도 포함(회전 쿼드 — 벽별 병합 메시, D3 패턴 재용).
- 문 개구부는 분할(문틀 목재가 캡을 대신).
- **파일:** `PlayerCastleInteriorBuilder`(AddWallTopCaps — 걸레받이 빌더 구조 재용, y=RoomHeight) + 팩토리(석재 캡 머티리얼 — 이미 존재하는 CreateWallStoneLower 재용).
- **게이트:** 컴파일 0 + focused + 캡처 승인. 예상 효과: 방 구조가 미니맵처럼 읽힘.

## Phase H2 — 접지 그림자(Ground Contact Shadow)

- **문제:** 오브제(가구/캐릭터/소품)가 바닥에 "붙어 있는" 느낌이 약함 — 실시간 그림자는 디더링(실내씬 7/8 지적).
- **방법:** 가구/소품 루트에 **블롭 섀도우 쿼드**(바닥 위 1cm, 절차 방사 페이드 텍스처 — HUD radial 재용) —
  실시간 그림자 의존 없이 접지감. Bed/Shelf/Crate/테이블 계열 자동 부착(카탈로그 Spawn 후처리).
- 캐릭터는 이미 실시간 그림자 — 블롭은 소품만(비용 0).
- **파일:** `IndoorFurnitureCatalog`(부착) + 절차 텍스처 팩토리.
- **게이트:** 동일. 예상 효과: 오브제가 바닥에 "앉은" 느낌 — 탑다운 입체감의 핵심.

## Phase H3 — 조명 온도로 방 무드 구분 (색 바닥 없이 방 구분)

- **문제:** 방 구분을 색 바닥(실패) 대신 **조명 색온도 차이**로.
- **방법:** 부엌/연금 = 청백 계열(작업등 기존 웜 → 미세 쿨 틴트), 배럭 = 딥 웜, 침실 = 캔들 웜, 로비 = 중립 웜.
  강도는 현재 암전치(0.09~0.14) 유지 — 색만 ±0.05 틴트 시프트(과하지 않게).
- **파일:** `PlayerCastleInteriorBuilder` 라이트 색 상수만. 계약(상한 0.15) 유지.
- **게이트:** 캡처 승인. 예상 효과: 방으로 걸어 들어가면 무드가 바뀌는 감각.

## Phase H4 — 그림자 디더링 튜닝

- **문제:** 실내씬 7/8에서 그림자 점무늬(디더링) 반복 지적.
- **방법(순서대로 캡처 A/B):**
  1. 원거리 소형 라이트(range ≤5, 실내 보조) 섀도우 OFF — 노이즈 원인 제거 + 비용 절감
  2. URP 추가 라이트 섀도우 해상도 점검(URPAsset additionalLightsShadowResolution)
  3. 그래도 남으면 main light soft shadow 품질 상향(성능 확인 후)
- **게이트:** 캡처 A/B 승인.

## Phase H5 — 바닥 미세 디테일 (선택 — 색 변화 없음)

- 원본 바닥 텍스처 위 **마모/균열/이끼 스탬프 데칼** — 8~12곳, 알파 낮게(0.15~0.25), 색은 바닥과 동일 톤.
  존 매트와 달리 "더러움"만 더함(색 구분 없음) — 자연스러움 유지.
- **게이트:** 캡처 승인. **실패 시 즉시 제거**(오늘의 교훈 반영 — 1단계 소량 먼저).

## 우선순위 제안

H1(벽 톱면 캡 — 방 구조가 읽히는 가장 큰 개선) → H2(접지 그림자) → H3(조명 온도) → H4(그림자 튜닝) → H5(바닥 마모, 소량만)

## 금지 원칙 (오늘 실험에서 확정)

- 천장/공중 구조물 금지(들보 ✗)
- 벽 없는 곳의 장식 라인 금지(걸레받이 ✗)
- 바닥 색 교체/오버레이 금지(존 매트 ✗) — H5 마모 스탬프만 예외(색 변화 없음)
- 모든 신규 요소 렌더러 전용(무콜라이더) 유지
