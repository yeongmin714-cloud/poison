# BotW 스타일 HUD 리디자인 계획

## 목표
예시.jpg(젤다의 전설: Breath of the Wild) 스타일로 게임 HUD 재구성

## 현재 상태
- HUD.cs: IMGUI 기반, 좌하단 HP바(700x70), 초록→노랑→빨강 그라데이션
- MinimapUI.cs: IMGUI 기반, 우상단 원형 미니맵 400x400
- MainScene.unity: HUD GameObject + MinimapUI GameObject 이미 존재

## 변경 사항

### 1. 하트 기반 HP 시스템 (BotW 스타일)
- **위치**: 좌상단 (기존 HP바는 좌하단)
- **디자인**: 빨간색 하트 3열 (기본 최대 체력 = 15하트 = 5열×3줄)
- **기능**: 
  - 하트 1개 = 20HP (일반 최대 HP 100 = 5하트, 더 늘어나면 추가)
  - 데미지 받으면 하트가 반개→없음으로 줄어듦
  - 임시 하트(노란색) = 버프/음식으로 얻은 추가 체력
  - 데미지 받을 때 하트가 흔들리는 효과 (애니메이션)
- **구현 방식**: IMGUI 유지 (기존 HUD.cs 프레임워크와 호환)

### 2. 미니맵 위치 변경
- **현재**: 우상단
- **변경**: **우하단** (BotW 스타일, 단 MinimapUI.cs는 UIWindow 상속, 위치만 조정)

### 3. 기존 UI 요소 정리
- HP바 제거 → 하트로 대체
- 티어 범례(초급/중급/고급) 제거 (디버그용)
- 버프 아이콘은 우상단으로 이동 (현재 HP바 우측)
- 은신 HUD는 그대로 유지 (좌상단 하트 아래)
- 가스 분사기 타이머는 상단 중앙 유지

### 4. 디버그 텍스트 제거
- MonsterDebugUI(몬스터 목록)는 TEST 전용, MainScene에서 제거
- 필요시 Debug 모드 토글 기능 추가
