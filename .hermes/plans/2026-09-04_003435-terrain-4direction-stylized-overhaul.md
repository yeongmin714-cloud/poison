## 1. 목표 (Goal)

스크린샷 폴더의 `예시.PNG ~ 예시 13.PNG` (총 13장, vision 분석 완료)가 보여주는
**"밝고 화사한 스타일라이즈드 구릉 지형"**을 현재 탑다운 맵에 이식한다.

- 시점은 사용자의 탑다운뷰를 유지 (예시와 시점이 달라도 **지형 스타일만** 이식)
- 로드맵 Phase 3/14의 4방위+황제국 컨셉은 유지하되, 지형 "형태 언어"는 통일하고
  **색 팔레트와 분위기만 국가별로 변주**
- 기존 GLB 프롭(나무/바위 대량 배치)은 제거하고 **Idyllic Fantasy Nature 프리팹으로 통일**
- 지형 **고도 자체를 재설계** (완만한 구릉 + 이끼 낀 절벽 + 계곡 + 수면)
- 결정론적(시드 고정)으로 재현 가능해야 함 (검증 가능성 확보)

### 디자인 원칙 (사용자 취향 반영 — 메모리 기록)
1. **리얼리즘 기반 스타일라이즈드**: 완만한 굴곡은 실제 지형처럼, 질감은 화사하게
2. **과밀 금지**: 나무 중간 밀도, 풀/꽃 고밀도 — 나무를 빽빽히 채우지 않는다
3. **수치 검증**: "밝아 보인다"가 아니라 클리핑 비율/고도 분포/밀도/m²로 검증
4. **결정론**: 같은 시드 → 같은 지형. 랜덤은 "시드가 결정하는 랜덤"

### Phase T-R2. 방위별 고도 재설계 — 지형 "형태"의 핵심 (2~3일, 가장 중요)

**목표**: 예시의 형태(F1 구릉 + F2 절벽 + F3 계곡)를 결정론 FBM으로 구현하고, 방위별로 난이도 컨셉(로드맵: 동 완만 → 북 험준)을 고도로 표현한다.

#### 5.1 수학 설계 (신규 헬퍼: `TerrainShape.cs` 신규 파일 권장)

```
H(x,z) = Base(x,z) + Cliff(x,z) + Warp
Base  : FBM (4옥타브 유지, lacunarity 2.0, gain 0.55)
        - 주파수 f0 = 국가별 (동 0.004 / 서 0.005 / 남 0.004 / 북 0.006 / 중앙 0.003)
          → 파장 200~250m의 완만한 큰 언덕 (F1, freq ≤ 0.02 제약 준수)
        - 진폭 A = 국가별 (동 7m / 서 9m / 남 8m / 북 13m / 중앙 3m)
Cliff : Ridged FBM (1-|FBM*2-1|) 의 smoothstep 게이팅
        - ridge 마스크 m = smoothstep(0.62, 0.78, ridgedNoise) → 상위 ~15%만 절벽화 (F2)
        - 낙차 C = 국가별 (동 4m / 서 6m / 남 5m / 북 9m / 중앙 2m) × m
        - 계단식 절벽(예시 9,10의 층진 cliff)은 terrace: h = floor(h/step)*step + smooth 경계,
          step = 2.5m, terrace는 m>0.5인 영역에만 적용
Warp  : 도메인 워핑 x' = x + 40*FBM(x*0.008+13.7, z*0.008+7.1)
        → 직선처럼 보이는 능선을 자연스럽게 휘게 함 (예시의 유기적 능선)
계곡  : Base에 음의 고지 골짜기 바이어스 — valley = -A*0.35*smoothstep(0.7,0.9,valleyNoise)
```

**제약 검산**: 최고 진폭(북) = A13 + C9 = 22m < bounds 여유. 절벽 경사는 메시 해상도 의존 → 5.2의 해상도 상향과 짝을 이룸.

#### 5.2 메시 해상도 상향 (절벽 표현력)

- `TerrainHeightApplier`의 정점간격 20m → **10m** (2000m 맵 → 201×201 ≈ 4만 정점, 안전권)
- 메모리 규칙 "FBM 주파수=파장 1/freq, 정점간격 20m라 freq≤0.02" → 10m 간격에서는 **freq ≤ 0.04** 허용.
  위 설계(f0 ≤ 0.006, warp 0.008)는 제약 내.
- 해상도 2배는 정점 4배 — 프레임타임 회귀 측정 필수(R7 예산 참조)

#### 5.3 방위 블렌딩 구조 (호환성 핵심)

```
TerrainGenerator 내부 확장:
  GetHeightAt(x, z, biome, seed)            // 시그니처 유지 (기존 호출부 전부 무변화)
    → nation = NationTerrainController.GetNationFromPosition(x,z)
    → defA, defB = 인접 국가 BiomeDefinition 2개 (국가별 파라미터 테이블 — 5.4)
    → w = 경계 거리 기반 블렌드 가중치 (TerrainTransitionManager의 전환폭 규격 재사용)
    → H = Lerp(H(A, x', z'), H(B, x', z'), w)   // 파라미터 보간이 아니라 "두 결과의 보간"
       (파라미터 보간은 위상 뒤틀림 발생 — 결과 보간이 안전. EditMode 테스트로 증명)
```

- 기존 `GetHeightAt(x,z,Plains,42)` 호출부(PlayerMovement 등)는 **코드 수정 없이** 자동으로
  방위별 지형을 따르게 됨 (biome 인자는 레거시 호환용으로 무시됨을 주석 명시)
- `ComputeTerrainHeight`(스폰지 평탄화)와 성 터(TerritoryBuilder) 평탄화는 **마지막에 적용**되는
  오버라이드로 유지 — R2에서도 스폰 반경 30m 평탄 보장 (기존 규칙 계승)

#### 5.4 국가별 파라미터 테이블 (BiomeData에 신규 5종 추가)

| 국가 | A(진폭) | f0(주파수) | C(절벽낙차) | ridgeGate | terrace | 분위기 |
|------|---------|------------|-------------|-----------|---------|--------|
| East | 7m | 0.004 | 4m | 0.65 | off | 완만·밝음 (시작지) |
| West | 9m | 0.005 | 6m | 0.62 | 2.5m | 구릉+계곡 |
| South| 8m | 0.004 | 5m | 0.60 | 3m | 화산 구릉 |
| North| 13m | 0.006 | 9m | 0.58 | 3m | 험준·산악 |
| Empire| 3m | 0.003 | 2m | 0.75(드묾) | 2m(정원 단) | 평탄·정원 |

**검증 (R2 완료 기준)**:
- EditMode: ①경계선 위 1m 간격 샘플 |Δh|<0.5m ②결정론 ③스폰 30m 평탄 ④국가별 진폭 분포(각 방위 50샘플 std가 테이블 ±20%)

### Phase T-R3. 국가별 지면 팔레트 — 스플랫/텍스처 재정의 (1.5일)

2. `TerrainSplatBaker` 가중치 재설계:
   - 절벽(ridge 마스크 m>0.5) → L3 바위 자동 지정 (형태와 색이 같은 데이터에서 나옴 — 정합성 핵심)
   - 수면 인접(호수 반경 +8m 밴드) → L5 모래/이끼
   - 흙길 경로 → L4 (TerrainPathGenerator와 동일 좌표계 사용)
   - 고도 3분위 → L1/L2
3. **야생화 패치 (예시의 꽃 들판)**: 스플랫 위 별도 패스 — 노이즈 마스크(주파수 0.02, 커버리지 ~8%)로

   (텍스처로 꽃을 그리는 대신 프리팹으로 — 저사양 유지)
4. 판타지 서브존(예시 12,13): 2.3의 서브존 마스크에 보라/마젠타 잔디 틴트(colorTint 방식 계승) + 꽃 프리팹 집중 배치

**검증**:
- 스플랫 베이크 테스트 갱신(가중치 합=1, 결정론) + 절벽 영역 L3 비율 수치 로그
- Play 스크린샷: 동쪽 라임그린 + 북쪽 청록/설 혼합 대비 확인(49~50)

### Phase T-R4. 데코 시스템 — Idyllic 전용화 + 국가별 랜덤 변주 (2일)

**목표**: "같은 느낌의 지형에 국가별 색·분위기가 랜덤(결정론 시드)으로 들어간" 식생.
