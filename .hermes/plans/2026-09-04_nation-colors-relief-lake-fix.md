## 1. 완벽 분석 — 3개 문제의 근본 원인

### 1.1 [문제 1] "고도가 있지만 평지처럼 보여 플레이어가 공중부양하는 것처럼 보임"

**원인: 지각 문제(렌더링)이지 물리 문제가 아님** — 세 가지가 겹침:

1. **카메라 피치 65~80°(근수직 탑다운)**: 고도 변화는 시차(parallax)로 인식되는데, 근수직 시점에선 언덕이 "텍스처"로밖에 안 읽힘. 지형 파장 200m/진폭 7~13m라 최대 경사 ~0.2로 완만 — 위에서 보면 평지처럼 뭉개짐
2. **잔디 텍스처 스케일 40** — 거친 풀잎 질감이 화면을 채워 지형 높이 정보를 덮음 (45에서 텍스처가 지배적으로 보이는 이유)
3. **셰이딩 부재**: 메시는 201×201이지만 노멀/음영 디테일이 없어(스플랫 단색+디테일맵) 언덕의 입체감이 소실. 그림자도 원거리에서 안 보임
4. 플레이어 위치는 정확함(콜리전 로그: 발밑 y 0.6 ≈ 지면 0.56) — "공중부양처럼 보임"은 주변 지형이 낮게 굴곡지며 시야상 발밑이 뚫려 보이는 지각 문제

### 1.2 [문제 2] "동쪽 말고 다른 방위에 방위 컨셉 색이 안 들어감" — 아키텍처 결함 확정

**근본 원인: 지형 메시에는 "단일 국가 머티리얼"만 적용되는 구조**
- `TerrainTextureApplier`는 **현재 국가(기본 East)의 스플랫 1장**을 2000m 전체 메시에 적용 (`ApplyMaterialForNation(_currentNation)`)
- R3에서 국가별 5스플랫을 베이크하는 파이프라인은 만들었지만 **지역별로 나눠 발라지는 구현이 없었음** — 5개 스플랫 중 1개(East)만 화면에 나옴
- 46의 "밝은 라임(좌) vs 어두운 올리브(우) 직선 경계" = 지형 메시의 East 머티리얼 영역 vs 외곽 Ground(Ground_Grass_Mat)/조명 음영의 경계 — 국가별 색 분할이 아님
- 이것이 로드맵 Phase 14의 핵심 미완성 부분

### 1.3 [문제 3] "호수가 여전히 치솟아 있음"

- 마지막 세션에서 W1 3단 구조+링 보정이 정상 작동(역전 경고 0건) — **수면-지형 교차 자체는 수리됨**
- 46에서 "하늘색 판이 공중에 떠 보이는" 잔여 요인:
  1. 수면 원판 가장자리(정확히 r)가 주변 선반 지형(wl−0.2)보다 **0.2m 위** — 비스듬히 보면 얇게 뜬 테두리가 보임
  2. 주변 지면이 (X1 이전) 흰색/어두운 올리브라 수면과의 정합성이 안 보였음 — 색 문제와 겹침
  3. 물 불투명 하늘색(cyan)이라 깊이감 없이 "판"처럼 보임
- 판정: 지면 색·음영 수리 후 재판정이 원칙. 단, 사용자가 3번째 지적한 만큼 이번 계획에 **수면 위치/색 보정을 포함**해 확실히 정리

## 2. 수리 계획 (Phase Y1~Y4, 총 3일)

### Phase Y1. 통합 월드 스플랫 — 국가별 색을 한 메시에 (핵심, 1.5일)

**설계**: 지형 메시 1장에 **5개 국가가 합성된 단일 마스터 스플랫**을 적용.

1. `TerrainSplatBaker`에 **마스터 베이크 신규**:
   - `BakeWorldSplat(resolution=2048, seed)` — 월드 전체(±1000m)를 2048px(~1m/px)로 스캔
   - 각 픽셀: `GetNationFromPosition(x,z)`로 국가 판정 → 경계 ±120m 크로스페이드 가중치로 **인접 국가 2개의 ComputeLayerColor 결과를 블렌딩** (R2의 고도 결과보간과 동일 원리 — 파라미터가 아니라 결과 보간)
   - 절벽/수변/흙길/꽃밭 마스크는 기존 ComputeWeights 그대로 공유 (R3 정합성 계승)
2. `TerrainTextureApplier.CreateMaterials` 교체:
   - 5개 국가 스플랫 대신 **마스터 스플랫 1개를 생성해 전체 메시에 적용**
   - 디테일 알베도는 위치별 국가 대표 잔디 유지(가까이서 국가 감별 가능)
   - 종전 국가별 머티리얼 파이프라인은 코드 보존(롤백 가능)
3. 베이크 비용: 2048² × 5레이어 샘플 — Start 1회, 수 초 예상. 진행 로그 출력
4. 검증: 씬뷰 47번 — 동=라임/서=황갈/남=적갈/북=청록/중앙=회백 구분 + 경계 크로스페이드 직선 없음

### Phase Y2. 평지 지각 해결 — 릴리프 가독성 (1일)

**카메라는 유지(사용자 탑다운 선호), 음영/텍스처로 해결**:

1. **잔디 텍스처 스케일 축소**: 디테일맵 타일 45 → **18** (풀잎 과대 확대 해소 — 지면이 질감이 아니라 지면으로 보이게)
2. **노멀 맵 적용**: Idyllic 팩에 실물 노멀 존재(`Textures/Ground/Grass/Grass_Normal.png` 등 6종) — TerrainLayerDef에 normal 필드 추가, 스플랫 적용 시 `_DetailNormalMap` 할당(국가별 대응 노멀) → 언덕 음영 디테일 부여
3. **릴리프 강화(선택 토글)**: 북쪽 제외 전방위 진폭은 유지하되, 시야 가독성을 위해 **정점 컬러 AO 근사** — 메시 정점 높이 기준 골짜기(하위 15%)에 어두운 틴트를 스플랫 베이크에 반영(이미 고도 3분위 로직 있음 — 대비 강화)
4. **그림자 거리 상향**: URP ShadowDistance 50 → 120 (언덕 그림자가 보여야 고도가 읽힘) — 프레임 영향 측정 병행
5. 검증: 48번 — 플레이어 주변에서 언덕이 "면"으로 읽히는지, 공중부양 착시 완화

### Phase Y3. 호수 마무리 (0.5일)

1. **수면 0.15m 하강**: 물 표면을 `waterLevel − 0.15`로 — 선반(wl−0.2)과의 테두리 돌출 제거, 수면이 지형에 "박힌" 느낌
2. **수면 색/투명도 튜닝**: 불투명 시안 → 반투명 유지하되 알베도 채도 살짝 낮춰 주변과 조화 (국가별 틴트 유지)
3. 수변 데코(갈대/연꽃 276+40개 배치됨)와 수면 높이 정합 확인
4. 검증: 49번 — 호수가 지면에 "박힌 호수"로 보이는지
5. **변수 통제 원칙**: Y1~Y2 머지 후 판정 — 이상하면 그때 물 디테일만 추가 튜닝

### Phase Y4. 검증·문서화 (0.5일)

1. 방위별 색 매트릭스(픽셀 샘플 5지점) + 클리핑 <10% + 호수 역전 0 재확인
2. 프레임타임 회귀(노멀맵+그림자 120m) 측정
3. QAPROGRESS + 메모리 + git commit/push + ROADMAP 체크
