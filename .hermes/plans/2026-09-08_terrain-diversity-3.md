# 지형 다양화 3차 (T-D3) — 예시2~13 잔여 Gap 완전 소거
작성: 2026-09-08 | 트리거 대기(유저 "진행" 시 실행) | 선행: T-D2 완료(커밋 3833b9cf)

## 배경
T-D2로 G1(노출암반)·G3(모래사장)·G7(분지) 소거, G2/G5 부분 충족. **잔여 미충족**:
- G2: 일반 구릉의 계단식 층절벽 (StratifyMesa가 메사에만 존재)
- G4: 연잎/연꽃 수면 데코 + **수면 바위(예시3의 핵심 연출 — 미발견 Gap)**
- G5: 꽃융단이 예시12/13의 "언덕 전체" 규모 대비 작음
- G6: 수종 3종 혼합 규칙 없음 (수양버들=수변, 침엽=능선, 활엽=군집)
- G8: 방위별 야생화 색 차등 없음
- G9: 흙길이 능선을 타지 않고, 호수와 연결 안 됨

## 예시 재분석 수치 근거 (vision 2장)
- 예시6: 활엽 60%+수양버들 40% 소군집(2~3그루), 수양버들=수변·경사면, 암벽 3~4단 테라스+상단 잔디, 표면 노출 40~50%(전면 적용 금지 — 블록 선별), 길=골짜기 S자+블렌딩 경계
- 예시3: 연잎 군집 5~10개+연꽃 1~2, **수면의 15~20%만 데코**, 호수 내부 대형 바위 10~12개로 수면 분할(바위:수면=3:7 체감), 수초 1~1.5m 뭉치, 붉은 관목 포인트, 숲=반원 그라디언트(전경 소밀→원경 밀집)

## 불변 제약
- 델타 가산 원칙(SubBiomeVariation 파괴 금지, cliffSupp 보호)
- 재귀가드: 마스크는 LakesOrNull, 캐시는 LakesReady 후 무효화
- 배치 규약 y=1f+GetHeightAt(x,z,Plains,42), Empire 중앙링 공유세트 패턴 유지
- 저밀도(과밀 금지), 국가 색 규칙 준수, 스폰/영지 pause 유지(T-D2 판정 전까지)

## Phase T1 — 지형 실루엣: 층절벽 일반화 + 만 형성
| 항목 | 내용 | 수치 |
|:---|:---|:---|
| T1-1 층절벽 일반화 | StratifyMesa 파라미터를 일반 구릉으로 확장 — 방위당 2~3개 "절벽 블록" 선별(ridge 상위 8~12% + 경사 게이트), 3~4단 테라스 + 상단 잔디 덮음 | 블록 반경 40~80m, 단 높이 2.5~4m |
| T1-2 능선 강화 | 선별 능선(방위당 1~2개)에 진폭 +30% 국소 델타 — 전체 진폭 유지, 국소만 | 능선 길이 200~400m |
| T1-3 호수 만(cove) | 호수 마스크에 저주파 노이즈 변조(반경 ±8%) — 원형→아메바, 만 2~3개 형성. **18개 전체 1.7r 밴드 무겹침 재검증 필수** | 노이즈 주파수 0.02~0.05 |
파일: TerrainShape.cs(T1-1 게이트+T1-3 변조), TerrainGenerator.cs(T1-2 델타)
리스크: T1-3이 호수 전역 영향 — 시뮬로 18개 밴드 검증 후 적용, 실패 시 롤백 플래그
