## 1. 완벽 분석 — 픽셀 단위까지 입증한 원인

### 1.1 결정적 발견: **동쪽 잔디 텍스처 3장이 전부 흰색 마스크다** (신규 확정)

`Assets/Resources/Models/UserProvided/terrain/textures_idyllic/` 21종을 픽셀 샘플링한 결과:

| 텍스처 | 내용 |
|--------|------|
| **east_grass1_albedo.png** | RGB = **순백(255,255,255) 100%**, 알파 채널만 0~255 변화 — **알베도가 아니라 잔디 카드용 알파 마스크** (2048² RGBA, 원본 2023-10 제작) |
| **east_grass2_albedo.png** | 동일 — 흰색 마스크 |
| **east_grass3_albedo.png** | 동일 — 흰색 마스크 |

- 즉 **동(East) 지면 L1/L2와 북(North) L1이 "흰색 마스크 텍스처"를 알베도로 쓰고 있었다.**
- 스플랫 베이크는 L1/L2가 우세(고도 3분위) → **동쪽 지면 대부분 = 흰색 × 국가 tint → 순백**
- 스크린샷 43 픽셀 카운트: 순백 94.9% — 이것이 화이트아웃의 정체. (조명은 이미 정상: 로그로 Sun 0.8 + 컬러그레이딩 + god rays 전부 확인됨)
- 44에서 "굴곡이 보이기 시작한 것"은 W3 메시 201×201 교체가 **성공**했다는 증거 (GroundWatch vtx=40401 로그 일치)

### 1.2 흰색 마스크의 출처
- 파일 생성일 2023-10-04 — **원본 Idyllic 팩의 잔디 카드(grass card)용 알파 마스크**로 추정 (RGB 흰색 + 알파가 잎사귀 모양)
- 이전 세션에서 "textures_idyllic 21종"을 만들 때 잔디 3종을 마스크 파일로 잘못 수집
- 이후 R3 5레이어 매핑이 east_grass1/2를 L1/L2로 지정 → 흰 지면

### 1.3 진짜 알베도는 팩 안에 있었다
- `Assets/Idyllic Fantasy Nature/Textures/Ground/Grass/Grass_Albedo.png` = **실제 라임그린 잔디** (185,188,41 등, 2048²)
- 동일 구조로 Cliff/Rock/Dirt/Cobblestone/Forest/Sand 실물 알베도 전부 존재 (Normal 포함)

### 1.4 호수가 "치솟아 보이는" 진짜 이유 (재판정)
- 마지막 세션 로그: 호수 6개 waterLevel 링 보정 정상 적용 + **역전 경고 0건** (W1 3단 구조가 작동함 — LakeGenerator 역전 안전망 미발동)
- 즉 수면-지형 교차는 이미 수리됨. 44에서 호수가 식별 안 되고 "치솟아 보인" 건:
  1. **주변 지면이 순백**이라 민트색 수면 원판과의 명암 대비가 없음 → 판이 떠 있는 것처럼 지각
  2. 씬 뷰 원거리 무그림자 상태에서 높이 정보 소실
- → **지면 텍스처 수리가 호수 인식 문제의 선행 조건.** 텍스처 수리 후 45번으로 재판정하는 것이 순서.

### 1.5 남은 의심점 (보조)
- 44의 좌/우 색 분할: 밝은 쪽 = 동(흰 마스크) 지면, 어두운 쪽 = 남/서(정상 색 텍스처 + 씬뷰 조명각) — 텍스처 수리 시 함께 해소 예상
- 물 수면 자체의 회전 문제는 배제(로그에 이상 없음, 44에서 "지형과 같은 높이"로 보인 건 흰 지면과의 대비 부재)

## 2. 수리 계획 (Phase X1~X3, 총 1.5일)

### Phase X1. 흰색 마스크 → 실물 알베도 교체 (핵심, 0.5일)

1. **원본 확보**: Idyllic 팩의 실물 알베도 6종을 textures_idyllic 경로로 생성:
   - `east_grass1_albedo.png` ← `Textures/Ground/Grass/Grass_Albedo.png` (라임그린, 그대로)
   - `east_grass2_albedo.png` ← Grass_Albedo에 **미세 색상 변주**(결정론 hue/밝기 시프트 — 예: 채도+8%, 밝기 −5%)로 L1/L2 구분
   - `east_grass3_albedo.png` ← Grass_Albedo 변주 2
   - `north_grass_albedo.png` ← Grass_Albedo에 **차가운 틴트**(청록 시프트) — 북 컨셉
   - 생성 방식: 파이썬(PIL)으로 변환 후 같은 경로에 저장 (2048² 유지, git add -f — 메모리의 LFS 규칙)
2. **안전 장치**: 변환 스크립트에 "흰색 마스크 감지" 단정 추가 — 만약 대상이 실제 알베도였으면(이미 색 있으면) 덮어쓰지 않음(방어)
3. TerrainLayerDef 매핑은 그대로 (경로 불변 — 파일만 교체). Ground_Grass_Mat의 _BaseMap guid(east_grass1)도 자동으로 정상색 획득
4. 임포트 확인: PNG 교체 후 Unity 재임포트 필요 — 에디터 포커스 시 자동

### Phase X2. 마스크 유사 텍스처 전수 검증 가드 (0.5일)

1. `TerrainTextureApplier.LoadTextures()`에 **흰색 마스크 감지 가드**:
   - 로드한 텍스처가 "순백 RGB + 알파 가변"이면 LogError + (가능하면) 동일 폴더의 대체 색 텍스처로 스왑
   - 판정 로직: 픽셀 샘플 32×32 → RGB 분산이 거의 0이면서 알파가 0/255 이분형이면 마스크로 판정
   - 마스크가 걸리면 로그: `⚠️ {name}은(는) 알파 마스크로 추정 — 알베도 부적합`
2. TerrainSplatBaker도 같은 가드의 판정 함수 재사용(단일 static 유틸로 분리)

### Phase X3. 검증·문서화 (0.5일)

1. Play 재부트 후 확인:
   - 43 재현(게임뷰): 동쪽 지면이 **라임그린 잔디**로 보이는지, 화이트아웃 해소(순백 <10%)
   - 44 재현(씬뷰 전체): 국가별 색 구분 + 호수 6개가 지면 위 판이 아닌 "물"로 보이는지
   - 콘솔: 마스크 경고 0건(가드가 발동 안 하면 교체 성공), NRE 0
2. 호수 재판정: W1이 이미 역전 0을 보장하므로, 흰 지면 수리 후 45번에서 호수 판정 — 여전히 이상하면 그때 물 디테일(수면 머티리얼/투명도) 튜닝으로 이어감
3. 3곳 저장: QAPROGRESS + 메모리 + git commit/push
