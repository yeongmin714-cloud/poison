3. **차등 진단(비교 실험)**: 같은 세션에서 **세금제안 창(117차 신규 — 불투명 배경)도 함께 개방** 비교 — 세금창 보임+음식점창 미보임 = "투명 루트 + 자식 패널 렌더" 문제로 확정 → 그 경우 LeftPanel 등 자식의 worldBound 로그가 범인 지정(0×0/밖/미부착). 세금창도 안 보이면 UIDocument/루트 계층 조사로 확장.

## R3. 지형 반영 지도 — 절차 베이크 (질문 답변: 가능합니다)

**답변**: 가능합니다. 실측 데이터가 이미 다 있고(E6), 프로젝트의 결정론 베이크 관례(낚시 GLB 동기베이크 선례)와 동일한 방식으로 양피지 위에 지형을 그릴 수 있습니다.

설계 — **세션당 1회 절차 베이크(정적 캐시)**:
1. **베이크 해상도/시점**: 256×256(65k 샘플 — 첫 개방 시 수십 ms, 지연 허용) 또는 512×512(분할 코루틴). 세계 span 3200 → 픽셀 매핑은 기존 마커 %(WorldU/WorldV) 산식 재사용 — 좌표계 이중화 없음.
2. **레이어(실측 데이터만 — 위조 금지)**:
   - 국가 바이옴 바탕색: 영지 정의(국가별 worldPosition) 기반 지역 판정 → 동=초원 녹 / 북=설산 백 / 서=화산 암적 / 남=사막 황 (색은 실측 후 확정 — "국가색 유지" 디자인 선호와 정합)
   - **호수**: `TerrainGenerator.Lakes`(center/radius) → 파란 원(물 표시)
   - **강**: `GetRiverMask(x,z)` 임계 샘플링 → 파랑 라인
   - **나무/숲**: TerrainModelPlacer 배치본(부모 GO 자식 열거) + ResourceNode(Wood) 위치 → 진녹 점 클러스터(숲 표시)
   - 고도 음영(선택 2차): GetHeightAt 밝기 변화 — 산악 음영
3. **합성**: 양피지 베이스 위에 지형 레이어 **알파 블렌드 오버레이**(중세 지도 질감 유지) → 마커(영지/내 영지/전쟁/황제국)는 기존 % 좌표 그대로 최상단.
4. **캐시/갱신**: 정적 텍스처 캐시(세션당 1회) — 지형은 씬 중 변경 없음(건설은 마커로 표현되므로 재베이크 불필요).
5. **테스트**: 베이크 함수 순수부(좌표→색) 단위 어서션 + 소스 어서션(레이어 구성).
6. **위임 분할**: 베이커 신규 파일(Systems 또는 UI.Toolkit — 1파일 신규 + WorldMap 배선 증분) — 사전소화 지시서로 서브 위임, 배선/톤 조정은 부모.
