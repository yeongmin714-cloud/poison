## 진단 확정 (소스 실측)

### 1. DayNightCycle이 매 프레임 포그 강제 (뿌리)
- `DayNightCycle.cs` L177-179 + L437-439: **`RenderSettings.fog = true`를 매 프레임 강제** + `_nightFogColor↔_dayFogColor` / `_nightFogDensity↔_dayFogDensity` Lerp. 씬/셋업 스크립트가 포그를 꺼도 다음 프레임에 즉시 복원 → 다른 스크립트의 포그 조정은 전부 무력화.
- `DayNightCycle.cs` L66-69 기본값:
  - 낮: color (0.7,0.75,0.8) / density **0.01**
  - 밤: color **(0.05,0.05,0.1) ≈ 거의 완전 검정** / density **0.03**
- Exponential 모드 특성거리 ≈ 1/density:
  - 밤 0.03 → 특성거리 ~33m, 100m 거리 투과율 e^(−3)=5% → **95%가 포그색으로 대체**
  - 낮 0.01 → 100m에서 63% 포그(여전히 뿌옇)
- 아레나 외부씬 카메라→아레나 거리 약 50~100m → 밤에는 아레나 실루엣이 거의 전부 검정 포그색(하늘과 구분 불가)으로 대체 = "아레나가 안 보임"의 직접 원인. 낮에도 뿌옇게 보이는 현상과 정합.

## 수리 계획 (F1~F3, 구현은 사용자 승인 후)

### F1 — 야간 포그 밀도 완화 (DayNightCycle.cs)
- `_nightFogDensity` 0.03 → **0.005** (Exponential 특성거리 33m→200m; 100m 투과율 5%→61%, 50m 투과율 78%→78%→e^(−0.25)=78% 유지수준 — 원거리 실루엣 식별 가능).
- 낮 밀도 0.01 → **0.005**로 동시 완화 (100m 63%→39% 포그 — 야외 광역 뷰 탁도 개선). 균형상 분위기 훼손 최소.

### F2 — 야간 포그색 청백화 (DayNightCycle.cs)
