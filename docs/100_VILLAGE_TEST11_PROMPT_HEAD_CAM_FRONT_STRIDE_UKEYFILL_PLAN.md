## 1. 실측 증거

### P1 프롬프트 — 배치는 성공 판정이지만 NPC "아래"에 붙음

- 판정 로그의 "부착" 기준(중심 거리 34px)은 패널 가장자리 기준으로 성공으로 찍히지만 **시맨틱 위치(머리 위)**가 계약에 없었음.

### P2 카메라 — 근접했으나 정면 미노출 + 하체 절단
- `[99차 F-B] 전신프레임 — bounds(minY=1.85,maxY=3.64) dist=2.92 상/하단여유 0.17m` — 산식상 전신 수용.
- 영상 33~42s 클로즈업 실측: NPC **모자/상체 위주 + 하체 절단, 정면 얼굴 미노출(측후면 느낌)**.
- 유력 원인 2개: ①높이 가드 `playerY+2.3m`가 지배해 하이 앵글(4.3m)이 됨 — 정면 얼굴이 프레임 상단 밖/측면으로 치우침 ②측면 오프셋 0.9m + 플레이어가 카메라-NPC 사이에 존재 → 하체 가림. bounds minY=1.85는 스킨바운드 부양 가능 — 실제 발(Foot 본) 기준 프레이밍 필요.

### P3 애니 — 상태머신/골격 정상, "보행 정합"이 원인
- `[99차 F-C] 골격정합 — 전원 smr=1 불일치=0` → SMR 골격 가설 **기각**(99차 프로브가 판정).
- `[98차 F1] 애니 진단 — state=Walk norm 0.23→7.47 루프 정상` 192샘플. 상태머신 정상.
- 클로즈업(정적 카메라) Idle 구간 픽셀 차이 평균 0.03~0.2 — Idle 미세 동작 범위(동결 아님).
- **핵심**: 스트라이드 정합 결과 — slip 0.34~0.52m/s, animSpeed **1.33~1.59** 부여(상한 1.8), 클립 유효 보행속도 실측 0.81~1.05m/s vs 루트 walkSpeed 1.4/1.25.
  → 클립 자연 보폭(≈0.9m/s)보다 루트가 40~60% 빠름 → 애니를 1.5배속으로 틀어도 슬립 0.4m/s 잔존 = **다리는 빠르게 돌고 몸은 미끄러지는(문�워크) 이상 보행**. 캘리브레이션 방향(애니를 속도에 맞춤)이 구조적 한계.

### P4 U키 — 창은 렌더됨, 콘텐츠가 창박스를 채우지 않음
- `[99차 F-E] 콘텐츠 렌더 — worldBound=(120,65,1200x780) children=4 판정=정상` — 99차 F-E 수리 유효(창+콘텐츠 렌더).

- 부착 검증 로그에 시맨틱 판정 추가: `패널하단중앙↔머리앵커 거리 ≤ 24px = 부착(성공)` — 기존 34px 중심 거리 판정과 병기.
- 비가시 숨김(99차 F-A) 계약 유지.

### F-2 카메라 정면 보정
파일: `Assets/Scripts/Systems/DialogueCameraDirector.cs`
- 높이 가드 완화: `playerY+2.3` → `playerY+1.75`(플레이어 머리 1.7m+여유)와 `center.y+0.6` 중 큰 값 — 하이 앵글 완화로 얼굴 프레임 진입.

- LookAt 상향 바이어스: center + up×0.15m(머리 쪽 — 얼굴 중심 프레이밍).
- 전신프레임 실측 하단 기준을 bounds minY → **Foot 본 최하단 y**로 교체(스킨바운드 부양 방어) — 하단여유 로그 실측화.

- 병사/영주 경로 무변경.

### F-3 보행 정합 재설계 (속도를 애니에 맞춤 — 방향 반전)
파일: `Assets/Scripts/Systems/VillagerWanderer.cs`
- walkSpeed 재조정: 캘리브레이션 1회 실측(measuredSpeed)을 walkSpeed에 채택 — animSpeed는 **1.0 고정 회귀**. 초기값 walkSpeed = 클립 유효 보행속도(성인 0.95/girl 0.85 부근 — 실측치 0.81~1.05).
- 목표: 잔존 슬립 < 0.1m/s. 캘리브레이션은 "animSpeed 올림" 대신 "walkSpeed 재조정"으로 전환(애니 배속 상한 1.8 남용 폐지).
- 이동 로직(forward×walkSpeed×dt)/Speed 플립 계약 무변경. 캘리브레이션 로그에 새 판정 필드(`목표=walkSpeed 정합`).
- 대화 정지→재개 사이클에서 캘리브레이션 재실행 시 기존 보정치 재사용(모델별 캐시 — 세션당 1회 실측).
