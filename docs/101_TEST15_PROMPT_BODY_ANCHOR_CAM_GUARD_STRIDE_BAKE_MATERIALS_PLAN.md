## 2. 수리 스펙

### F-1' 프롬프트 본체 단일 앵커
파일: `Assets/Scripts/UI/Toolkit/InteractionPanelUTK.cs`
- 앵커 교체: 정면앵커/재투영 경로 폐기 → **본체 단일 앵커** — x = NPC 렌더러 bounds 중심 투영 x, y = (Foot 본 y + 1.95m) 투영 y(머리 위). Foot 부재 시 bounds maxY+0.15 폴백.
- 배치: 패널 하단 중앙 = 본체 앵커(기존 100차 산식 유지 — 앵커 소스만 교체).
- 판정 강화: `몸중심 x 편차 ≤20px AND 패널하단↔머리 y ≤24px = 부착(성공)` — x축 판정 신설(자기참조 방지 — 앵커 좌표와 본체 실측 좌표를 별도 산출해 대조).

### F-2' 카메라 거리 가드 + 로그 산식 수리
파일: `Assets/Scripts/Systems/DialogueCameraDirector.cs`
- 거리 재조준: ReframeCamera에서 매 틱 거리 재계산 — dist = max(기본 2.92m, NPC bounds 반경×2+0.5m) — 모델 내부 침투 방어. nearClip 보정(92차) 유지.
- 각도: 현행(측면 0.45m+높이 가드 1.75+LookAt 0.15) 유지 — Play에서 가림/정면 판정 로그([100차 F-2] 가림)로 잔여 확인, 미세 조정은 다음 차수.
- 전신프레임 로그 산식 수정: 실제 프러스텀 반높이=dist×tan(FOV/2), 센터=LookAt y — 상/하단 여유를 실측 좌표(하단=Foot 본, 상단=하단+1.8m) 대비 산출. 음수 여유 불가 검증.

### F-3' 모델별 보행 베이크
파일: `Assets/Scripts/Systems/VillagerWanderer.cs`
- 실측 기반 모델별 walkSpeed 상수 테이블 신설(테스트11/12 실측: man1 1.10/man2 1.08~1.14/girl1 0.79~0.80/girl3 0.97/oldman1 1.06/oldman2 1.07 부근 — 구현 시 최신 실측 우선) — 첫 스폰부터 정합(캘리브레이션 대기 시간 제거).
- 잔존 슬립 >0.1m/s 모델 한정 animSpeed 미세 트림 허용(0.9~1.1 클램프) — 이후 캘리브레이션 스킵.
- 캘리브레이션은 테이블 미지 모델의 폴백으로만 유지.
- 로그: `[101차 F-3] 보행 베이크 — model=… walkSpeed=…(테이블) 슬립목표=<0.1`.
