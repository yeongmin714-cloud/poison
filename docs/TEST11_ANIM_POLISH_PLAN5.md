## Phase 1 — JobTempAlloc 누수 (최우선: 성능/메모리 위협)
- **원인 후보**: ProceduralAnimationController의 네이티브 잡 경로(AllocateNativeArrays + LimbIKSolver.
  ScheduleParallel) — 프레임마다 잡 스케줄 + temp NativeArray가 4프레임 내 해제되지 않음.
  2족(미노타우르스)에서 발화 → 다른 몬스터 로그 사이에도 스팸.
- **수리**: ①2족 경로의 ScheduleParallel 호출 제거(동기 처리 또는 4족과 동일한 본회전 보행으로 대체)
  ②잡 버퍼 상시 할당+Dispose 패턴으로 전환. 회전 보행 전환으로 4족은 이미 잡 불필요.
- **완료 기준**: JobTempAlloc 경고 0건.

## Phase 2 — ShowcaseMonitor 재설계 (진단 신뢰성 확보)
- **문제**: 관측 본이 SMR.bones[0]/중앙/맨끝 추정이라 실제 구동 본(다리 체인 루트)을 놓침
  → IK가 정상 작동해도 폴백 경고가 뜸 + 폴백은 스티키(재검증 없음)로 영구 활성.
- **수리**: ①관측 본을 **매핑된 구동 본**(L_Hip/R_Hip/L_HindHip/R_HindHip + Spine0)으로 교체 —
  Setup 시 boneMap 레퍼런스를 받아 관측 ②스티키 해제: 3초마다 재검증, 변화 감지 시 폴백 자동 해제
  + "[ShowcaseMonitor] 폴백 해제 — 애니 정상화" 로그 ③slime(Special) 스케일 관측 본을
  실제 펄스 대상 본(Root)으로 교체.
- **완료 기준**: 정상 구동 몬스터 폴백 경고 0건, 진짜 고장만 경고.

## Phase 3 — 보행 품질 라운드 튜닝
- 회전 보행이 실제 화면에서 보이는지(Phase 2 신뢰 로그로 판정) → 스윙 각도/주기 미세 조정
- 발 미끄러짐·부유 재평가 (타일시트 연속 프레임 분석 — 1fps 단일 프레임 아님)
- 필요 시 접지 스냅(발 y 고정) 추가

## Phase 4 — 검증 루프
- 각 라운드: 유니티 재컴파일 → 영상 촬영 → 타일시트 분석 + 로그(매핑/폴백/누수/FPS) 판정 → 다음 라운드
- 합격 기준: ①누수 경고 0 ②폴백 경고 0(정상 구동 시) ③타일시트상 미끄러짐/부유 미관찰
