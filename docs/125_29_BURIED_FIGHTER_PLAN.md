# [125차 후속29 계획] 결투선수 지하 낙하 확정 수리 — 접지 실패 3중 원인과 물리 안전망

> 상태: **계획 수립 — 구현은 사용자 승인 후.** 사용자 추측 "병사가 지형 밑에 묻여 있다" = **수치로 확정**.
> pit_late 실측: 병사 pos y=**-27.93 / -29.35**(모래 톱 0.15 대비 28m 지하), worldHeight 1.29/1.34(크기 정상).

---

## 확정된 인과 사슬 (모든 증상이 하나로 설명됨)

| 증상 | 원인 | 근거 |
|---|---|---|
| 병사 안 보임 | **스폰 직후 낙하** — 스폰(±5, 0.15) → 2.5s 후 y=-28/-29 | 자유낙하 0.5×9.81×2.5²≈30m — 시간 정확 일치 |
| 병사 "작아 보임" | 지하 매몰 + 수직 관전 투영 — **크기 자체는 정상** | worldHeight 1.29/1.34m bounds 실측 |
| 이름표 안 보임 | 병사 앵커(머리+2.2m)가 지하(-26m) → 카메라 시야 밖 | pit_late pos 실측 |
| 플레이어 이탈 (-4, 1.27, -24) | 지형 콜라이더 통과 낙하 → 왕가 박스 플랫폼 에지 착지 추정 | 배치(0,0.65,-7.5) 로그 vs 2.5s 후 좌표, 왕가 박스 z범위(-24.05~-28.55) 일치 |

**낙하의 기술적 원인(2겹)**
1. **ProceduralAnimationController 자체 중력**: gravity=-9.81 내장( 소스 L56 ) — 지면 판정 실패 시 스스로 루트를 낙하시킴
2. **지면 판정 실패 사유**: 스폰 y(0.15) = 모래 톱과 정확히 겹침 → 발 레이캐스트가 콜라이더 표면에서 시작해 미스 +
   모래/에이프런 = 비균일 스케일(35.6,0.15,37.2) Cylinder MeshCollider — 충돌 신뢰성 저하

## 수리 항목 (판정 기준 사전 정의)

### G1. 병사 스폰 높이 상향 — 0.15 → 0.6
- 지면 레이캐스트(groundCheckDistance 1.0m)가 위에서 아래로 모래를 인지하게 함(접지 성공 경로).
- 착지는 proc 컨트롤러가 자체 수행(검증된 경로 — 구조 스왑 금지, 파라미터만).
- **판정**: pit_late bounds.min.y ≈ 0.15±0.05.

### G2. 모래 표면 보행용 박스 콜라이더 추가 (플레이어+병사 공용 보행면)
- 모래 톱 위 얇은 BoxCollider(y=0.14, ±17.8×±18.6) — 비균일 스케일 실린더 MeshCollider의 불신뢰를
  결정론 박스로 대체. 렌더와 무관한 충돌 전용(시각 변화 0).
- **판정**: 재Play에서 플레이어/병사 모두 지상 유지(플레이어 y≈1.05±0.1 — 컨트롤러 중심 기준).

### G3. 병사 물리 안전망
- 스폰 후 자식 전수 조사: Rigidbody 발견 시 isKinematic=true+useGravity=false
  (이동 계약 = LungeVisual 트랜스폼 구동 — 물리 이동 불필요, Physics의 예외적 낙하 원천 제거).
- CharacterController가 있으면 enabled=false.
- **판정**: 동일 — bounds.min.y 실측.

### G4. (백업 스위치) proc 컨트롤러 중력 토글
- G1~G3으로도 낙하가 재발하면 ProceduralAnimationController에 공개 플래그(GravityEnabled) 추가 후
  병사 스폰 시 off — 검증된 경로 내 파라미터 계약(84차 교훈: 구조 스왑 금지, 파라미터 튜닝만).
- 본 항목은 G1~G3 실패 시에만 착수.

### G5. 진단 유지
- F5(캡처 직전 관전 프레이밍 강제) + F1(bounds 덤프 + min.y 추가) 유지 — 모든 판정이 수치로 남는다.

## 검증 절차 (재Play 1회)
1. pit_late 덤프: 병사 pos.y ≈ 0.15 / bounds.min.y ≈ 0.15 / worldHeight 1.29~1.34 유지
2. RT 판독: 병사 2기가 모래 위에 서 있음(높이 ≈ 화면 8% — 1.3m/16m) + 플레이어 하단 표시
3. 영상 판독: 병사 2기 위 이름표 2개(이름+HP바) + 결투 애니 진행
4. 로그: 이동자 감지 상태 / 예외 0 / baseline 1:1
5. 미충족 시: 판정 기준 명시 후 G4(백업 스위치) 착수
