## A. 월드맵 플루언트 정합
- WorldMapWindowUTK 크롬(범례/위치줄/헤더) → 플루언트 언어: 반투명 글래스 패널(0.85)+액센트 테두리+플루언트 타이포·라운드. 양피지/마커/지형 오버레이/풀스크린 계약 유지(사용자 확정 — 등배수 예외).

## B. 상호판넬 (261:3)
- InteractionPanelUTK에 아레나 2액션 변형 추가 — 신규 kind ArenaManager(관리인 NPC): 액션 [대화하기, 베팅하기], 261:3 정합 스타일(모서리 장식/액션 버튼 색 구분). 기존 63차 상호 패널 경로(좌클릭+F키) 재사용.

## C. 로비 관리인 NPC
- ArenaInteriorBuilder에 베팅 관리인 NPC 1명 배치(바 카운터 옆 — GLB npc 규약 + 캡슐 폴백, 63차 GLB 교체 패턴). 클릭 → B 패널. 기존 ArenaNpc(E키 ArenaMenu)는 유지 — 역할 분리(관리인=베팅, 데스크 NPC=직접 출전 메뉴).

## D. 투기장 베팅 UI — ArenaWindowUTK 신설 (255:647 전정합)
- 음식점창 동일 골격(1600×1040, UIRoot 부착 패턴) + Figma 텍스트/좌표/색상 전실측 정합.
- 좌: 선수 카드 리스트(선택 상태 전환), 우: 상세+베팅 계산기(금액 빠른 설정 칩/예상 수령액·순이익 실시간/잔액 미리보기), 확정 버튼.
- 헤더 현재 위치/게임 시간 = 기존 시계 시스템 연동.

## E. ArenaBettingSystem 신설
- 선수 2명 생성: 이름/출신 설명/태그/공·방·민 + 세션 누적 기록(승·패·승률).
- 배율: 능력치 기반 implied odds(1.2~3.0 클램프) — 베팅 시점 고정(전투 중 변동 없음).
- 확정: 골드 즉시 차감(부족 가드/0 금지) → 전환 트리거. 정산: 승리 bet×odds 수령(원금 포함), 패배 0. 토스트+전투 로그.
- 선수 기록 세이브 영속은 후속(기본 세션 누적).

## F. 자동 전투 플로우
- 베팅 확정 → ArenaWindow 닫힘 → 로비→투기장 자동 전환(IndoorSceneTransition 경로) → 선수 2명 스폰(**120차 배치구역 서/동 연동**) → 대면.
- 라운드제 자동 전투(ArenaSystem 라운드 로직 확장 — 공·방·민 판정, HP 소모, 근접 애니 트리거+피격 FX+고스트 HP바). "마지막까지 생존한 선수 1명이 승리".
- 결과 표시 3~5s → 승자 기록 갱신 → 정산 → 로비 자동 복귀.
