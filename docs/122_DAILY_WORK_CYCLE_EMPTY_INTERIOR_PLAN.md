# 122차 계획 — 병사 일일 노동 사이클(가시) + 저장고 선행 게이트 + 전 영지 빈 실내 규칙

## 발단
사용자 — ①병사배치의 채집/채광/사냥 역할 병사가 **하루마다** 각 작업을 수행해 수확물을 **알아서 저장고에 적립** ②역할 배치의 선행 조건 = 그 영지 실내에 **저장고 존재** ③**모든 영지**(초기 성 포함) 실내는 **빈 상태로 시작** — 크래프트 창·저장고를 플레이어가 직접 배치(기존 건설 경로). 테스트씬의 선구성은 편의용 유지.
확정: 1=(b) 가시 일일 사이클 / 2=기존 쿨다운 루프 **교체** / 3=메인씬 전 영지 빈 실내 / 4=기존 건설 관리 UI 경로 / 플레이어 직접 수확 0변경 / 사냥 사망 8% = 사냥병사 1인당 하루 1회.

## 현황 실측 (계획 근거)
- GuardTaskSystem: Gather(2s 채널)/Hunt(전리품+8% 사망)/Mine(3s 쿨다운) — 수확물 전부 **PlayerInventory** 적립, 실시간 루프.
- WarehouseSystem.AddItem(string territoryId, ItemData, count) — 영지별 저장고 적립 API 존재.
- PlayerCastleInteriorBuilder L446: StorageShelf에 TerritoryWarehouse **자동 부착**(영지 키) — 실내 스테이션도 선구성 → 제거 대상.
- ConstructionManager: 음식점만 실내 배치 금지, **타 시설은 실내 배치 가능**(90차 사용자 요구 2) — 크래프트 시설 건설 경로 존재. 창고(저장고)는 건설 항목으로 전환 필요.
- TimeManager.OnDayStart 이벤트 존재(GuardSalaryManager.OnDayStart 선례).

## R1 — 병사 일일 노동 사이클 (가시, GuardTaskSystem 교체)
- **개시**: 낮 시작(OnDayStart 또는 낮 전환 이벤트) → 채집/채광/사냥 배치 병사 그룹핑 → 영지 근처 작업 대상 선정(기존 탐색 로직 재사용 — 약초/ResourceNode/몬스터).
- **사이클**: 성문/로비 집결 → 대상 지점 이동(가시 보행 — SetCommandTarget) → 작업 연출(채집 캐스팅 바/채굴/사냥 전투) → 수확 집계 → 귀환 → **WarehouseSystem.AddItem(영지 키)** 적립 → 귀환 상태(침대/대기 — 기존 침대 규약).
- **수확량**: 병사 레벨·능력치 기반 산식 + 대상 품종(약초/고기/광물 종별). 사냥 = 전리품 고기 + **8% 사망(1인당 일 1회 — 사망 시 기존 Die()/GuardManager 제거 경로 + 로그)**.
- **폐기**: Gather/Hunt/Mine 실시간 쿨다운 루프(Update 분기) 제거 — Attack/Defend/Farm/Envoy는 무변경(이번 범위 외).
- 멱등/예외 안전: 대상 부재 시 스킵 로그, 씬 전환 중 중단 가드.

## R2 — 저장고 선행 게이트
- 병사배치 UI 역할 할당 시 채집/채광/사냥 → **WarehouseSystem에 그 영지 저장고 존재 검사** → 없으면 배치 거부 + 토스트 "저장고를 먼저 건설하세요" (피드백 필수 계약).
- GuardTaskSystem.AssignTask에도 동일 가드(이중 방어 — 리플렉션/직접 호출 모두 차단).

## R3 — 전 영지 빈 실내 규칙
- PlayerCastleInteriorBuilder: 스테이션/저장고 **자동 부착 전부 제거**(StorageShelf-TerritoryWarehouse 자동 부착, 크래프트 쉘프 상호작용 등) — 실내는 방 셸만 생성.
- 창고(저장고)를 **실내 건설 가능 항목**으로 추가(ConstructionManager — 건설 시 TerritoryWarehouse 부착+StorageShelf 실물 생성, 영지 키 바인딩).
- 크래프트 스테이션(제작/요리/연금) 실내 건설 항목 확인·보강(90차 경로 재사용 — 실물 생성+상호작용 부착).
- 기존 테스트씬(InteriorSystemsTest 등)은 자체 시딩 사용 — 무영향 확인. 세이브: 건설 상태 영속은 기존 건설 세이브 체계 연동 확인.

## R4 — 테스트
- GuardDailyWorkTests: 사이클 트리거/수확량 산식/저장고 적립(warehouse 위임)/사망 판정(확률 주입)/게이트(저장고 부재 배치 거부).
- 빈 실내: 신규 영지 실내에 스테이션/저장고 부재 확인 테스트(자동 부착 제거 회귀 방지).
- baseline 11건 1:1 유지.

## Play 게이트(별도 승인)
①메인씬 영지 실내 — 빈 상태 진입 ②건설 관리 UI로 저장고+크래프트 시설 실내 건설 ③병사배치 — 저장고 전 배치 거부 토스트 ④저장고 후 배치 → 낮 시작 시 원정 가시(이동/작업/귀환) ⑤저장고에 수확물 적립 확인(창고 UI) ⑥사냥 병사 저확률 사망 ⑦플레이어 직접 수확 기존 동작 회귀 확인.
