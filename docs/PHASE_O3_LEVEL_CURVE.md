# Phase O3 — 레벨 곡선 분석 (C-O3-01 실측) + 재배율 (C-O3-02)

> **참조:** docs/reference/openmmo/LEVEL_CURVE.md (목표 페이스 꺾은선: (2,5분)(10,22분)(30,5.5h)(50,8h), K=100/h, 사냥감XP=L²+2L−5)

## 1. 현재 활성 XP 계통 (실측)

| 계통 | 공식 | 상태 |
|:-----|:-----|:-----|
| 플레이어 커브 | L2~10 표(100→3,700, 누적 13,850), L11+ 증가 4000+(i−9)×1000 | ✅ 활성 (PlayerStats.GetExpForLevel) |
| 플레이어 킬 XP | baseExp(티어, 기본15) × (1+0.1L) × rand(0.8~1.2) — **선형** | ✅ 활성 (AnimalAI.Die) |
| 병사 킬 XP | **고정 15**/킬, 레벨업 필요 = level×50 | ✅ 활성 (GuardPlaceholder.AddEXP) |
| 병사 정적 커브 | 100×1.2^(L−1), HP 10+10(L−1) | ⚠️ **미사용 유령** (GuardLevelSystem) |
| 몬스터 정적 커브 | 5+2L 선형, HP 티어×L | ⚠️ **미사용 유령** (MonsterLevelSystem.CalculateXP 소비자 0) |

## 2. 문제 진단 (수치)

| 레벨 | 플레이어 필요(증가) | 킬 XP(현재 선형) | 킬 수 | 벤치마크 사냥감 XP(L²+2L−5) | 킬 수(벤치) |
|:----:|:-------------------:|:----------------:|:-----:|:---------------------------:|:-----------:|
| 10→11 | 5,000 | 30 | 167 | 115 | 43 |
| 20→21 | 19,000 | 55 | 345 | 435 | 44 |
| 30→31 | 25,000 | 75 | 333 | 955 | 26 |
| 40→41 | 35,000 | 90 | 389 | 1,675 | 21 |

- 선형 킬 XP → 레벨이 오를수록 킬 수가 정체/증가 → **후반 파밍 벽**
- 병사 고정 15 XP → 병사 Lv30 레벨업에 100킬 (벽)
- 몬스터/병사 정적 커브는 유령 코드 — 실계통과 불일치

## 3. 재배율 설계 (C-O3-02)

1. **사냥감 XP = 벤치마크 2차 곡선 채택**: MonsterLevelSystem.CalculateXP(L) = L²+2L−5 (L≤2: 2/5 폴백) — 유령 함수를 단일 소스로 승격
2. **플레이어 킬 XP**: CalculateXP(L) × (GetExpBase(티어)/15) × rand(0.8~1.2) — 기존 티어 표 보존, 선형 배율 제거
3. **병사 킬 XP**: 고정 15 → CalculateGuardKillXP(targetLevel) = max(5, CalculateXP(L)/3) (병사 1/3 지분) — MonsterLevelSystem에 헬퍼 추가
4. **플레이어 커브**: 기존 표 유지 (2차 사냥감 XP와 결합 시 목표 밴드 진입 — 위 표 "킬 수(벤치)" 열)

## 4. 목표 페이스 (포이즌 단일인 기준 — K≈60킬/h 가정)

| 구간 | 레벨당 시간 | 근거 |
|:-----|:-----------|:-----|
| Lv1~10 | 3~5분 | 기존 표 유지 — 초반 성취 |
| Lv10~20 | 10~20분 | 링1→링2 진행 |
| Lv20~30 | 20~45분 | 링3 — L30→31 ≈ 26킬 |
| Lv30~40 | 30~60분 | 링4 — L40→41 ≈ 21킬 |
| Lv40~50 | 60~120분 | 황제국 — 최종목표 완주 20~30h |

## 5. 영향 범위
- 플레이어 킬 XP 대폭 상승(중후반) → 레벨 페이스 단축 → 컨텐츠 소비 가속 — C-O3-04에서 실측 후 보정
- 병사 레벨업 가속 — 부대 전투력 성장 속도 상승 (GuardLevelSystem 정적 유령은 유지, 별도 정리는 후속)
