# [125차 후속34] 로비 바닥 주황색 — 진짜 원인 확정 + 수리 계획 (러그 과대 스케일)

## 1. 결론 (사용자 가설 = 정확)

"주황색 타일이 실제 타일보다 위에 깔려서" → **맞음**.
진짜 원인 = `Arena_Fireplace_Rug` — 방 **전체를 덮는 60×60m 순수 주황 평면**이
실제 바닥(오크 판자, y=0) **위(y=0.02)**에 깔려 있음.

- 위치: ArenaInteriorBuilder.BuildFireplace L395-401
- 실측: `GameObject.CreatePrimitive(PrimitiveType.Plane)` — Unity Plane 원본 **10×10m**
  × `localScale(6,1,6)` → **60×60m** (작성자 의도 6m 러그로 추정 — 10m 원본 크기 미반영 실수)
- 색상: `(0.85, 0.4, 0.1)` — 순수 주황 (텍스처 없는 단색 머티리얼)
- 높이: y=0.02 — Floor(y=0) 바로 위 → **오크 판자를 완전히 가림**
- 방 크기 대조: 45.6×61.3m(2,797m²) < 러그 60×60m(3,600m²) — 방보다 큼

## 2. 다각도 증거

### 각도 1 — 스크린샷 판독 (아레나 실내2.PNG, 00:19)
- 주황면 = 화면 85~90%+, **단색·무패턴(타일 격자/판자 결 없음)·경계 없음**
- 중앙 밝고 외곽 어두운 그라데이션 = 포인트라이트 감쇠
- → 텍스처 바닥(Floor/Ground)이 아니라 **단색 대형 평면**이 최상위 가시면이라는 뜻.
  러그(단색 무텍스처)와 정확히 정합.

### 각도 2 — Editor.log (00:35 재Play, N1 적용본)
- L2721 `[125차 후속32] 주점 머티리얼 적용 완료 — Floor(오크 판자)+Wall(회반죽 투톤)`
  → Floor에 오크 머티리얼 **실제 적용됨**(배선 무결)
- L2877 `[125차 후속33 N1] 스테이징 리소스 토글 — 실내=True → Ground/StagingLight 비활성`
  → Ground 정리 **정상 작동**
- 그런데도 여전히 주황 → 최상위 가시면은 Ground도 Floor도 아닌 **제3 오브젝트**.

### 각도 3 — 소스 실측 (위 1번 표) + 참조 스캔
- `Arena_Fireplace_Rug` 외부 참조 0건 — 스케일 수정의 영향 범위 = 렌더링만.
- 같은 빌더 내 대형 Plane은 이 1개뿐(L396 유일).

### 각도 4 — 치수 대조
- 굴뚝(원형 돌) 지름 5.4m(r=2.7) — 러그 60×60m는 그 **~100배 면적**.
- "러그 평면 데칼" 주석과 실제 크기 모순 — 스케일 버그 확정.

### 각도 5 — 시간축 (후속33 진단 정정)
- 러그 y=0.02 > Ground y=0 → **러그가 항상 위**. 첫 스크린샷(00:19)의 주황도
  사실상 러그였을 가능성이 큼.
- 후속33 Ground 진단: **진짜 결함**(Floor와 동평면 경합 — z-fighting/가림 위험)을
  잡은 유효한 위생 수정이지만, **가시 주황의 원인은 아니었음** → 오진 정정.

## 3. 수리 계획

### O1 — 러그 스케일 축소 (근본 수리)
- 파일: Assets/Scripts/Systems/ArenaInteriorBuilder.cs L400
- 변경: `localScale = new Vector3(6f, 1f, 6f)` → `new Vector3(0.6f, 1f, 0.6f)`
- 결과: 10m 원본 × 0.6 = **6×6m 러그** — 굴뚝(지름 5.4m)을 감싸는 적정 크기.
- 주황색 자체는 유지(주석상 인테리어 의도 "주황 러그"). y=0.02 유지 —
  바닥 위 데칼로 정상 동작.

### O2 — 옵션 (사용자 선택 가능)
- O1a(기본): 6×6m 주황 러그 존치 — 굴뚝 주변 포인트 인테리어.
- O1b(대안): 러그 삭제 — 바닥 전면 오크 판자 노출. (러그 텍스처링은 GLB 가구 사이클에서 재검토)

### O3 — 부수 결함 발견 (본 사이클 제외, 보고만)
- ArenaInteriorBuilder L118-123 `AddWearStamps` 좌표 6개 중

  마모 스탬프 2장이 방 밖에 배치됨(보이지 않는 이유). 별도 사이클 정정 후보.
