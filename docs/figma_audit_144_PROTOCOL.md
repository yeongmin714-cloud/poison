# 144차 전 UI Figma 1:1 감사 — 공통 프로토콜 (QA 서브에이전트 필독)

작성: 2026-10-31. 목적: **전 UTK 창을 Figma 진실치와 1:1 대조**하여 괴리를 등급화 기록한다. **코드 수정 일체 금지** (읽기 전용 감사 + 보고서 파일 작성만).

## 1. 진실치 JSON 읽는 법
- 위치: `/mnt/c/Unity/code/docs/figma_truth_144/<batch명>__<id>.json` (인덱스: `_index.json`)
- 필드: `ax/ay`=캔버스 절대좌표, `x/y`=부모 상대좌표, `w/h`=크기, `d`=깊이, `c`=자식 배열
- 스타일 필드: `fills`(색 `#RRGGBB/<colorA>@<paintOpacity>` — **실효 알파 = colorA × paintOpacity**, `@` 생략 시 1.0; 그라디언트 포함), `strokes`+`strokeW`(테두리), `r`(코너반경), `op`(불투명도), `fx`(효과/그림자), `layout`(HORIZONTAL/VERTICAL)+`gap`+`pl/pr/pt/pb`(오토레이아웃 패딩)
- 텍스트 필드: `fontSize`, `font`(패밀리 weight 스타일), `lineH`(행높이 px), `letterSp`, `align`, `text`(본문 앞 60자)
- ⚠ 이 JSON은 nodes API 원본에서 파생 — **색/테두리/코너/폰트 모두 실측값**이다. 유실 항목(arcData/이미지 imageRef)은 판정에서 제외하고 "IMAGE" 표기만 존중.

## 2. 대조 좌표계 계약 (치환 금지)
- **창 박스 = Figma rect × k**, k = min(화면w/1920, 화면h/1080). **내부 요소는 raw Figma px**(스케일은 루트 transform으로 일괄).
- 따라서 **코드 상수(단위 px) ↔ JSON 값(px)을 직접 비교**한다. 코드에서 ×k/÷k 환산해 대조하지 않는다.
- 예외(HUD 계약): HUD/핫바는 Y=화면 하단 고정 앵커(게이지 24px·핫바 12px screen px), X만 Figma 분율. 이 축의 Y 괴리는 계약상 정합으로 판정.
- 월드맵은 패널@0.80 계약(Figma 캔버스 y좌표와 의도적 차이) — 판정 시 주석/계약 근거 확인.

## 3. 판정 5축 (사용자 지정)
1. **그리드**: 칸 수·셀 크기·간격(gap)·열/행 수·정렬
2. **배열**: 요소 순서·위치(ax/ay)·부착 구조(임베드/독립)
3. **여백**: 패딩(pl/pr/pt/pb)·마진·행간 간격
4. **플루언트 스타일**: 배경색+알파(글래스 #161B22@0.80 계약), 코너 r, 테두리(strokes/strokeW), 그림자
5. **폰트**: fontSize, 행높이(lineH), 정렬, 굵기(700=Bold·그 외 Normal 근사), 색

## 4. 등급
- **P0** = 구조 괴리: 요소 누락/미구현, 그리드 체계 불일치(칸수/열수), 존재하지 않아야 할 요소, 배경 완전 상이
- **P1** = 수치 괴리: ≥2px 좌표/크기, 폰트 ≥1pt, 색상·알파 상이, 코너/테두리 상이
- **P2** = 근사 수용: ≤1px(부동소수 반올림권), 굵기 근사(500→Normal 프로젝트 관행)
- **PASS** = 대조 결과 전축 일치 (이것도 명시 기록 — "확인 완료"가 산출물의 절반)

## 5. 규약/주의 (스킬 계약 승계)
- **Figma가 단일 진실** — 게임이 맞춘다. 단 의미색(국가/HP/등급/위험)은 유지 원칙 → 크롬색(배경/패널/테두리)만 괴리로 판정.
- **상호작용 패널**: 142차 B' 사용자 판정 = 피그마 스타일(배경판) 유지가 정답. 배경판 유무는 정합 판정하되 수치는 대조 기록.
- **게이지 어휘**: UTKGaugeStripArc 계약(벡터메시 금지) — 형태 대조만, 구현 방식 강요 금지.
- **데이터 위조 금지**: 코드에 없는 수치를 "아마 그럴 것"으로 기록 금지. 못 찾으면 `grep -rn "상수명" Assets/Scripts/` 로 실측. 상수가 별도 파일(예: `InventoryClusterPanelRegions`, `*Bounds*`, `UTKTheme`)에 있을 수 있음 — 반드시 확인.
- 코드에서 값을 발견 못 하면: ①인라인 리터럴 ②const 필드 ③Regions/Bounds 파일 ④계산식(예: gap 기반 배치식) 순으로 추적하고, 그래도 없으면 "코드 무상수(동적 계산)"로 기록.
- 스크린샷/Play 판정은 본 감사 범위 아님(별도 게이트). **코드↔Figma 대조만**.
- 두 Figma 판본이 있으면(예: 상점 구매 74:4/판매 76:7) 둘 다 대조하고 공통/판본별 차이를 구분 기록.
