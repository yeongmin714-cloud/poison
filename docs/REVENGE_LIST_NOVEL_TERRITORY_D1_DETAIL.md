# 분기 D1 — 유백 대리석 성 상세 설계 (게임 구현용 초안)

> **상태:** 깊이 1단계 상세 설계 / 검토 대기.
> **소속 문서:** 캠페인 분기 트리(`REVENGE_LIST_NOVEL_CAMPAIGN_BRANCHES.md`) §7 분기 D의 첫 하위. 분기 B-b(국경 성, `TERRITORY_Bb_DETAIL.md`) 너머로 진입.
> **작명 주의:** 모든 이름은 **검토용 초안**. 옛 원고(archive) 명부는 **참고 레퍼런스**일 뿐 확정으로 재이식하지 않는다(전면 재시작 후 삭제됨).
> **게임 연계:** 설계 문서. 게임 코드는 승인 후 code agent+QA agent로 구현.

## 1. 진입 조건 & 역할

- **진입 경로:** 분기 B-b(국경 성) → 분기 D를 통해 황제국 세력권 진입. 중앙 황제국이 분열국 경계를 지키는 앞선 요새.
- **역할:** 분열국과 황제국의 경계에서, **옛 국경을 기억하는 지도자 엘레노르(명부 16)** 와 접촉. '땅의 경계가 어떻게 조작됐는지' — 네 방위 분열과 황제국 사이의 국경 진실을 여는 관문.

---

## 2. 영지 정체성

| 항목 | 내용 (초안) |
|---|---|
| 인게임 이름 | 유백 대리석 성 (초안) / Territory ID: `terr_marble_border` (Ring 3~4) |
| 위치/링 | 설원 서쪽 끝과 황제국 대리석 고원이 만나는 국경 |
| 지형/기후 | 하얀 대리석 성벽, 설원 바람과 고원의 건조가 섞임. 경계석이 늘어선 황량한 완충지 |
| 문화/생활 | 황제국 명목의 지배 아래, 분열국과의 교류·마찰이 사는 접경. 주민은 이름보다 '지번(地番)'으로 불림 — 땅의 경계가 곧 신분 |
| 성 구조 | 대리석 성문(중앙 수비) → 성벽 안 경계민 취락 → 기록 겐트 → 지도실(엘레노르) → 고원으로 가는 성문 |

**설계 초점:** 이 영지는 "땅이 누구의 것인가"가 테마다. 명목상 황제국이지만, 네 방위로 갈린 뒤 경계가 잦은 뒤바뀜을 겪음. 국경의 '경계석'이 조작/이동했다는 단서를 아렌이 엘레노르의 지도와 대조한다.

---

## 3. 인물

- **명부 인물 16 · 엘레노르 (초안):** 옛 국경을 그린 지도자. 대리석 성의 지도실에서 현재 경계와 옛 경계를 대조하는 기록을 만듦. 명단 '황실 목록을 위조한 자'.
- **경계민 두령 (초안):** 경계석 이동에 따라 자기 땅을 잃었다고 주장하는 주민 대표.
- **중앙 수비대장 (초안):** 황제국 명목을 지키는 수비대장. 국경 진실을 은폐하려는 이해관계.

---

## 4. 복수명부 단서 (명부 인물 16 · 엘레노르)

**단서:** 경계석 이동 + 엘레노르의 옛 국경 지도 → 현재 '공식 경계'가 옛 땅의 경계와 어떻게 다른지. 국경 진실이 명부 인물 16의 존재·위치를 드러냄.

| 증거 | 종류 | 확실성 |
|---|---|---|
| 옛/현 국경 지도 대조 | 문서(물증) | 확실 |
| 경계민 두령 증언 (땅 상실) | 증언 | 중·높음 |
| 중앙 수비대의 이동 경계석 기록 | 문서 | 중 (은폐 위조 가능) |

**교차:** 엘레노르 지도 ↔ 국경 성(Bb)의 국경 기록·분기 A-b(서부 상권) 거래 기록 → 땅 경계 조작의 전모.

---

## 5. 메인 목표 — 「옮겨진 경계석」 (초안 ID `AQ_Marble_Border`)

### 액트 (간결)
1. 대리석 성 진입 — 성문과 경계민 취락을 둘러보며 경계 미무의 징후 확인.
2. 엘레노르의 지도실 접근(협조/침입/우회 분기).
3. 해결 분기:
   - **D1-a (지도 대조):** 엘레노르를 설득해 옛·현 지도를 나란히 펼침 → 국경 조작 전모 확보, 명부 인물 16 수렴. 주민 신뢰.
   - **D1-b (성문 장악):** 국경 성문을 무력으로 장악해 경계 기록 완전 확보 → 중앙 수비대 타격, 경계민 우호. 명부 16 간접.
   - **D1-c (경계민 동맹):** 두령과 손잡아 경계석 이동을 공개 → 황제국 명목이 흔들리고 수도(D2)로 가는 동맹 진출. 명부 16수렴의 대가로 중앙 적대.
4. 점령 후: 대리석 성 통제 → 분기 D2(수도) 진입로 확보, 옛 국경 지도 단서.

---

## 6. 서브 퀘스트

- **「잃은 지번」** (초안): 경계 이동으로 땅을 잃은 가족의 지번 재조사 → 경계민 신뢰, 엘레노르 지도와 대조 자료.
- **「대리석 모서리」** (초안): 성벽에 새겨진 옛 경계 각인 수집 → 국경 진실 물증 강화.

---

## 7. 점령 후 여파 & 하위 연계

- **경계/땅:** 대리석 성 통제로 황제국 진입로 확보. 경계민 신뢰(or 중앙 적대)에 따라 수도 접근 방식 갈림.
- **하위 연계 (이 문턱 넘으면):** 엘레노르(명부 16) 수렴 → `REVENGE_LIST_NOVEL_20TH_STORIES.md` 16 「옛 국경의 지도」. 그리고 **분기 D2(수도 교외)** 로.
- **안 막힘:** 대리석 성을 안 가도, 국경 성(Bb)·수도(D2) 경유로 엘레노르·국경 진실 단서 확보 가능.
