## 1. 영지 정체성

| 항목 | 내용 (초안) |
|---|---|
| 인게임 이름 | 새덕골 요새 (Fallgrain Keep) |
| 위치/링 | 첫 거점(오스릭 요새) 동쪽. 옛 황제국 도로와 곡물 수송로가 만나는 변경 요새 |
| Territory ID (후보) | `terr_fallgrain_keep` (Ring 2) |
| 지형/기후 | 완만한 황색 초원, 성 아래 곡식 창고와 방앗간. 수송로는 좁은 벽돌 다리를 지나 요새로 들어옴 |
| 문화/생활 | 곡물을 키우고 나르는 마을. 주민 대부분이 수송로와 방앗간 생계에 의존. 성 주인보다 "수레가 달리는 길"을 더 신경 씀 |

## 2. 인물 관계망

### 2.1 영주 노번 (초안)
- 작은 영지를 맡은 귀족. 전쟁 준비로 이웃 트레스티앤보다 먼저 수송로를 선점하려 함.
- 자신이 쓰는 무기가 "병영 도장"이 찍힌 유통·반출품이라는 사실은 모르거나 눈감음. 공급자를 건성으로 믿음.
- 아렌에게 "공납·세금을 걷는 주인"으로 보이지만, 궁지에 몰리면 공급자에게 책임을 미룸.

### 2.2 이웃 영주 트레스티앤 (초안)
- 노번의 동쪽 영주. 같은 곡물 수송로를 두고 경쟁.
- 마차 방화를 서로에게 덮어씌우는 구도. 실제 범인(공급자 사내)은 제3자다.

### 2.3 성문지기 잔나 (초안)
- 요새 성문 수비대장. 영주 명령과 병사 봉급 사이에서 흔들림.
- 봉급을 제때 보장하면 문을 열어줄 성향(분기 ② 협상 경로의 핵심 NPC).

### 2.4 마차 수리공 오단 (초안)
- 불탄 마차를 가장 먼저 본 주민. 실종된 견습생을 걱정.
- 견습생이 습격 각도를 목격했을 수 있다는 걸 아는 유일한 인물. → 서브퀘스트 연결.

### 2.5 명부 인물 #(초안) — 무기 대장장이 (참고: 옛 명단 18 '민병을 무장시킨 대장장이' 계열)
- 아렌이 복수명부에서 추적하는 대상 1명.
- 병영에서 무기를 반출해 여러 영지·민병을 무장시킨 인물로 추정. 새덕골에 공급한 중개자를 통해 간접 등장.
- **확정 아님**: 노번과의 관계, 과거 죄목(표면/이면)은 사용자 검토 후 확정. 이 문서에서는 단서로만 존재.

### 2.6 상인/공급자 (측금파 상회, 초안)
- 무기 거래를 주선하는 중간상. 인장이 불탄 마차에서 나옴.
- 아렌과 처음 마주치진 않고, 거래 기록·납표로만 실체가 드러난다.

## 3. 복수명부 단서 설계

**단서 전체 내용:** 노번의 무기고와 불탄 마차에서 → (병영 도장 무기 + 무기상인 거래 인장) → 중개 상회(측금파) → 명부 인물 #(무기 대장장이)의 행방.

| 증거 | 종류 | 확실성 | 게임에서의 표시 |
|---|---|---|---|
| 불탄 마차 화물 파편 | 물증 | 확실(제한) | 조사 시 자동 기록, 화물 명세서 복구로 강화 |
| 무기 거래 인장(측금파) | 물증 | 확실 | "중개 상회가 개입" 확인 |
| 병영 도장 찍힌 무기(반출품) | 물증 | 확실 | "병영 밖 무기 유통" 확인 → 명부 인물 성향과 연결 |
| 무기상인 증언(납표만 앎) | 증언 | 중 | 주선자 미목격 → 후보지가 좁히는 용도 |
| 오단/견습생 목격 | 증언 | 중 | 매복 각도 → 매복조(공급자 사내) 존재 확인 |
| 군중 소문 | 소문 | 낮 | 미화 문자열로만 노출, 단독 증거 아님 |

**원칙:** 단서 하나만으로 위치·유죄를 단정하지 않는다. 모든 물증+증언이 모여야 "명부 인물 #가 이 수송로의 무기 공급망에 관여했을 가능성"으로 좁혀진다. 다른 영지의 목격·동맹 단서와 교차해야 확정에 가까워진다.

## 4. 메인 퀘스트 — 「빈 보급마차」

> 제안 ID: `AQ_Fallgrain_Supply_Ambush` (초안)

### 액트 1 — 진입 (도착)
1. 첫 거점에서 이웃 영지 점령 퀘스트를 받고 동쪽 새덕골에 진입.
2. 성문 밖 수송마차 한 대가 타오르는 현장. 노번측 영주와 트레스티앤측 상인이 현장에서 서로를 습격범으로 지목.
3. 주민들은 "다음 군대가 오기 전에 문을 열까 닫을까"로 갈라져 있음.
4. 퀘스트 갱신: 불탄 마차의 원인과 성문 상황 파악.

### 액트 2 — 조사
5. 성문/곡창고/방앗간 둘러보기. 주민·성문지기 잔나 접촉.
6. 마차 잔해에서 화물 파편·거래 인장 발견 → 무기 거래가 끼어 있었음이 드러남.
7. 마차 수리공 오단이 실종 견습생('레시로')을 찾아 달라 함. → 서브퀘스트 분기점.

### 액트 3 — 전환 (역전)
8. 실종 견습생을 찾거나 흔적을 추적 → 공격은 영주 둘 사이가 아니라 **공급자 쪽의 매복조**가 감행했을 가능성.
9. 성문 밖 초원에서 매복 징후 확인. 무기고 문이 열려 있고 병영 도장 무기가 눈에 띔.
10. 퀘스트 갱신: 점령 방법 3가지 선택지 제시.

### 액트 4 — 해결 (3분기)

**① 무력 점령** (전투 중심)
- 성문 수비대를 정면 무력화 → 요새 장악.
- 무기고를 완전히 뒤져 병영 도장 무기 다수·측금파 거래 기록 확보.
- 결과: 수송로 즉시 개방, 병참 확보. 그러나 트레스티앤은 적대, 주민 일부 불안. 무기 단서 농도 높음.

**② 협상 점령** (대화 중심)
- 성문지기 잔나에게 "병사 봉급·보급 보장" 조건 제시 → 무혈로 성문 개방.
- 노번은 궁지에 몰려 공급자(측금파)에게 책임을 "미루는" 대사를 함 → 중개 상회 이름 노출.
- 결과: 인명 피해 최소, 주민 신뢰 유지. 무기고는 소규모 조사만 가능 → 단서 중간 농도. 트레스티앤은 관망/협상 태세.

**③ 매복 격퇴** (조사·전투 혼합)
- 매복조를 역으로 쳐서 공급자 쪽 사내 일부를 포로로 잡음.
- 포로/증언으로 무기 공급 경로와 이동 방향 확보 → 명부 인물 행방 후보가 명확.
- 결과: 가장 정확한 단서 농도 높음. 다만 노번·트레스티앤은 여전히 대치 상태로 남아 뒤처리 필요.

### 액트 5 — 점령 후
- 새 깃발과 함께 수송로가 아렌의 통제 아래 열림. 병참 개선, 마을은 곡물 유통 재개.
- 점령 방법에 따라 반응 상이: ① 트레스티앤 보복 위협 / ② 관망·동맹 여지 / ③ 두 영주 다 아렌을 경계.
- 무기고/기록에서 얻은 단서 → 다른 영지의 명부 단서와 교차할 수 있음을 연속성 노트에 표시.

## 5. 서브 퀘스트

### 5.1 「사라진 견습생」 (초안 ID `SQ_Apprentice_Lost`)
- 의뢰인: 마차 수리공 오단. 실종 견습생 **레시로** 수색.
- 진행: 초원 매복지·방앗간·마을 회관을 뒤져 흔적(찢긴 견습생 앞치마, 각인 망치) 발견.
- 결과: 레시로가 습격 각도를 목격했음을 확인(생존 시 증언 / 사망 시 남긴 표시).
- 보상/연계: 메인 액트 4 ③(매복 격퇴) 접근로 힌트, 주민 평판 상승.

### 5.2 「성문지기의 봉급」 (초안 ID `SQ_Gatekeeper_Salary`)
- 의뢰인: 성문지기 잔나. 병사 봉급 미지급 문제.
- 진행: 관리책상/세금 문서 확인 → 노번이 봉급을 빼돌렸거나 공급자에게 대고 지불 미룸.
- 결과: 봉급 보장 협상 성공 시 메인 ②(협상) 무혈 통과 또는 합류. 실패 시 전투로 전환.
- 보상: 성문지기 합류, 병참 문서 정리.

### 5.3 「불탄 화물 명세서」 (초안 ID `SQ_Tally_Recover`)
- 의뢰인: 마을 서기(초안). 타버린 마차 화물 수량을 복구해 달라.
- 진행: 곡창고·상회 기록·가마 증언을 교차 → 무기 거래량·발신지 재구성.
- 결과: 무기 공급 물량과 발신 성근을 단서로 확보 → 명부 인물 후보지 좁히기 강화.
- 보상: 곡물/보급 보너스.

## 부록 A — 선택지별 후속 연계 (A-a / A-b / A-c)

> **태깅 규칙 (캠페인 전체 적용):** 각 영지의 메인 퀘스트 최종 선택지를 알파벳 하위 태그로 붙여, 그 선택이 **뒤의 이야기(후속 영지, 명부 단서 경로, 인물 반응)와 일대일로 연계**되게 한다. 분기 A(새덕골)는 **A-a(무력) / A-b(협상) / A-c(매복격퇴)**. 분기 B·C 등 이후 모든 영지에 동일 체계(`B-a/B-b`, `C-a/C-b`…)를 적용한다.

### A-a — 무력 점령 (전투 중심)
- **점령 직후:** 수송로 즉시 개방·병참 확보. 트레스티앤 적대.
- **명부 단서:** 무기고 완전 조사 → 측금파 거래 기록 다수 → "불탄 마차는 공급망 내부 정리" 가능성. 명부 인물 #(무기 대장장이) 후보지가 **남부 세력권**으로 좁힘.
- **뒤 이야기(연계):** 트레스티앤이 남부 세력권의 이웃 영주와 동맹을 맺고 반격 병력을 모은다.
  - → **다음 목표: 남부 세력권 영지 진격** (트레스티앤 동맹 대응). 명부 단서는 "측금파의 남부 납품처" 추적으로 이어짐.
  - 명부 인물 # 접근: 남부 거래처 경유 = 간접·중간 속도.
- **브랜치 연결:** 이 경로는 분기 C(서부 상권)와는 약하게 얽히고, 남부 영지 신규로 빠진다.

### A-b — 협상 점령 (대화 중심)
- **점령 직후:** 무혈. 주민 신뢰 유지. 노번이 측금파 상회에 책임을 미룸.
- **명부 단서:** 무기고 소규모 조사. 대신 **측금파 상회가 "보복/압박"으로 아렌에게 접근** → 거래 의뢰인 이름 일부를 은밀히 노출. 단서는 중간 농도.
- **뒤 이야기(연계):** 측금파 상회가 아렌을 견제하며 **서쪽 상권**에서 수상한 거래 동향을 보인다.
  - → **다음 목표: 서부 상권 추적** (측금파 뿌리). **분기 C(정미관문)와 직접 교차 지점.**
  - 명부 인물 # 접근: 상회 기록 경유 = 간접·중간 속도.
- **브랜치 연결:** 이 경로는 분기 C(서부 관문)의 용병·거래 단서와 자연스럽게 이어진다.

### A-c — 매복 격퇴 (조사·전투 혼합)
- **점령 직후:** 포로·증언으로 무기 공급 경로 확보. 노번·트레스티앤 양측 다 아렌 경계.
- **명부 단서:** 공급 경로(발신 성근)가 명확 → **명부 인물 #의 실거점 후보가 가장 구체적**. 대신 주민 신뢰·트레스티앤 후속은 뒤처리 필요.
- **뒤 이야기(연계):** 공급 경로를 따라 명부 인물 #의 **숨은 무기고/거점 흔적**이 드러난다.
  - → **다음 목표: 명부 인물 # 실거점 추적(직행)** — 가장 빠르게 명부 진행.
  - 값: 동·북부 접경의 숨은 무기고가 **분기 B(북부 고개)와 얽힐 수 있음**.
- **브랜치 연결:** 이 경로는 분기 B(북부)의 피난민 목격 단서와 교차 가능.

### 캠페인 "안 막힘" 원칙 (재확인)
- 세 선택지 모두 명부 인물 # 추적이 가능하되, **접근 방식·속도·다음 영지가 서로 다르다.**
- 어느 쪽을 골라도 (A-a 남부 / A-b 서부 상권 / A-c 명부 직행) 다음 후보 영지가 반드시 남는다.
- 각 후속 목표에서 다시 하위 선택지(다음 영지의 A-x 체계)가 열려, **선택이 곧 게임 전체의 분기 트리**가 되게 한다.
