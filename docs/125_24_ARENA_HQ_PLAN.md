## Phase 0 — 전제 게이트: 투기장 렌더 뿌리 확정 (착수 조건)

- **근거**: 영상9 실측 — 발광 화염(emission)조차 미렌더 = 렌더 체계 결함이 아직 미해결. 사용자 규약
  "UI장애=신규Phase 전 선행봉합" 준용 — **미가시 뿌리 수리 없이 고품질 작업을 얹지 않는다**.
- **수행**: 에디터 재시작 후 Play → `[125차 후속22 F1] 투기장 렌더 감사` 로그 전문 수집 →
  ①카메라 cullingMask/depth/targetTexture ②ArenaPit_Stage·Apron·WallSeg·TorchFlame의 enabled/layer/셰이더명/bounds
  실측 → 뿌리 수리(예상 후보: 레이어 컬링/카메라 이중/머티리얼 셰이더 무효).
- **완료 판정**: 투기장 화면에 모래 타원+벽 링+발광 횃불이 육안 식별되는 최초 시점.
- **파일**: IndoorSceneTransition.cs (감사 로그 판독 기반 수리) / 예상 수리 1~2파일.

## Part A — 아레나 외부씬(투기장) 고품질화

> 현재: 원시 프리미티브+절차 텍스처(단일 톤), 조명 단순(달빛 0.7+횃불), 품질레이어 부분(마모 8개만).
> 본질: 야외 경기장은 실내 HQ 팩토리(Floor/Wall_Front 매칭형)를 못 쓰므로 **야외 전용 팩토리**를 신설한다.

### A1. ArenaOutdoorMaterialFactory 신설 (핵심 — 최우선)
- **파일**: `Assets/Scripts/Systems/ArenaOutdoorMaterialFactory.cs` (신규) — IndoorMaterialFactory 패턴 준용.
- **공급 규약**: IndoorTextureLoader 파일 존재 시 파일 우선, 없으면 IndoorTextureGenerator 절차 폴백
  (프로젝트 기존 규약 — IndoorTextureLoader.HasFiles 게이트 동일 사용).
- **머티리얼 4종**:
  1. 모래(모래타원): 노이즈 모래 텍스처+노멀맵(_BumpMap) — 격자 제거(현재 GenerateFloorTile 격자를 모래에 쓰는 것 교체)
  2. 에이프런(보행 띠): 돌판/압축 흙 톤 — 모래와 톤 구분(경기 구역 식별)
  3. 외벽(벽 링/게이트/기둥 공용): 석재 블록 + 국가별 틴트(동국=청/서=금/남=적/북=은/황제=대리석 — NationColor 계약)
  4. 왕가 박스: 대리석/금장 톤(왕가 대비)
- **연결점**: ArenaPitInteriorBuilder — CreateSandFloor/CreateApron/ResolveWallMaterial 교체 호출 4~5곳.
- **검증**: 컴파일 0 / ArenaInteriorTests 기존 계약 무손상(이름·카운트 계약 유지) / Play — 모래와 벽 톤 구분 식별.

### A2. 품질레이어 확장 — IndoorQualityLayers 재사용 (API 실측 완료)
- **벽 톱 캡**: `AddBoxCap`으로 48세그먼트 각 벽 톱에 캡(게이트 제외) — 탑다운에서 벽 실루엣 링 명확화
  (성 내부 "벽톱면캡" 계약 이식). 기존 게이트 인방 캡 7개와 톤 통일.
- **블롭 섀도우**: `AddBlobAt` — 기둥 12+게이트 기둥 12+왕가 박스+배치구역 프롭 6개 = ~31개(성 내부 블롭섀도우 선례).
- **마모 확장**: `AddWearStamps` — 기존 8개 유지 + ①결투 중심 궤적 마모(중앙 반경 3m 원형 분산 6개)
  ②게이트 6곳 발 마모(출입 동선) ③관중석 입구 6곳 마모. 총 ~26개 — 결정론 좌표(재방문 동일 배치 계약).
- **검증**: ArenaQualityLayersTests 계약 갱신(캡 수/마모 수 상수 — 라운드 마커 승계 규약 준용) / Play — 탑다운에서
  벽 링 실루엣+기둥 그림자+마모 식별.

### A3. 관중석(스탠드) 신설 — 과밀 배제형
- **구조**: 외곽 벽 바깥 타원 2단 테이프레이드 링(박스 프리미티브, 단 높이 1.2m/폭 2.4m, 48세그먼트 링 재사용).
  관중 NPC 배치 **없음**(성능+과밀 배제 계약) — 자리 구조+색만.
- **국가색 장식**: 스탠드 상단에 국가색 방패 패널 12개(기둥 각도 재사용) + 북측 왕가석 구역 별색.
- **관중석 횃불**: 스탠드 상단 모서리 12곳 횃불 확장(밤 실루엣 강화 — 후속18 계약 연장).
- **검증**: Play — 관중석 링 2단 실루엣+국가색 패널 식별 / 라이트 총수 상한 유지(횃불 프롭은 발광 재질이라 라이트 추가 0).

### A4. 시간연동 조명 고도화
- **낮**: 태양 방향광 유지+**섀도우 Soft 옵션**(야외 탑다운 깊이감 — 성 내부 섀도우None 계약과 구분, 야외 전용.
  저사양 가드: 기존 품질 게이트 패턴으로 토글 — Balanced=Off/HighSpec=Soft).
- **밤**: 후속19 달빛+후속18 횃불 수치 유지(검증된 값 — 변경 금지) + 스탠드 횃불(호출부만).
- **황혼 틴트**: IsDay 경계 구간 앰비언트 웜 틴트 Lerp(왜곡 금지 — ±10% 이내, 현실감 선호 계약).
- **포그**: 투기장 무포그 유지(후속23 F1 계약) — 이 항목은 **건드리지 않음**.
- **검증**: 낮/밤/황혼 3시점 스크린샷 비교 판독(ffmpeg+vision 프로토콜).

### A5. 디테일 프롭/데칼 (소규모)
- 장애물 6개(바구니/단지/돌)에 HQ 머티리얼(A1 재사용)+블롭 섀도우.
- 결투 마커(중앙 원+출발선) 밝기/톤 보정 — 현재 절차 마커 가시성 실측 후 미세 조정.
- 기둥 상단 국가색 깃발(작은 쿼드, 12곳 — A3와 통합 가능).
- **과밀 금지**: 신규 프롭 총 수 ≤ 30 (계약).

### A6. 후처리(테스트씬 품질 게이트 준용)
- 씬 Volume에 GlobalVolumeProfile.asset(기존 에셋) 부착 — ACES+Bloom(횃불/화염 픽업)+경량 비네트.
- **품질 게이트**: `enum {Balanced, HighSpec}`+`static ActionFeel` 관통 토글 패턴 준용 —
  Bloom/섀도우Soft는 HighSpec 전용, 메인 게임 Balanced 무손상(기존 동작 바이트 보존).
- **검증**: HighSpec Play 스크린샷 — 횃불 블룸 확인 / Balanced — 무변경 확인.

## Part B — 아레나 내부씬(로비) 고품질화

> 현재: HQ 체계 **이미 적용됨**(로그 `HQ 실내 적용 — 방 45.6x8.0x61.3` — Floor/Wall 매칭 성공).
> 남은 것: HQ 적용 상태의 실측 확인 + 기능공간 분리 + 프롭/조명 폴리시.

### B1. HQ 적용 상태 실측 → 격차 수리 (최우선)
- Editor.log에서 `[IndoorMaterialFactory] HQ 머티리얼 적용 완료 — Floor+Wall(석재/회반죽 투톤)` 로그 발생 여부 확인
  (TryCreateWall 실패 시 하부 석재 밴드 누락 상태로 로비 벽이 단색인지 판별).
- 미적용 항목만 수리(팩토리/텍스처 로더 측 — ArenaInteriorBuilder 무수정 원칙).

### B2. 기능공간 독립 계약 (사용자 설계 선호 직접 반영)
- **3존 분리** — 각 존에 바닥 마모+존 틴트+조명 우선권:
  1. 베팅 존(베팅 데스크+베팅관리인): 데스크 전면 발 마모 스트립+금톤 존 틴트
  2. 접수 존(관리자): 대기석 마모+국가색 틴트
  3. 남동 입구 통로: 출입 마모+차가운 톤(경계 안내)
- 존 틴트는 성 내부 존틴트 계약 선례 준용(과채도 금지 — 미세 틴트).
- **검증**: Play — 존 경계가 바닥 톤으로 식별되는지 스크린샷 판독.

### B3. 가구/프롭 폴리시
- 베팅 데스크: 나무 HQ 머티리얼+상단 캡(이미 계약)+황금 장식 라인(국가색).
- 대기 벤치 2~3개(과밀 금지 — 성 내부 가구 밀도 기준), 벽걸이 횃불 4곳(기존 유지+HQ 화염 머티리얼 — CreateEmberUnlit 선례).
- 국가색 현수막 2면(남벽) — 투기장과 시각 연속성.

### B4. 조명 폴리시
- 기존 3등(베팅 데스크·남동 입구·관리인 대기석) 유지 + HQ 웜광(후속22 F2 스킵 대상이 된 2등은 **재도입 금지** —
  빌더 소유 계약 유지, 빌더 측에서 등화 조정).
- 대화카메라(관리인 1.8m 전신 계약) 프레이밍 무손상 — 조명 변경 후 DialogueCamera103Tests 회귀 확인.

### B5. NPC 정합 무손상
- 관리자/베팅관리인 GLB 1.8m 보정·접지·남향 계약 유지 — HQ 작업이 NPC 경로에 접근 금지(파일 분리 원칙).

## 실행 순서·의존성·우선순위

1. **Phase 0** (렌더 뿌리) — 게이트, 승인 즉시 착수 가능
2. **A1 → A2** (머티리얼+품질레이어 — 체감 최대, 서로 결합) → **A3 관중석** → **A4 조명** → **A5 프롭** → **A6 후처리**
3. **Part B는 Part A와 파일 독립(ArenaInteriorBuilder 측)** — A1~A2 완료 후 병렬 착수 가능(단, 동일 라운드에서
   양쪽 동시 편집 시 컴파일 게이트 1회로 묶음 처리)
4. 각 항목 = 독립 Phase/Task — 승인 시 전체 일괄 또는 항목별 선택 승인 모두 가능

## 전역 계약 (파트 공통)

- 탑다운: 천장/존매트/걸레받이 금지, 벽 톱 캡 계약 유지
- 국가색 유지, 과밀 배제(프롭 상한), 현실적 소재(모래/석재/목재 — 사용자 설계 선호)
- 1.8m 캐릭터 계약·NPC 경로 무손상, baseline 11건 1:1, 컴파일 error CS 0
- 검증: 컴파일+EditMode+Play 판별표+프레임/vision 판독, 텔레그램 라운드 보고 병행
