## §11 [134차 E6] 측면 롤 "앞으로만 구르는" 수리 (2026-10-30)

- **판정 근거**: Screenshots/구르기 2.mp4 — 1fps 36프레임 추출 후 6프레임 모자이크 vision 판정: 측면 롤 전 구간에서 **몸 각도 고정 + 서있는 자세로 슬라이드**(스핀/구름 자세 미관측). Editor.log [134차 E5]는 스핀 발화 정상(Left/Right axis ±X, duration 0.50) — 기구는 돌지만 **기하가 틀림**.
- **원리**: 몸이 기존 시선(전방)을 유지한 채 옆으로 미끄러지면, 스핀축(±visual.right)이 진행 방향과 **평행**이 되어 제자리 트위스트로만 보인다 → 사용자 지각 "앞으로만 구르는".
- **수리**: PlayerMovement.StartRoll — Left/Right 롤 발화 시 `_rollDirection`으로 즉시 `LookRotation` 요 스냅(전방/후방 롤은 무수정). 스냅 후 스핀축 ⊥ 진행축 = 옆으로 전복(측면 구르기)으로 판독. E5 스핀+딥웅크림(0.65/1.08)은 그대로 조합.
- **게이트 확인**: 롤 중 루트 회전을 건드리는 다른 경로 전부 게이트 — 이동 조준(L897 `!_isRolling`), 경사 정렬(ApplySlopeAlignment `_isRolling` early-return). 스냅 요가 롤 내내 유지되며 종료 후 자연 이동 회전으로 이어진다.
- **검증**: 컴파일 error CS 0 / EditMode 1721/1710/11 = baseline 1:1(신규 실패 0). Play 재판정 대기(사용자).
