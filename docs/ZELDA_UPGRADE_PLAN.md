# TRACK 1: 젤다풍 지형 다양화

> 목표: 예시 2,13처럼 "여러 지형이 한 월드에 자연스럽게 혼재"하되, **방위별 국가색(동초원/서사막/남화산/북설원/중앙황금)을 최상위에서 유지**하고 그 안에서 BotW 밝은 판타지 분위기(조명·공기)를 달성한다.

## Phase 1A — 방위별 바이옴 (Bioregion) 레이어
> **핵심 원칙:** 방위별 국가색이 지형의 **최상위 아이덴티티**다. 바이옴은 이 색을 **덮지 않고, 각 방위의 컨셉에 맞는 지형 형태(형태·데코·릴리프)로 구체화**한다. 바이옴은 "어떤 색이냐"가 아니라 "그 색이 어떤 세계인지"를 결정한다.

**방위별 컨셉 → 바이옴 매핑 (현재 NationTerrainController tint와 1:1 대응):**

| 방위 | 기존 tint (world pos) | 컨셉 지형 (네이옴이 채울 형태) | 데코 |
|:----:|:-----|:-----|:-----|
| **동 East** (`x+`) | 초록 초원 `(0.20,0.55,0.15)` | 롤링 힐 + 파스텔 초원 + 숲 군락 | 활엽수/버드나무/야생화 |
| **서 West** (`x-`) | 황색 사막 `(0.75,0.65,0.20)` | 메사 단차 + 사막 고원 + 오아시스 | 선인경/머른바위/드문 나무 |
| **남 South** (`z-`) | 홍색 화산 `(0.55,0.15,0.10)` | 협곡 + 용암 광맥(붉은 지면) + 검은 현암 | 용암 균열/현무암 |
| **북 North** (`z+`) | 설원 백색 `(0.93,0.95,0.98)` | 설상 척봉의 빙하 계곡/빙상 | 가문비 설송/빙결 바위 |
| **중앙 Empire** (center) | 황금 `_empireTint` | 평탄 황금 평야(황제국) + 중앙로드 | 기하 배치 중심 |

- **T1A-1** `BiomeRegionMap` 구성: FBM 노이즈 기반 **방위 단위 바이옴 마스크**를 각 방위 구역 안에서 배분(예: 동쪽 내부에서도 숲/초원/언덕이 노이즈로 분포). 방위 전환은 `NationTerrainController.GetNationAtPosition`(736~810줄)을 재사용 — **국가 경계(방위 경계)는 이미 존재함**, 그 안에서 바이옴 변동만 추가.
- **T1A-2** 방위별 지형 형태 주입: 위 표의 바이옴을 `TerrainGenerator.GetHeightAt`에 적용 — 서쪽 사막 메사·남쪽 협곡·북쪽 설산 첨봉·동쪽 초원이 각 방위 구역에서 지배적.
- **T1A-3** 데코 밀도/종류를 방위 바이옴별로: `IdyllicDecoPlacer`에 방위 마스크 반영(동쪽 숲/초원, 서쪽 사막, 북쪽 설송, 남쪽 용암 파편).
- **T1A-4** 방위 경계 크로스페이드(`TerrainTransitionManager` 재사용): 방위가 바뀔 때 색+지형이 부드럽게 전환 — 기존 국가전환 로직에 바이옴 릴리프도 동시 lerp.

> ⚠️ **설계 우선순위:** 색 = 방위 tint(변경 없음), 형태/릴리프/데코 = 방위 바이옴(신규). 색이 덮이지 않으므로 방위별 정체성을 보존하면서 지형 다양성을 달성한다.

## Phase 1B — 지형 드라마(릴리프) 강화
예시의 메사 단차·절벽·계곡 입체감 확보.

- **T1B-1** 메사 레이어 고도화: 35%→지역 따라 40~60%, 급경사 가장자리 stratification(층상 단차) 추가 — `TerrainGenerator` 메사 패스
- **T1B-2** 절벽/계곡: ridged noise 기반 협곡 + 계곡 바닥에 하천/물 흐름, cliff 절벽 기하(teaxture 절벽면) — `TerrainShape`/`TerrainHeightApplier`
- **T1B-3** 고원(Plateau) 바이옴: 200m 평탄 대지+절벽 가장자리(예시2 단차 스타일)
- **T1B-4** 호수: 바이옴 경계 호수평원 강화, 호수 주변 폭포/절벽 연출 — `LakeGenerator` 확장
- **확인**: CC slopeLimit(45°) 초과 구간은 GetHeightAt 평탄화로 보완(writing-plans 개입 없이 결정론)

## Phase 1C — 조명 & 공기(D = Atmospheric) [탑뷰 최적화]
> **프레임:** 현재 **탑다운뷰**이므로 하늘/God Rays/뭉게구름/스카이박스는 화면에 안 보인다 — 해당 항목은 **제외**한다. 대신 탑다운에서 실질적으로 보이는 밝기·그림자·안개·지형 색감만 조정한다.

- **T1C-1** 상장한 태양(Directional Light) 색/강도 튜닝 — BotW 밝은 파스텔 느낌의 **지형 조명**(전반 밝기+채도 확보). Contact Shadows 켜기(GraphicConfigSetup 확인) → 나무/바위/**메사 단차**와 성자 발 그림자가 지면에 뚜렷해져 입체감.
- **T1C-2** **탑다운 공기 원근감(노이즈)**: Exponential fog 색상(담은 하늘색 계열) + density — 링 바깥(원거리 영지/데코)이 살짝 연해져 깊이감. (탑다운에서 멀리 얕아지는 하염 모방)
- **T1C-3** **방위 tint를 BotW 파스텔 방향으로만 미세 보정**(기존 색 배열 유지 — 동=초록, 서=황색, 남=붉은, 북=백색, 중앙=황금). **바이옴이 색을 바꾸지 않음**(형태만 담당). 지형 채도를 자연스럽게 높여 탑다운에서 생동감 확보.
- **T1C-4** 목데이터 오버드로우 방지: 탑뷰는 지형이 화면 대부분 — **프레임 수치 필수 확인**(Contact Shadows/수파 켜지는 비용 감붕).

## Phase 1D — 잔디/초목 품질
- **T1D-1** 잔디 **색 변주**(바이옴별 틴트: 초원 연두, 설산 서리색, 사막 황갈) — `IdyllicGrassCover`+NationTerrain tint에 바이옴 색 오버레이
- **T1D-2** 잔디 밀집/높이: BotW 느낌의 빽빽한 멀칭(정적+동적 균형), 바람 흔들림 강화(Wind Zone)
- **T1D-3** 꽃/야생화: 흰·빨강 점(예시2/7) 패치 밀도 — 이미 꽃밭 있음, **화면 포화 주의**(no over-density 규칙)
- **T1D-4** 지면-잔디 경계 블렌드(지형색 대비 자연스럽게)

## Phase 1E — 성능 & 통합 검증
- **T1E-1** 드로우콜/프레임 수치 확인(RuntimeTerrainChunk), 데코 컬링 150/200m 유지
- **T1E-2** 배치컴파일 error CS=0 선행, Play 눈검증 gate
- **최종 확인**: 예시2~13 요소(메사 단차/절벽 협곡/숲 군락/흙길/호수/꽃밭/설산/사막) 전부 메인씬에서 눈에 띄게 존재

- **T3A-1** 폰트 렌더링 복구: 한글 조합 처리 + 안티앨리어싱 + 텍스트박스 오버플로우 설정 — 안 잘리는 폰트/style (UIStyleManager 공통 fontSize)

## Phase 3B — 2분할 레이아웃
- **T3B-1** 좌측: 아이템 **5열 그리드** 패널(슬롯 시각화 필수 — 현재 그리드 가이드라인 부재)
- **T3B-2** 우측: **캐릭터 프리뷰 + 상태창** 패널(TotK) — 장착 장비 실시간 반영, 발치 고대 원형 패턴, 상태 바(HP/스태미나/버프 아이콘+타이머)
- **T3B-3** 상단: **카테고리 아이콘 탭 바**(검/활/방패/요리/재료/기타) — 선택 탭 강조

## Phase 3C — 슬롯 폴리시
- **T3C-1** 미세 라운드 사각 슬롯, 우하단 수치(공격력/내구도), **장착 뱃지**(칼 아이콘)
- **T3C-2** 선택 상태: **민트 글로우 배경 + 금색 테두리** (포인트 컬러 = 게임 테마 청록)
- **T3C-3** 아이콘: `ProceduralIconGenerator`(카테고리/희귀도) 고해상도 렌더 — 실물 느낌

## Phase 3D — 무기 섹션 & 통합
- **T3D-1** 무기 4종 검 장착/해제 UI(`WeaponEquipManager` 연동) — 장착 슬롯 하이라이트 + 그리드 뱃지 동기화
- **T3D-2** 우측 프리뷰에 장착 무기 표시, 상태/내구도 반영
- **T3D-3** 배경: 반투명 다크 + 금테 + 테마 엔진(UIDesignTheme) 재활용 — 인벤토리 고유 테마

## Phase 3E — 검증
- **T3E-1** `인벤토리 예시` 대비 눈검증: 텍스트 잘림 0, 2분할 정렬, 아이콘 탭, 슬롯 상태, 캐릭터 프리뷰
- **T3E-2** I키 토글·무기 장착/해제·내구도 표시 정상 동작(Play gate)
