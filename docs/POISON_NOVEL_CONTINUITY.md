## v2 리라이팅의 4대 변경 (사용자 지시)

1. **왕비의 주사 이유 = 끝까지 말로 듣지 않는다**: 33장에서 왕자가 조각들(공방의 문장, 샐러맨더·밴시·늑대·미노타우로스의 경의, 신월의 노래 구조, 아버지 장부의 마지막 이름)을 스스로 조립해 깨닫는다(33장 '깨달음'). 35장 어머니의 대답은 "……네." 하나뿐. 명부 마지막 줄은 이름+이면으로 '채워질 뿐' 긋지 않는다.
2. **복수 명부(스무 손)**: 명부 20줄 = 게임 `RevengeReasons[0..19]` 죄목 문자열 원문 사용. 표면 죄목 vs 이면(RevealReason 개념) 이중 구조. 첫 이름은 2부 바렛(증거: 전언), 마지막 줄(20번)은 소설 전용 "왕의 피에 바늘을 넣었다". 부록에 20손 전체 매핑표.
3. **판타지 우주 + 구현 몬스터**: 옛 황제국 = 노래(매료의 향)로 스스로 멸망한 나라, 몬스터 = 노래의 남은 청중, 4방위국 = 노래의 네 소절을 지키는 감옥의 나라. 구현 22종 몬스터(MonsterData.cs)를 아치별 배치(부록 매핑표) — 늑대 '빵' 동료(28장 사망, 명부에 기록), 샐러맨더·밴시·미노타우로스·돌골렘·트롤의 '고개 숙임' 모티프, 그림자암살자=매향회의 그림자.
4. **이영도풍 톤**: 고유명사 운율(스무 손/하얀 매듭/노래의 청중/이름 없는 이슬), 경구 삽입("이름은 값이 되고 값은 칼이 된다"류), 장별 클리프행어, 문서 장치(명부·장부·도감) 중심 서사.

## 미스터리/판타지 규칙 (본문 확정 — 변경 시 본문 동시 수정)

- 저주: 왼팔 손목→목의 검은 실, 신월마다 매듭 1개 자람(12 = 죽음, 절대 시한 — 약으로 진행 못 막음).
- 약물 1개 = 그 신월 통증 제거 + 매듭 1개 '하얀 매듭' 낙인. 하얀 매듭 4개 + 자기 피 + 열두 번째 신월 밤 조향 = 실 전체 절단(완치).
- 조향 완성 순간 첫 향 기화 = 매료의 향(가장 가까이 맡은 자 예속, 무명의 이슬 주인만 면역).
- 무명의 이슬: 살아 있는 피에서만 존재. 왕비의 설계 = 아들의 죽음(처형)을 잠금으로, 아들의 삶(4약물 치료)을 열쇠로.
- 방위국 보물고는 전부 신월 밤 개방(은월화 개화/화산 숨쉼/심연 제단/빙하 숨쉼·미궁).
- 독 명명: '잠자는 이슬'=치명(바렛), '눈 덮인 이슬'=비살 수면(왕국군 진영, 27장). 만티코어 독침 = 청독사 시그니처 재료(19장 획득).
- 명부의 법: "이름은 증거가 있어야 적는다"(아버지의 장부의 법의 어두운 버전). 처리는 왕도가 아닌 각국 법정에 증거를 놓는 방식.
- '이미 지워진 손': 브루겐(실종)·카일로스(시체)·돌벤(사망) — 베스파가 매향회로 명부를 먼저 정리 중(경쟁 레이스 구조).

## 인물 관계 (초안 이름 — 확정 전까지 초안 취급)

- 아르센(왕자·청록 머카랭·17) ↔ 세레나(탈베사 향료 명가, 무명의 이슬 전승자): 주사(서장) → 탑 거절(30장) → 깨달음(33장) → "……네."(35장).
- 발렌 3세: 장부의 왕. 독을 알고 마심(33장 왕자의 깨달음 내 재구성). 장부 마지막 이름 = 아르센.
- 브란트(1군단장): 폭발 탈출 → 4장 사망, 인장+아버지의 장부+저주 유언.
- 베스파(재상·향료원 총괄): 20손 수장(직접 가담 줄). "죽으면 곤란합니다" 모티프 → 서재 조향 → 한 숨의 향 → 예속 → 기록되지 않는 최후(개방).
- 카시엘(백향사): '명을 빌려 쓴' 사람 — 왕의 잔을 따은 손(33장 고백), 지켜라는 자기 지은 명. 34장 재상 손목 → 명부 19줄 기입 → 후일담 백향 공방, "다시 검을 맞대는 날" 개방.
- 로완(마르겐 기사단장→공작)·페르(젊은 기사): 증거를 법정에 놓는 방법의 실행자.
- 이딜리크: 촌장 할로(아버지 장부의 이름), 약초 소녀 미아(완청초·빵 명명자), 늑대 빵(28장 사망, 젊은 늑대 '빵 둘' 후일담).
- 4방위국: 서 세레네(알시온·월그늘·은월 탑), 동 카르만(발가드·이그나르·불의 계곡), 남 탈베사(테오도라·마레노·흰 탑·백섬), 북 드노브(비른·호르텐·만년빙·빙하 미궁).
- 스무 손 20인: 부록 매핑표 참조(2부 1/3부 4/4부 3/5부 4/6부 2/7부 6 분포).
