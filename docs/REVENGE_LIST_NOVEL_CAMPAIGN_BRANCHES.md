# 《독의 이름》 — 캠페인 분기 트리 총람 (v0.1)

> **상태:** 검토 대기. 이 문서는 소설·게임의 **분기 트리 전체 지도**다. 영지 점령 선택이 어떻게 다음 이야기로 이어지는지 한눈에 보여 준다.
> **작명 주의:** 모든 영지명·영주명·NPC명은 **검토용 초안**. 옛 원고(archive) 명부는 **참고 레퍼런스**일 뿐 확정으로 재이식하지 않는다.
> **상세 위치:** 분기 A·B는 각각 `REVENGE_LIST_NOVEL_TERRITORY_{A,B}_DETAIL.md`에 깊이 1단계로 있음. 하위 목표 영지들(아래 ◎ 표시)은 아직 개요만 있고, 이후 같은 깊이로 확장한다.
> **게임 연계:** 설계 문서. 게임 코드는 승인 후 code agent+QA agent로 구현.

---

## 1. 분기 트리 개요

**핵심 원칙:** "메인 스토리 한 줄"이 없다. 첫 거점(오스릭 요새)을 얻은 뒤 열리는 세 영지(분기 A·B·C) 중 **어느 것을 먼저 점령하느냐**가 곧 분기를 정한다. 각 영지의 메인 최종 선택지(하위 태그)는 다시 그 다음 목표를 나눈다.

```
첫 거점 (오스릭 요새)
 └─ 점령 선택 → 3개 영지가 각자의 단서 경로로 열림
     ├─ A 새덕골 요새 (동부·무기 거래)   ──> TERRITORY_A_DETAIL
     ├─ B 창백고개 성 (북부·피난민 목격) ──> TERRITORY_B_DETAIL
     └─ C 정미관문   (서부·용병 계약)   ──> (개요만, 상세 대기)
```

각 영지의 최종 선택이 하위 분기(예: `A-a`)이고, 그 선택이 **다음 목표 영지/단서 경로**를 결정한다. 여러 경로가 후반에 합류/교차하여 전체가 **분기 트리**가 된다.

## 2. 분기 A — 새덕골 요새 「빈 보급마차」

**상세:** `REVENGE_LIST_NOVEL_TERRITORY_A_DETAIL.md` (5액트·부록 A)
**명부 인물 연결:** ◎ 명부 인물 #(무기 대장장이, 참고 옛 명단 마르텐 계열)

| 하위 분기 | 점령 방식 | → 다음 목표 (◎=상세 대기) | 명부 접근 |
|---|---|---|---|
| **A-a** | 무력 점령 | → **◎ 남부 세력권 요새 진격** | 남부 거래처 경유 (간접·중간) |
| **A-b** | 협상 점령 | → **분기 C(정미관문) 서부 상권 교차** | 상회 기록 경유 (간접·중간) |
| **A-c** | 매복 격퇴 | → **◎ 명부 실거점 찾기 (동·북부 접경)** | 가장 빠른 명부 진행 |

### A-a의 다음 — ◎ 남부 세력권 요새 (초안)
- **이름:** 유염 언덕 요새 (초안) — 남부 붉은 대지 권역
- **현 영주:** 트레스티앤이 동맹을 맺은 남부 이웃 영주 (초안)
- **목표:** 트레스티앤의 반격 동맹을 조기 분쇄, 남부 세력권 발판 확보
- **명부 단서:** "측금파의 남부 납품처" 무기 거래 기록 → 명부 인물 #(무기 대장장이) 후보 좁히기
- **상세:** 미확정 (다음 깊이 작업 대상)

### A-c의 다음 — ◎ 명부 실거점 (초안)
- **이름:** 잿빛 무기고 (초안) — 동·북부 접경의 숨은 시설
- **목표:** 명부 인물 #(무기 대장장이)의 실거점/작업장 추적 (분기 C-c와 교차 가능)
- **명부 단서:** 무기 공급망의 최종 발신지 → 명부 인물 # 직면 가능성
- **상세:** 미확정

## 3. 분기 B — 창백고개 성 「눈 위의 세 발자국」

**상세:** `REVENGE_LIST_NOVEL_TERRITORY_B_DETAIL.md` (5액트·부록 B)
**명부 인물 연결:** ◎ 명부 인물 ◎(북부 장군, 참고 옛 명단 에드릭 계열)

| 하위 분기 | 점령 방식 | → 다음 목표 (◎=상세 대기) | 명부 접근 |
|---|---|---|---|
| **B-a** | 포로 석방·사기 꺾기 | → **◎ 남쪽 설원 능선 추적** | 경로 추적 (간접~중간) |
| **B-b** | 피난민 통로 협상 | → **◎ 설원 서쪽/황제국 국경 (분기 D 후보)** | 증언·정세 경유 (간접·느림) |
| **B-c** | 정면 성문 돌파 | → **◎ 명부 직행 은신처** | 가장 빠른 명부 진행 |

### B-a의 다음 — ◎ 남쪽 설원 능선 (초안)
- **이름:** 얼음 능선 성(초안)
- **목표:** 명부 인물 ◎(북부 장군)이 부상자를 호위하며 남긴 경유지 확인
- **명부 단서:** 발자국·붕대·피착 짜투리의 연속 → 이동 경로 특정
- **교차:** 분기 A-c(명부 실거점)의 동·북부 접경과 합류 가능
- **상세:** 미확정

### B-b의 다음 — ◎ 설원 서쪽/황제국 국경 (초안·분기 D 후보)
- **이름:** 회백성 국경 성(초안)
- **목표:** 정착 피난민의 정세 소문을 타고 명부 인물 ◎가 향한 국경 방면 열기
- **명부 단서:** 망명자·공용 물자·국경 통행 기록 → 명부 장군의 최종 행선지
- **상세:** 미확정 (새 분기 D로 확장 후보)

### B-c의 다음 — ◎ 명부 직행 은신처 (초안)
- **이름:** 설원 남단 은신처 (초안)
- **목표:** 돌파 순간 조우한 명부 인물 ◎ 실루엣을 따라 직접 추적
- **명부 단서:** 설원 남단 은신처에서 명부 인물 ◎ 직면 가능성 (조기 명부 진행)
- **상세:** 미확정

## 5. 교차 지점 요약

| 출발 | 교차 대상 | 이유 |
|---|---|---|
| A-b (협상점령) | 분기 C(정미관문) 서부 상권 | 측금파 상회 뿌리·거래 기록 공유 |
| A-c (매복격퇴) | B-a / B-c (동·북부 접경) | 명부 실거점·무기고가 북부 접경과 얽힘 |
| B-a (포로석방) | A-c (명부 실거점) | 남쪽 설원 능선 → 동·북부 접경 합류 |
| B-b (피난민 협상) | 분기 D 후보 (설원 서쪽·황제국 국경) | 피난민 정착 → 국경 정세 확장 |

**캠페인 "안 막힘" 원칙:** 어느 하위 분기를 골라도 다음 후보 영지가 반드시 남는다. 여러 경로가 교차해 전체 분기 트리를 이룬다.

## 6. 다음 확장 우선순위 (검토용)

1. **① 분기 A·B 확정** — 영지명·NPC명·명부 인물(#/◎) 매핑·죄목 확정
2. **◎ 하위 목표 영지 상세** — 유염 언덕 요새(A-a)·잿빛 무기고(A-c)·얼음 능선 성(B-a)·국경 성(B-b)·설원 남단 은신처(B-c)를 차례로 `TERRITORY_{...}_DETAIL.md`로 확장
3. **분기 C 상세 설계** — 정미관문을 A·B 패턴으로(용병 계약 중심) + 하위 태깅
4. **분기 D(설원 서쪽/황제국 국경)** — B-b 경로에서 확장 결정 시 도입
