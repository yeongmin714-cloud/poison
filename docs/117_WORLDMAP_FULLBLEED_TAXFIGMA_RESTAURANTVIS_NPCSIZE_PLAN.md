## R1. 월드맵 풀스크린 (화면 전체 창에 지도)

**판단**: 월드맵은 피그마 패리티 "창"이 아니라 풀스크린 오버레이 — 등배수 예외를 명시하고 창을 루트 전체로(사용자 지시 우선).

파일: `Assets/Scripts/UI/Toolkit/WorldMapWindowUTK.cs` (부모 직접 — 대형 UI 재구성은 위임 사망 클래스)

1. **창 박스 = 루트 전체**: `ApplyCanvasBounds`를 등배수 ApplyDesignSpace에서 **비등비 100% 채움**(left/top=0, width=rootW, height=rootH)로 교체 — E2의 하단 99px 노출 소멸. `_content`도 창과 동일 크기(scale 1.0, raw 폐기). [117차 R1] 마커
2. **지도 = 창 전체**: `_mapCanvas`를 flow(flexGrow)에서 **Position.Absolute + inset 0**(left/top/right/bottom=0)로 전환 — 지도가 창 전체를 채움. E1의 상단 36.8% 빈 공간 소멸. 배경 신축(100%×100%) 유지.
3. **HUD 요소 = 지도 위 오버레이**: legend / hudRow(현재 위치+좌표) / 나침반(696,168 → 우상단 기준 재배치)을 모두 absolute 오버레이로 전환(pickingMode.Ignore 유지 — 마커 클릭 방해 금지).
4. **마커 좌표계 무변경**: 마커는 캔버스 기준 %(left=u·100%, top=(1−v)·100%) — 캔버스가 창 전체가 되어도 자동 정합. span 3200(안 A) 유지.
5. **진단 로그**: 개방 시 `_mapCanvas.worldBound` + 루트 크기 로그 1회 — Play에서 "캔버스=창 전체" 판정 근거.
6. **테스트 갱신**: WorldMapSceneWiringTests 및 116차 주석(`등배수 계약` 문구)을 신계약으로 갱신 — 소멸 예정 문자열 목록 동봉(92차 교훈).
