# 205차 계획 — 전투 FX·말·인벤 8건 (사용자 지시 11-27)

> 사용자 지시 원문: "일단 활 애니메이션이 플레이어 활쏘기 애니메이션으로 교체가 아직 안되었어 / 화살이 조준선 방향으로 나가지고 않아 / 창으로 휘두르기시 두번의 휘두르기 모두에 타격이 들어가야해 지금은 첫번째만 들어가 / 패링시 여전히 청백색 화면 흰색으로 바뀌게 해줘 / 폭탄 부족시 따로 알림 안떠도 괜찮고 / 폭탄 던질시 vfx를 좀 더 고품질화 시키고 싶어 / 말은 여전히 찌그러진채 나와서 정상적으로 나오게 해주고 / 테스트10 인벤창에 안장 추가해줘"
> 본 문서는 계획만 포함(구현 미착수). 실행은 사용자 "진행" 승인 후.

## 공통 근거 (부모 실측 완료)

- **활쏘기**: 195차 BowRigFix195가 "FBX 4종 Generic→Humanoid + 모션 원본 교정 2건" 적용 상태 — 그런데도 미교체 재보고. 195차 내부 교정 범위(ArcheryShot 모션 GUID·아바타 바인딩) 재실측 필요. 트리거는 발화됨(195차 로그 11회 정합).
- **화살 방향**: 발사 메커니즘 산술 정상(195차 — 22발 전부 총구→커서월드점 일치) + 조준선 Y플립 수식 단일화 완료(무번호 176 — BowAimAlignmentTests 핀). 정적 소거 소진 → Play 실측 영역.
- **창 2연타**: 무번호 176이 2클릭 분리 완료(HumanoidClipDriver MonitorSpearSequence — L1277/L1338 stage1, L1360 stage2 데미지 스트라이크). 그런데도 "첫번째만 타격" 재보고 → 세그먼트2 발화 경로 재실측 필요.
- **패막 색**: FXPalette.ParryWhite = **이미 순백(1,1,1,0.85)**(171차 §6 사용자 확정). 무번호 176이 크로매틱 수차(RGB 프린지) 철수 완료 — 그런데도 청백 체감 → 잔여 왜곡 경로(ParryFlashFader 색 배정·ScreenVignetteFX 블렌드·라이트/블룸) 전수 실측 필요.
- **폭탄 부족 알림**: BombArmController L158 `PlayerNotify.Notify($"{item.displayName} 없음 — 인벤에서 확보 필요")` — 이 1행이 알림. 무장 거부 자체는 유지.
- **폭탄 VFX 현황**: 절차 구형+GLB 자식 · 빨간 폭발범위 텔레그래프 링+내부 필 · 착지 링 sin 펄스(2Hz) · 폭발 스파크(BombExplosionVisual) · SFX · 히트스톱 0.05s · 셰이크(193차 핀 14건 유지 중).
- **말 찌그러짐 (GLB 축별 실측 완료)**: 백마 dim(x,y,z)=[0.341, 0.74, 1.003] · 적토마 [0.345, 0.756, 1.002] · 황마 [0.338, 0.76, 1.004] — **비균일 노드 스케일 0건 · root 스케일 1:1:1**. 찌그러짐 근원 = uniform 스케일로 해소 불가한 **모델 비율 자체**(체고/체장 0.74~0.76 — 실제 말 표준 0.62~0.66 대비 다리 짧음·몸통 압축 체감). 195차 bounds 균일 정규화(체장 2.3m)는 정상 동작.
- **Test_10 지급 선례**: TestTerritoryCombatSetup L121 — `bombInv.AddItem(PlayerInventory.Bomb_Explosive, 3)` 동일 패턴에 안장 1줄 추가 가능. (204차 월드 안장 바구니 병존 상태)

## Phase 분해 (구현 서브에이전트 위임 — 소형 순차 → 수리 → 신설)

- **수리**: 원샷 교정 스크립트(BowRigFix195 확장/신설) — 모션 원본·아바타·클립 길이 3점 교정
- **범위**: 에디터 스크립트 1건 + Player_AC.controller(YAML 핀) + 계약 갱신(BowClipRig195Tests 유지)
- **완료 기준**: ArcheryShot 모션=플레이어 활쏘기 귀속 핀 + Humanoid 리타깃 계약 GREEN / Play: 당김→발사 동작 재생

### P2 — 화살 조준 3자 정합 (검증 강화 — 수리는 실측 후)
- **에디터 고립 프로브**: 조준선 오버레이 패널좌표 → ScreenPointToRay → 예상 착탄점 vs 화살 초기속도 방향 일치 실측(수식 단일화 이후 상태 검증)
- **Play 게이트 후**: 사용자 Play 영상 프레임 실측(ffmpeg+vision — 사용자 워크플로) → 미정합 시 수식 트림. 중력 0.15 착탄 하강(~3cm@20m) 무시 수준 확인 포함
- **완료 기준**: 조준선=커서=착탄 3자 일치 실증(영상 프레임) — 정적 소거 소진 상태에서 유일한 잔여 검증선

### P6 — 폭탄 투척 VFX 고품질화
- **설계(절차 기반 — 프로젝트 패턴 FXPalette·파티클, 신규 에셋 불필요)**:
  ①투척 트레일 — 비행 중 연기+불꽃 스파크(폭탄 자식 파티클, 초저비용)
  ②폭발 다단 — 플래시 퀵(0.05s 과노출) → 화구(스케일 펄스 0.15s) → 스파크 버스트 → 충격 링(ShockwaveRingFX 재사용) → 연기 페이드(~1.2s)
- **계약 유지**: 빨간 텔레그래프·착지 링 펄스·히트스톱 0.05s·셰이크·SFX·대미지 단일소스(193차 핀 14건) 무손상
- **범위**: BombArmController.cs + BombExplosionVisual(신설/확장) + 계약 신설(다단 구성+기존 핀 무손상)

### P7 — 말 찌그러짐 정상화 (비율 보정)

- **범위**: HorseMountSystem.cs + 계약 갱신
- **완료 기준**: 체장 2.3m + 체고 비율 핀 GREEN / Play 스크린샷 대조 후 비율 트림(사용자 관찰 대기)
