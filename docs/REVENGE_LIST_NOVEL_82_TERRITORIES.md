# 《독의 이름》 — 영지별 지역 설계 (분기 A/B/C — 1차)

> **상태:** 초안 / 사용자 검토 대기.
> **설계 원칙:** 메인 스토리 한 줄이 없다. 플레이어가 어느 영지를 **먼저 점령하느냐**가 곧 분기다. 아래 세 영지는 서로 독립된 지역 이야기·명부 단서 경로를 가지며, 어느 쪽을 먼저 가도 캠페인이 막히지 않도록 대체 경로를 둔다.
> **작명 주의:** 모든 영지명·영주명·명부 인물 매핑은 **검토용 초안**이다. 옛 원고(archive/novel-reset-20261004-222644/)의 20명/82영지 설정은 **참고 레퍼런스**일 뿐 확정으로 재이식하지 않는다. 사용자가 확정하기 전에는 정사로 취급하지 않는다.
> **게임 연계:** 이 문서는 설계 제안이며, 게임 코드(Territory ID·퀘스트 정의)는 수정하지 않았다.
> 세 영지의 상세 항목은 `REVENGE_LIST_NOVEL_BRANCH_OUTLINE.md` §5의 80영지 설계 표준을 따른다.

## 분기 A — 동부 변경 요새 「빈 보급마차」

**배치:** 첫 거점(오스릭 요새)의 동쪽, 옛 황제국 도로와 곡물 수송로가 만나는 변경.

| 항목 | 내용 (초안) |
|---|---|
| 영지 ID / 지역 / 링 | 동부 변경 / Ring 2 (초안 ID 미확정) |
| 영지명 / 현 영주 | **새덕골 요새(Fallgrain Keep) / 영주 노번(초안)** |
| 독립 목표 | 이웃 동부 영주 **트레스티앤(초안)** 과 곡물 수송로 선점을 놓고 대치. 요새의 수송마차가 불에 타 양측이 서로 먼저 습격했다고 주장. |
| 지역 메인 퀘스트 | 성문을 지키는 영주측 수비대와 대치. 점령 방법 3분기: ① 정면 무력화 ② 성문지기와 협상 ③ 마차를 노린 매복조 먼저 격퇴. 방법에 따라 수비병 일부 합류/이탈. |
| 주민 서브 퀘스트 | 마차 수리공 **오단(초안)** 이 습격 순간을 목격한 실종 견습생을 찾아 달라 한다. 구하면 군대 진입 방향을 알려 주되, 증언은 여전히 미확인 기록. |
| 영주/NPC 서브 퀘스트 | 성문지기가 "영주 노번보다 먼저 병사 봉급을 보장하겠느냐"고 묻는다. 협상 성공 시 성문 무혈 통과, 실패 시 교전. |
| 복수명부 연결 | 불탄 마차의 거래 인장·무기상인 봉인 조각 → **명부 인물 #(초안, 참고: 옛 명단 18 '민병을 무장시킨 대장장이'와 연결 가능성)**. 무기 거래 관여 가능성만 시사. |
| 단서 | 물증(거래 인장·봉인) + 증언(상인은 납표만 앎, 주선자 미목격). 위치·유죄 확정 아님. |
| 점령 후 결과 | 수송로 열림 → 병참 개선. 거래에 손해 본 이웃 영주가 되찾으려 사절/병력 파견. |
| 대체 경로 | 이 영지를 먼저 안 가도, 다른 영지의 동맹·목격 단서로 같은 명부 인물 후보지를 좁힐 수 있다. |

## 분기 B — 북부 고개 요새 「눈 위의 세 발자국」

**배치:** 첫 거점의 북쪽, 설원으로 통하는 유일한 고개.

| 항목 | 내용 (초안) |
|---|---|
| 영지 ID / 지역 / 링 | 북부 고개 / Ring 2 (초안 ID 미확정) |
| 영지명 / 현 영주 | **창백고개 성(Bleak Pass) / 영주 하렌(초안)** |
| 독립 목표 | 영주 하렌이 피난민을 "적군 첩자일 수 있다"며 문을 걸어 잠갔다. 국경수비대는 명령을 따를지 주민을 몰래 통과시킬지 갈등. |
| 지역 메인 퀘스트 | 고개 수비대와 대치. ① 포로를 풀어 수비대 사기 꺾기 ② 피난민 안전 통로 확보 ③ 정면 성문 돌파. 선택에 따라 생존 수비병·주민 태도 변화. |
| 주민 서브 퀘스트 | 길을 잃은 정찰병 수색 + 설한에 갇힌 가족 호위. 성공 시 고개 너머 순찰 간격 → 점령전 접근로. |
| 영주/NPC 서브 퀘스트 | 수비대장 **베드리아(초안)** 가 명령과 양심 사이에서 아렌과 협상. 피난민을 받아들이는 조건으로 문을 열 수도 있음. |
| 복수명부 연결 | 피난민 목격: 명부 인물로 추정되는 지휘관이 눈보라 속에서 부상자 호위, 남쪽 고개로 향함 → **명부 인물 #(초안, 참고: 옛 명단 2 '북부 장군'과 연결 가능성)**. 신원·망토 색·호위 숫자 미확정. |
| 단서 | 증언(목격자 1명, 기억 엇갈림). 물증 부재. 위치 후보만 제시. |
| 점령 후 결과 | 피난민 수용 → 인구·정보원 증가 + 식량 부담. 내쫓을 시 점령은 쉬우나 주민 신뢰 상실, 일부 병사 이탈. |
| 대체 경로 | 이 고개를 먼저 안 가도, 전쟁 현장 증언/동맹 단서를 다른 영지에서 얻을 수 있음. |

## 분기 C — 서부 관문 영지 「대가를 치른 창끝」

**배치:** 첫 거점의 서쪽, 상인 통행이 잦은 관문 도시.

| 항목 | 내용 (초안) |
|---|---|
| 영지 ID / 지역 / 링 | 서부 관문 / Ring 2 (초안 ID 미확정) |
| 영지명 / 현 영주 | **정미관문(Grain Gate) / 영주 살리자르(초안)** |
| 독립 목표 | 현지 영주가 용병대를 고용해 관문을 장악. 용병대장 **코디악(초안)** 이 "계약 끝났다"고 주장하나 영주는 미지불. 상인 통행 막힘, 양측 서로 배신자 호칭. |
| 지역 메인 퀘스트 | ① 용병대장에게 더 나은 계약 제안 ② 영주 보급 끊기 ③ 양측 충돌 틈 관문 공격. 협상 시 용병 일부 편입, 정면 공격 시 손실·적대감 증가. |
| 주민 서브 퀘스트 | 상인의 빼앗긴 수레 회수. 용병 출신 대장장이가 버려진 장비 회수 의뢰 → 거래 당사자·병사 설명을 다르게 들어볼 수 있음. |
| 영주/NPC 서브 퀘스트 | 영주 살리자르가 "용병값을 치러줄 방법"을 제시하거나, 코디악이 임금 대신 자유를 원함. 선택에 따라 동맹/적 형성. |
| 복수명부 연결 | 용병 계약 인장과 특정 명부 인물의 사절이 남긴 표식 일치 → **명부 인물 #(초안, 참고: 옛 명단 1 '재무관' 또는 20 '서부 사막 변방'과 연결 가능성)**. 고용주인지 보증인인지 미상, 대장도 의뢰인 미목격. |
| 단서 | 물증(계약 인장·표식) + 증언(코디악 미목격). 동맹·고용 관계만 시사. |
| 점령 후 결과 | 용병 계약 수용 시 즉시 병력 + 봉급 부담. 거절 시 용병이 타 영주에게 고용 → 다음 전쟁에서 적으로 등장 가능. |
| 대체 경로 | 용병·동맹 단서는 다른 영지의 고용 관계/거래 흔적으로도 얻을 수 있음. |

## 세 분기의 연결 원칙 (재확인)

- **A(동부)** 먼저 → 상업·무기 조달 경로로 단서를 좁힌다.
- **B(북부)** 먼저 → 전쟁 현장 목격·피난민 경로로 단서를 좁힌다.
- **C(서부)** 먼저 → 용병 계약·고용 관계로 단서를 좁힌다.
- 각 단서는 **서로 다른 명부 인물**에 연결될 수 있다. 초반부터 한 인물을 모든 분기의 배후로 만들지 않는다.
- 어느 분기를 먼저 가도 다음 후보 영지가 남으며, 수집한 단서에 따라 복수의 후보 영지에 목적을 둘 수 있다. "정답 영지" 하나만 강요하지 않는다.
- 서브 퀘스트는 메인의 유일한 열쇠가 아니다. 생략해도 다른 영지의 목격·동맹·전리품으로 메인 단서를 얻는 대체 경로를 둔다.
