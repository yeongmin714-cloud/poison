## 1. 영지 정체성

| 항목 | 내용 (초안) |
|---|---|
| 인게임 이름 | 창백고개 성 (Bleak Pass) |
| 위치/링 | 첫 거점(오스릭 요새) 북쪽. 설원과 저지대를 잇는 유일한 고개 |
| Territory ID (후보) | `terr_bleak_pass` (Ring 2) |

| 문화/생활 | 설원 주민과 남쪽 상인을 잇는 통행 중심지. 계절이 바뀌면 피난민·군대가 몰려듦. 성문이 잠기면 주민도 곤겨드는 구조 |

## 2. 인물 관계망

### 2.1 영주 하렌 (초안)
- 설원 접경의 영주. 전쟁 소문에 과민해 피난민을 "적의 첩자"로 단정, 고개 성문을 걸어 잠금.
- 공포에 휩쓸려 사실 확인보다 성문 폐쇄를 먼저 택한 인물. 책임을 자기 병사에게 미룸.

### 2.2 수비대장 베드리아 (초안)
- 명령(성문 잠금)과 양심(얻어 죽는 피난민) 사이에서 갈등. 아렌과 협상 가능한 핵심 NPC(분기 B-b 경로).
- 피난민 통과를 몰래 돕자다 적발된 이력 암시.

### 2.3 피난민 두령 이바 (초안)
- 설원에서 도망쳐 온 피난민들을 이끄는 여성. 정보를 앎(수비대 배치·출구) + 강한 필요(생존).
- 아렌에게 협력하지만, 남는 정보는 조건부로만 넘김.

### 2.4 정찰병/부상 가족 (초안)
- 길을 잃은 정찰병, 부상당한 가족. 서브퀘스트 대상. 이들을 구하면 고개 너머 순찰 간격·망토 색 목격이 열림.

### 2.5 명부 인물 ◎(초안) — 북부 장군 (참고: 옛 명단 2 '북부 장군' 계열)
- 아렌이 추적하는 대상 중 한 명. 병력을 이끌지 않고 **부상자를 호위하며 남쪽 고개로** 지나갔다는 목격이 있음.
- **확정 아님**: 분기 A의 무기 대장장이(#)와 별개 인물. 관계·과거(표면 죄목/이면)는 사용자 검토 후 확정.

## 3. 복수명부 단서 설계

**단서 전체 내용:** 피난민의 목격(눈 속 지휘관) → 망토 색·호위 숫자·방향(남쪽 고개) → 명부 인물 ◎(북부 장군)의 이동 경로 후보.

| 증거 | 종류 | 확실성 | 게임에서의 표시 |
|---|---|---|---|
| 피난민 이바의 목격 증언 | 증언 | 중 | 눈 속 얼굴·망토는 미확인, 호위 숫자 엇갈림 |
| 눈 위 세 발자국(실종·함정 자국) | 물증 | 확실(구간적) | 고개를 남쪽으로 나는 지휘관 일행 발자국 |
| 부상자 호위의 고통 표시(피착·붕대 짜투리) | 물증 | 확실 | "부상자 동행" 확인 → 성향과 연결 |
| 수비대 감찰 기록(통과 대장) | 문서 | 중 | 지휘관 행렬이 남긴 흔적, 이름은 비어 있음 |
| 군중 소문 | 소문 | 낮 | 미화 문자열로만 노출 |

**원칙:** 목격 + 물증(발자국·붕대)이 모여야 "명부 인물 ◎가 이 고개를 지나 남쪽으로 향했다"는 후보지가 좁혀진다. 다른 영지의 동맹·거래 단서와 교차해야 확정에 가까워진다.

## 4. 메인 퀘스트 — 「눈 위의 세 발자국」

> 제안 ID: `AQ_Bleak_Pass_Three_Prints` (초안)

### 액트 1 — 진입 (도착)
1. 북쪽 고개에 다다르지만 성문은 잠겨 있고, 문 밖에 얼어붙은 피난민 몇 명이 표류.
2. 영주 하렌이 "적의 첩자"라며 문을 열지 않음. 수비대는 명령 수행에 착실해 보이지 않음.
3. 주민은 "영주가 피난민을 버려 전쟁 소문만 키운다"고 속삭임.
4. 퀘스트 갱신: 고개 상황과 성문 폐쇄의 진상을 파악.

### 액트 2 — 조사
5. 안뜰·창고·천막지대를 둘러보며 이바 등 피난민 접촉.
6. 피난민 이바가 눈 속에서 본 지휘관에 관한 증언(망토 색·방향·호위 숫자 엇갈림) 제공.
7. 정찰병 수색·부상 가족 호위(서브)로 고개 너머 순찰 간격·발자국 단서 확보.
8. 눈 위 세 발자국(지휘관 일행)을 추적 → 남쪽 고개로 이어지는 흔적 확인.

### 액트 3 — 전환 (역전)
9. 성문 폐쇄의 진짜 배후가 "피난민 첩자"가 아니라, 피난민 일행 중 부상자를 호위하던 **지휘관(명부 인물 ◎)** 때문임이 드러날 개연성(지휘관이 영주 하렌과 알던 사이일 수도, 하렌이 그를 숨기려는 것일 수도 — 미확정).
10. 퀘스트 갱신: 점령 방법 3가지 선택지 제시.

### 액트 4 — 해결 (3분기)

**① 포로 석방·사기 꺾기** (전투·심리)
- 수비대장 베드리아가 데려 놓은 포로를 풀거나, 수비대 사기를 꺾는 실마리를 확보 → 성문 혼란 틈 요새 장악.
- 결과: 수비대 일부가 현명한 판단으로 합류. 단서는 남쪽 고개 추적 강화(명부 인물 ◎ 일행과 근접).

**② 피난민 통로 확보·협상** (대화·인도 중심)
- 베드리아와 협상, 피난민을 안전하게 통과시키는 조건 → 성문 개방.
- 이바가 감사의 정보(지휘관이 남긴 발자국·방향의 정확한 위치)를 제공.
- 결과: 인명 구출, 주민 신뢰 최상. 증언(중간) 단서 보존.

**③ 정면 성문 돌파** (전투 중심)
- 고개 성문을 전면 돌파 → 강제 점령.
- 지휘관(명부 인물 ◎) 일행과 곧바로 조우 가능 → 가장 빠른 명부 진행.
- 결과: 주민 신뢰 낮음, 피난민 일부 흩어짐. 전투 중심이라 파병·피해 큼.

### 액트 5 — 점령 후
- 성문이 열리고 설원 통행로가 아렌 통제 아래 개방. 얼어붙었던 생존 피난민이 정착/통과.
- 점령 방식에 따라: ① 수비대 합류·명부 근접 / ② 주민 신뢰·정보 / ③ 명부 빠른 조우 + 주민 불신.
- 눈 위 발자국·붕대 단서 → 다른 영지의 명부 단서와 교차.

## 부록 B — 선택지별 후속 연계 (B-a / B-b / B-c)

> **태깅 규칙:** 분기 A의 부록 A(`A-a/A-b/A-c`)와 동일 체계. 분기 B(창백고개)는 **B-a(포로석방)·B-b(피난민 통로 협상)·B-c(정면 돌파)**. 각 선택이 뒤의 이야기와 일대일로 연계된다.

### B-a — 포로 석방·사기 꺾기 (전투·심리)
- **점령 직후:** 수비대 일부 합류, 성문 장악. 하렌 축출.
- **명부 단서:** 수비대 감찰 기록·포로 진술 → 명부 인물 ◎(북부 장군)이 남쪽 고개로 나는 경로 확인. 단서는 중간~높음.
- **뒤 이야기(연계):** 합류 수비대가 "지휘관이 지휘하지 않고 단독으로 부상자를 챙겼다"는 이례적 증언을 늘어놓는다.
  - → **다음 목표: 남쪽 설원 능선 추적** (명부 인물 ◎ 일행 경유지). 명부 진행 직행성 중간.
  - 명부 인물 ◎ 접근: 경로 추적 = 간접~중간.
- **브랜치 연결:** 이 경로는 남쪽 능선을 따라 **분기 A-c(명부 실거점)** 의 동·북부 접경과 교차 가능.

### B-b — 피난민 통로 확보·협상 (대화·인도 중심)
- **점령 직후:** 무혈, 주민·피난민 신뢰 최상. 베드리아·이바가 아렌 편으로 남음.
- **명부 단서:** 이바의 세부 증언 + 발자국 물증 → 명부 인물 ◎ 방향 확인. 단서는 중간(신뢰 덕에 교차 용이).
- **뒤 이야기(연계):** 피난민이 정착하며 설원 너머의 **망명자·정세 소문**을 전해 온다.
  - → **다음 목표: 설원 서쪽/황제국 국경 인근 영지** (명부 장군이 향한 곳과 정세가 얽힘). 주민 정보망 활용.
  - 명부 인물 ◎ 접근: 증언·정세 경유 = 간접·느림.
- **브랜치 연결:** 이 경로는 설원·황제국 국경 방면으로 새 분기(분기 D 후보)를 연다.

### B-c — 정면 성문 돌파 (전투 중심)
- **점령 직후:** 성문 강제 장악. 주민 신뢰 낮음, 피난민 일부 흩어짐.
- **명부 단서:** 지휘관(명부 인물 ◎) 일행과 곧바로 조우 가능 → **가장 빠른 명부 진행**.
- **뒤 이야기(연계):** 돌파 순간 목격한 지휘관의 실루엣·망토 색이 뒤늦게 교차된다.
  - → **다음 목표: 명부 인물 ◎ 직행 추적** — 설원 남단의 은신처.
  - 값: 신뢰·생존 정보 결손은 뒤처리 필요.
- **브랜치 연결:** 이 경로는 분기 A-c(실거점 직행)와 함께 **조기 명부 집중 루프**를 이룬다.
