# 141차 계획 — 피부/에셋 "깨짐" 정확 분석 + 텍스처 압축 품질 수리계획

작성: 2026-10-30 (141차). 사용자 요청: "이유를 정확히 분석해주고 한번 다시 수정 계획 세워줄것".

## §0 ⭐ 계약 확정 (사용자 지시 141차) — **텍스처 무조건 고품질**
- 환경 분업: **현 데스크톱 = 테스트씬 확인 전용 / 메인씬 판정 = 고사양 데스크톱 전용.**
- 따라서 VRAM 절약을 위한 다운스케일·저품질 압축 절충을 **하지 않는다** — 원본 해상도·고품질 포맷을 그대로 사용.
- 이 계약은 NPC뿐 아니라 GLB 건물/프롭 임베드 텍스처까지 전 에셋에 적용(상시 후처리기로 고정).
- VRAM 절충안(2048 다운스케일 등)은 **폐기** — 더 이상 제안하지 않음.

## §1 분석 — 증거 체인 전체 요약

### 1-1 새 단서가 바꾼 것
1. **"특정 NPC만 깨진다" + "GLB 건물도 일부 깨짐"** → 글로벌 라이팅/셰이딩 원인이 아니라 **에셋(텍스처)별 현상**으로 방향 전환.
2. 측면 스크린샷(npc 얼굴 측면.PNG 14:05) 판정: **미세한 사각형 격자(4×4 블록)로 색상이 단계별로 끊김** — 어두운 면에서 훨씬 심함. 4×4 블록 = **BC1/DXT 압축 아티팩트의 지문**(그림자 아크네는 이런 격자 패턴을 만들지 않는다).

### 1-2 확정 데이터 (임포트 설정 실측)
- NPC base_color 임포트: **원본 4096² → maxSize 2048 (2× 다운스케일) + compressionQuality 50 + 자동 압축(RGB 무알파 → BC1/DXT1)**.
- BC1의 알려진 결함: **어두운 그라데이션 영역에서 4×4 블록 밴딩/노이즈** — 밝은 영역에서는 거의 안 보임.
- 신규 확정(141차): **normal.png가 textureType=Default(색상 취급)로 임포트** → 노멀맵을 sRGB 색으로 해석해 _BumpMap 샘플 오염(부가 결함 — 정상화 필요).
- 이것이 지금까지의 모든 관측을 일관되게 설명한다:
  | 관측 | 설명 |
  |---|---|
  | "특정 NPC만" | 질감이 어둡고 넓은 무난 톤인 캐릭터/건물(큰 평면 암흑 영역)에서 BC1 블록이 도드라짐 |
  | GLB 건물도 | GLB 임베드 텍스처도 동일 임포트 기본값(압축) — 큰 평면 어두운 표면 = 블록 노출 |
  | 내 Unlit 컷이 "청결" | **밝은 톤이라 어두운 영역이 적었을 뿐** — 압축 수리 효과가 아니었음(140차 해석 정정) |
  | 모든 Lit 변형 무효과 | 그림자/노멀맵/메탈릭/프로브는 전부 BC1 블록과 무관 |
  | 얼룩이 "터미네이터 부근" | 명암 경계 = 어두운 그라데이션 시작점 = BC1 밴딩 최악 구간 |

### 1-3 확정 소거 목록 (140차까지)
그림자 맵 아크네(부분), 노멀맵 소스, AO/추가 맵, 메탈릭, UV/알베도(Unlit 검증), 중복 지오메트리(렌더러 1개), 알파 블렌딩(RGB), 노멀 방향성(균일), 탄젠트 불일치(측정 버그 정정).

## §2 수리계획 (무조건 고품질 계약 반영 — 실행 완료 기준 재작성)

### P1 — NPC 텍스처 임포트: 무조건 고품질 (실행)
- 대상: `Assets/Resources/Models/UserProvided/Npc2026/Textures/Npc_*/base_color.png` + `normal.png` 48장.
- base_color(24장): **maxSize 4096(원본 유지, 다운스케일 폐지) + textureFormat BC7 + compressionQuality 100 + mipmap on**.
- normal(24장): **textureType NormalMap + sRGB off + maxSize 4096 + compressionQuality 100**(포맷 자동 BC5 — Default(색상) 임포트 결함 정정).
- 도구: `Assets/Editor/Tools/Npc141TextureQuality.cs` (RunPatch 배치) — [141차 P1/P2] 마커.

### P2 — GLB/FBX 임베드 텍스처 상시 고품질화 (실행)
- `Assets/Editor/Tools/Npc141GlbTextureQualityPostprocessor.cs`: Models/UserProvided 하위 모델 임베드 텍스처에 maxSize 4096 + compressionQuality 100 **상시 적용**(건물/프롭/캐릭터 GLB 전부) — 계약의 영구 이행 장치.
- Npc2026 단독 PNG는 P1 배치 소관(후처리기 제외 — 타입 충돌 방지).

### P3 — receiveShadows 원복 판정
- 140차 수리(receiveShadows=false)는 그림자 아크네 가설의 수리였으나 무효과 판정 → **기본(true) 원복이 원칙**. P1 적용 후 재Play에서 그림자 수신 양쪽 비교 1회 후 최종 결정.

### P4 — 보조 튜닝 (잔존 시 별도 승인)
- 주 라이트 그림자 normalBias 상향(경계 노이즈 보조 완화) — 글로벌 변경이라 최후순위.

## §3 실행 순서
P1(P1/P2 도구 작성+컴파일) → 배치 재임포트(BC7 인코딩 포함, 수 분) → 설정 검증(meta grep) → **사용자 재Play 스크린샷 → 전/후 픽셀 비교(어두운 영역 블록률)** → P3 원복 판정 → 필요 시 P4.

- Play·커밋 별도 승인. "무조건 고품질" 계약 자체는 141차 사용자 지시로 확정(재승인 불필요).
