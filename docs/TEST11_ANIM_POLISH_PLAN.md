## 진단 (실측 확정 3건 + 가설 2건)

### 확정 1 — 다리 체인이 척추를 삼켜서 IK가 척추를 꺾음 (어색함의 본체)
- 매핑 로그: **전 몬스터 `spine=없음, head=없음`** + 2족(미노타우르스) `legs=16개 뼈`
- 원인: FindLimbChains가 발잎에서 위로 거슬러 올라가며 **단일 자식 연쇄를 전부 흡수** — 다리 위쪽 골반·척추 뼈까지 다리 체인에 편입(제한 없음)
- 결과: IK가 척추/골반 뼈를 무릎·발목처럼 구동 → 몸통 후굴·비틀림, 메시 찢어짐/늘어짐(영상 f018 실측: 척추 후방 과신전+사지 스트레칭)
- 부수: SpineWave/HeadLook이 전부 생략 중 → 걷기가 "뼈대만 미끄러지는" 인상

### 확정 2 — 영주 메시 깨짐 (재질 이식 경로)
- 영주 = 병사 lv1-20 **FBX 골격** + `npc_lord_rigged.glb` **재질 복사**(CopyMaterialsFromGlb)
- GLB 본체의 UV 배치/메시 토폴로지는 FBX 골격과 다름 → 텍스처가 UV 미스매치로 뭉개져 "깨진 것처럼" 보임이 유력 (영상 f018 근처 렌더링 잔상과 부합)
- 검증 필요: 재질 복사 OFF(기본 흰색)로 비교 렌더

### 가설 3 — 큰 병사 어깨 움츠러짐 (lv40-50 FBX)
- 후보 ①FBX 리스프포즈 자체가 굽은 자세 ②SoldierShield_AC Idle 클립이 다른 비율 골격(lv40-50)에 리타깃되며 어깨 말림 ③180° 교정 부작용(교정은 상하 반전이라 어깨와 무관할 가능성 높음)
- 검증 필요: Idle OFF(T포즈) 비교 → 모델 고유 vs 클립 문제 분리

## Phase 1 — 체인 흡수 버그 수정 (몬스터 자연스러움의 핵심)
| 항목 | 내용 |
|:--|:--|
| 체인 길이 캡 | 잎→위 탐색을 **최대 4뼈**(Hip/Knee/Ankle/Foot)로 제한 — 골반/척추 흡수 원천 차단 |
| 분기 조기 정지 | 탐색 중 자식 2개 이상 노드(골반) 도달 시 즉시 정지 |
| 척추 재매핑 활성 | 다리 제외 잔여 뼈에서 최장 체인 → Spine0/1/2 + 중심선 위 Neck/Head 복귀(현재 전부 없음) |
| IK 사영 클램프 | Solve 결과 각도 제한 — 체인이 목표에 못 미치면 무리하게 꺾지 않고 목표를 사거리 내로 당김 |
| 진단 로그 | `토폴로지 매핑` 로그에 spine/head 재확인 |

**완료 기준**: 콘솔에 `spine=bone_N, head=bone_M` 복귀 + 악어/미노타우르스 척추 꺾임 소멸 + SpineWave 가동(보행 중 몸통 물결)
