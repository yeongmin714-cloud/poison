## Phase R — 관전 근본 결함 봉합 (최우선 — 모든 시각 작업의 전제)

### R-A. 카메라 (0,0,0) 이동자 근본 수리
- **현황**: Update 페이즈에서 매 프레임 (0,0,0) 기록(락 로그 5회×4부착 실측) — 락이 프레임 말 복구로 증상은 해결.
- **수리**: 범인 특정 — 유력 후보 = ApplyFollowCamera 계열이 파괴/비활성 대상 트랜스폼을 참조(파괴된 Transform.position=(0,0,0) 패턴).
  ①플레이어 재생성/이동 경로에서 구 참조 정리 ②락의 이동자 로그에 프레임 타임스탬프 추가로 1회 역추적 ③범인 분기에 투기장 게이트 추가.
- **완료 판정**: 락 로그의 "이동자 감지"가 0건(락이 있어도 이동 시도 자체가 없음).

### R-B. 플레이어 아레나 이탈 방지
- **현황**: pit_late 실측 플레이어 (-4.02, 1.27, -24.09) — 에이프런(±23.9) 밖으로 이탈+y 1.27 부유 의심.
- **수리**: 투기장 진입 시 플레이어 지정 좌표 고정(관전 모드 중 플레이어 이동 입력 무시 — 관전 계약) 또는 경계 클램프.
- **완료 판정**: 결투 중 플레이어가 관전 좌표 내 유지.

### R-C. 병사 크기/접지/이름표 재검증 (R5 확인)
- 원본 크기 스폰+localPosition 접지+기존 병사형 이름표(이름행+HP바) — 재Play에서 ①원본 크기 식별 ②모래 위 접지 ③이름표 HP 실시간 갱신 확인.

## Part A3 — 관중석(스탠드) 신설 — "아레나답게"의 핵심
- **구조**: 외곽 벽 바깥 타원 2단 테이프레이드 링(박스 프리미티브, 단 높이 1.2m/폭 2.4m — 48세그먼트 링 재사용).
  관중 NPC 배치 **없음**(과밀 배제 계약).
- **국가색 장식**: 스탠드 상단 국가색 방패 패널 12개(기둥 각도 재사용) + 북측 왕가석 별색.
- **관중석 횃불**: 스탠드 상단 모서리 12곳(발광 재질 — 라이트 추가 0, URP 한계 회수 계약).
- **검증**: 줌아웃(ortho 28)에서 관중석 링 2단 실루엣 식별 / baseline 1:1.

## Part A5 — 프롭/데칼 폴리시
- 장애물 6개 HQ 머티리얼(A1 팩토리 재사용)+블롭 섀도우 / 결투 마커 톤 보정 / 기둥 상단 국가색 깃발 12(A3 통합 가능).
- 과밀 금지: 신규 프롭 총 수 ≤ 30.

## Part A6 — 후처리 (품질 게이트 준용)
- GlobalVolumeProfile(ACES+Bloom+경량 비네트) — Balanced/HighSpec 토글 게이트, 메인 무손상.
- Bloom으로 야간 횃불/화염 발광 강조(R2 야간 밝기와 결합).

## Part B — 로비 폴리시 (파일 독립 — ArenaInteriorBuilder 측)
- B2 3존 분리(베팅/접수/입구 — 마모+미세 존틴트) / B3 가구 폴리시(데스크 캡+황금 라인, 벤치 2~3) /
  B4 조명 폴리시(빌더 소유 계약 유지) / B5 NPC 정합 무손상(1.8m·접지·남향).
