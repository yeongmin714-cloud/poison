## 1. 기존 인프라 실측 (재구축 금지 — 연결만)

**사망/부활 흐름 (현행)**
- `PlayerHealth` (Core): TakeDamage → `_isDead` → `OnPlayerDied` 발화 → `DeathEffects`(페이드/슬로우모) → `RespawnCoroutine`(3s realtime) → `Respawn()`
- `Respawn()` = HP 10% 복원 + 위치 우선순위: ①침대 스폰핀(리플렉션 — Core↔Systems 순환 회피) ②가까운 플레이어 영지(GuardManager.FindNearestPlayerTerritory) ③기본 위치 → OnPlayerRespawned
- 구독자: DeathEffects(연출), GuardManager.OnPlayerDied(병사 퇴각/복구), TimeManager 계열

**재사용 가능**
- `ArenaInteriorBuilder/PlayerCastleInteriorBuilder` + `IndoorSceneTransition.EnterBuilding("castle"…)` — Additive 씬 포켓 공간 패턴 (이계 씬 = 동일 패턴 신규 빌더)
- 몬스터 풀: SkeletonGuardPlaceholder/AnimalAI/몬스터 시스템 — 웨이브 소스 실측 후 결정 (A1)
- `Pickup` 선례(HerbPickup) — XP 오브/골드 드랍 재사용 패턴
- `Systems/BulletTime` 크리슬로모 — unscaled 시간 구분 실측 완료(RespawnCoroutine이 WaitForSecondsRealtime 사용 선례)

**핵심 충돌 (자가감사)**
- ⚠ **시간 배율**: TimeManager._timeScale=60 → 현실 15분 = 게임 15일. 이계 중 월드 시간 방치 시 급료 15일치+공물+배신 15회 판정 = **경제 파산** → 이계 진입 중 TimeManager 정지 게이트 필수 (A2)
- ⚠ **중복 없음**: 아레나/검투장은 대련 콘텐츠 — 본 시스템과 무관(이름 분리로 충돌 방지)
- ⚠ **세이브**: 이계 중 수면/침대세이브 불가 처리 필요 — 세이브 오염 방지 (A2)
- ⚠ **불릿타임**: 서바이벌 타이머는 `Time.unscaledDeltaTime` 기준 — 크리슬로모 중에도 실시간 유지

## 3. Phase A2 — 이계 진입 + 서바이벌 코어

**신규 `Systems/AfterlifeSurvivalSystem.cs` (static + 씬 드라이버)**
1. **사망 인터셉트**: `OnPlayerDied` 구독 → 기존 RespawnCoroutine 대신 이계 진입 (PlayerHealth에 1곳 게이트 수정 — `_useAfterlifeRespawn` 설정값, 오프 시 기존 동작 유지)
2. **이계 씬**: 어둠의 이계 아레나 — 신규 `AfterlifeInteriorBuilder` (국가색 불필요 — 진홍/보라 위주, 탑다운 원칙 유지, 지형은 단순 원형 바닥 + 기둥 장식)
3. **타이머**: 15:00 실시간(unscaled) 카운트다운/카운트업 — 난이도별: Casual 5분 / Normal 10분 / Hardcore 15분 (기본값 = Normal, 유저 결정 대기)
4. **웨이브 에스컬레이션**: 2분마다 웨이브 강화(수량/티어) — 5/10/14분 정예 출현, 15분 달성 = 귀환 문 개방. 스폰 스케줄은 결정론(사망 영지+일차 시드) — 결정론 원칙 유지
5. **월드 시간 정지**: TimeManager 게이트 (이계 중 OnDayStart 미발화 — 공물/급료/배신 모두 안전)
6. **세이브/수면 차단**: 이계 중 침대 없음(구조적으로) + F5 세이브 호출 가드

**귀환 후 위치**: 기존 Respawn() 위치 우선순위 로직 그대로 재사용 (스폰핀 > 자기 영지 > 기본)

## 4. Phase A3 — 로그라이크 재화/증강

1. **XP 오브 + 골드 드랍**: 웨이브 몬스터가 오브/코인 드랍 → 플레이어 흡수(VS식 자석 반경) → **귀환 시 소유 이관** (죽어도 이계 수확은 챙김 — 실패의 회수감)
2. **3택1 증강** (5/10분 도달): 런 한정 버프 — 공속+15%/이속+10%/최대HP+20%/흡수반경+50% 등 4~6종 풀에서 3개 제시, 귀환 시 소멸
3. **이계 티어**: 사망 위치의 영지 링 난이도 기반 (Ring1 사망 = 쉬움, Ring4 = 어려움) — 게임 난이도 철학(국가색/링)과 정합

## 6. Phase A5 — 귀환/탈주/퍼머데스 (사용자 지시 2026-10-15 확정)

1. **귀환**: 타이머 달성 → 귀환 문 스폰(문양 빛) → 진입 → 정산(골드/XP) → 기존 위치 로직 복귀 + HP 50%.
   **게임 시간 변동 없음** — 이계 중 월드 시간 정지(급료/공물/배신 판정 전부 안전) + 귀환 후 소급 변동도 없음.
   죽음의 비용 = 경제 제로, 대신 생명 = 세이브 전체(아래 퍼머데스).
2. **탈주(포기)**: 언제든 "봉헌" 버튼 — 골드의 20% 봉헌 → 즉시 귀환(HP 10%, 증강 소멸, 수확 50%).
   ⚠ 퍼머데스 도입으로 탈주는 "보험" 가치로 상승 — 가격 동결 유지.
3. **이계 사망 = 완전 게임오버(퍼머데스 — 사용자 지시)**:
   - 이계 HP 0 → 정산 없음 → **현재 플레이 슬롯 세이브 파일 삭제** → 타이틀 화면 복귀 → 새 게임 필요
   - 삭제 원칙: ①현재 슬롯만 삭제(다른 슬롯 보존 — 표준 퍼머데스 관례) ②**판정 확정 후 1회 삭제** — 씬 언로드/크래시 도중 조기 삭제 사고 방지 ③삭제 전 확인 없음(게임오버는 게임오버 — 단, 삭제 로그는 기록)
   - 골드 0이어도 동일(소프트락 개념 자체가 소멸 — 퍼머데스가 그 자리를 대체)
   - **승률 우선 튜닝 (필수 가드)**: 파멸은 월드 판단 실수에서 와야지 이계 그래프에서 오면 안 됨 → 웨이브 상한/정예 컷/체력 회복 아이템으로 이계 승률 우선 설계, 실패 잦으면 튜닝 조정
   - NG+: 퍼머데스 시 NG+ 상태도 함께 소멸(해당 슬롯 삭제이므로 자동)

## 7. Phase A6 — 세이브/엣지 (퍼머데스 반영)

- 이계 진입 중 게임 종료 → 재접 = 이계 타이머 리셋 재도전 (세이브 원천 차단이므로 세이브 사이 이계 진입이 없음 — v5 필드 불필요)
- **퍼머데스 구현**: SaveManager에 `DeleteSave(slot)` 공개 API(파일 삭제+삭제 로그) 신규 → 이계 사망 정산 확정 후 1회 호출 → TitleManager 타이틀 복귀 (기존 씬 전환)
- QA 안전: 테스트는 임시 슬롯 파일 생성→삭제 검증(실슬롯 파괴 금지) + Play 게이트에서 실제 사망→이계 실패→스롯 삭제→타이틀 전체 흐름 확인
- EditMode: 결정론 테스트(웨이브 스케줄/증강 풀/정산 산식/삭제 API 멱등)

## 9. A1 스파이크 실측 결과 (2026-10-15)

- 몬스터 소스 ✅ — MonsterSpawner가 `Resources.Load("Models/UserProvided/{modelPath}")` 프리팹 로드 + SetPaused/ClearAll/SpawnAll API 보유 → 이계 웨이브는 독립 스폰 루틴으로 이 모델 로드 패턴/프리팹 키를 재사용 (MonsterSpawner 인스턴스는 영지 기반이라 직접 재사용 아님)
- 타이머 ✅ — unscaled 실시간(RespawnCoroutine WaitForSecondsRealtime 선례) + 불릿타임 무영향
- 이계 씬 진입 — EnterBuilding("castle") Additive 패턴과 동일 구조의 독립 씬 로더 (복귀는 기존 Respawn 위치 로직 재사용)
- 월드 시간 정지 — TimeManager에 IsTimeFrozen 게이트(구독자 전수 확인 후 A2에서 구현)
