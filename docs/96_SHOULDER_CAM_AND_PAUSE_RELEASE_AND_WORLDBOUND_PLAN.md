- **수리 — 측면 오프셋(오버숄더) + 시선 높이 상향**:
  1. 카메라 = center + 베어링×2.92m + **측면 오프셋 perpendicular(bearing×90°)×0.9m**, 높이 = center.y + **0.7m**(1.2→0.7 — 옆에서 약간 내려다보는 3/4 뷰) — 시선이 플레이어 몸통을 피해 NPC 정면 3/4가 프레임에 들어옴. LookAt=center 유지(대상 고정 추적 — 사용자 요구 계약 유지). [96차 F1] 마커.
  2. ReframeCamera/LateUpdate 틱/게이트/원복 계약 전부 무변경(94차 성공분 보존).

## 결함 3 — U키 건설창: worldBound=0x0 리드 — 요소가 "레이아웃은 있고 기하가 없음"
- **증거(DOM 진단 성공 — 가림/투명설 폐기)**: `DOM 조상 체인 [0]UTKWindow_건설 관리 display=Flex visibility=Visible opacity=1.00 picking=Position` — 전부 정상. 그런데 `개방 직후 world=(0,0,0x0)`(2세션 연속, 2차 world=(120,65,**0x0**) — 위치는 있고 **크기 0x0**) → **요소의 실제 기하가 0** — 아무리 Visible이어도 0픽셀이라 안 그려짐. 시각 리소스(ThemeUss) 설은 이제 기각.

- **수리**:

  2. **방어**: worldBound 크기가 여전 0이면 → 창 루트에 position=absolute + width/height 재주입 + (필요 시) UIRoot에 직접 좌표 배치 — "레이아웃은 있고 기하가 0" 상태 탈출. [96차 F3] 마커.
