# 계획서: 인기 3D RPG 검증 장점 이식 — 고품질 세계감 고도화 (무번호 34, 계획 전용 — 2026-11-13)

**사용자 지시**: "젤다의 전설이나 엘더스크롤 같은 인기 3D RPG들의 장점을 살려서 고품질로" — 검증된 설계 원칙을 본 프로젝트 규모/계약에 맞춰 이식.

**중복 셀프감사(실측 완료)** — 이미 존재해서 제외: 말 탑승(MountSystem — 질주/체력/소환 완비)·시간대(DayNightCycle)·요리 버프(UIBuffSystem)·스텔스 인지(NPCAwarenessSystem/StealthCloakFX)·배경 대화(AmbientDialogueManager)·발자국 데칼(DecalSpawnerIntegration)·시간 정지(ParadoxTimeStop PERFECT)·건설(ConstructionHologram)·요리/농경/낚시.

## Phase A — 젤다식 "발견의 연출" (신규 지역 = 이벤트) [체감 대, 규모 중]

BotW 핵심: 새로운 곳에 도착하면 세계가 이를 "선언"한다 — 지명 타이틀+카메라 무드+음악 큐. 탐욕 루프의 핵심 보상.

| 항목 | 내용 | 파일/영역 | 검증 |
|---|---|---|---|
| A1 지명 발견 배너 | 영지/마을/랜드마크 최초 진입 시 화면 중앙 지명 타이틀 페이드인(2.5s — 세리프 대비, 국가색 액센트 라인) — 세션별 1회(저장 승계는 별도 확정) | 신규 DiscoveryDirector.cs + UI Toolkit 배너(utk-compile 패널 패턴) | 계약테스트+EditMode, Play 판정 |
| A2 발견 카메라 무드 | 최초 진입 0.8s 짧은 줌아웃+비네트 브레스(ScreenVignetteFX 재사용 — 청록=W1 패러독스 선례) — 조작 잠금 없음(게임 흐름 무방해 계약) | DiscoveryDirector → CombatCameraEffects 경유 | 기존 카메라 계약(Cinemachine 소유권) 무침습 확인 |
| A3 월드맵 핀 자동 등록 | 발견 지점 월드맵에 핀 표시 — 기존 월드맵 계약(패널@0.80+현재지핀) 확장 | 기존 월드맵 패널 소스 | ⚠UI 라운드 — Figma 단일소스 재확인 선행 |

## Phase B — 스카이림식 "사는 세계" (주민 일과) [체감 대, 규모 중]

Skyrim 핵심: NPC가 자기 삶을 산다 — 낮엔 일하고 저녁엔 집으로. 마을이 "무대 장식"에서 "공동체"로 읽힘.

| 항목 | 내용 | 파일/영역 | 검증 |
|---|---|---|---|
| B1 주민 일과 스케줄 | 촌락/일반 마을 주민(주민3~10 — VillageBuilder 상주) 낮=광장/작업장 근처 배회, 저녁(DayNightCycle 연동)=집 앞 복귀 — 결정론 경로(StableHash 배정, InteriorRandomizer 단일 시드 계약 준수) | VillageBuilder/주민 스폰 시스템 | 기존 배치 계약 무손상(영지 배치 계약 — 원형금지/링 무수정), Play 판정 |
| B2 시간대별 배경 대사 | AmbientDialogueManager에 낮/저녁 2톤 추가 — 일과와 동기 | AmbientDialogueManager.cs | 기존 대사 풀 무수정 — 추가만 |
| B3 주민 인사 리액션 | 플레이어 3m 접근 시 짧은 인사 애니+말풍선 없음(연출만) — 쿨다운 20s | 주민 컴포넌트 | 애니 패리티 계약 준수(전 씬 본씬 동일 애니) |

## 진행 방식/우선순위

- 추천 순서: **A(발견 연출) → B1-B3(주민 일과) → C1-C2(환경 반응) → D(성장 피드백) → E(판단 항목)**.
- A/B/C1/C2/D1은 현재 아키텍처에서 확장형 — 기존 계약(색 단일 소스·결정론·EditMode 가드·baseline 1:1·Play 별도 승인) 전부 준수.
- A3/D2는 UI 계약(Figma 단일소스)이라 UI 전용 라운드로 분리 권장.
- 대형(C3 날씨·E2 던지기·등반/파쿠르급 이동 자유도)은 별도 설계 확정 후 — 본 계획에서 보류 명시.
