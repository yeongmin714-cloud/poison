## A. 안개양 추가 축소 (소작업 — 선행 권장)

- **A-1**: `IndoorDensity 0.12f → 0.09f` (한 단계 — "조금만 더" 요구에 맞는 최소 보폭. 이력이 캡처 피드백 기반 단계 조정 선례).
- **A-2**: IndoorAeroFogTests가 상수를 핀하면 갱신(사유 주석 — 157차 사용자 지시).
- **A-3**: 배치 캡처로 전/후 비교 1컷 → **Play 판정 후** 더 줄일지 반복(0.09에서 만족/추가 축소 사용자 결정).
- 순서 근거: 안개를 먼저 줄여야 B(품질 패키지)의 시각 효과가 정확히 판정된다.

## B. 실내 고품질 패키지 (사용자 선택 후 실행 — A~E 제시)

- **A. 벽 질감 고도화**: CaveMaterialFactory 암반 텍스처 256→512² + 2옥타브 노이즈 + 노멀 강화 + 돌 줄눈 패턴(결정론 — Random 0건 계약 유지).
- **B. 바닥 디테일**: 마모 스탬프(H5 계약 — 알파≤0.22) 동굴 적용 + 자갈/이끼 데칼 결정론 산포(잔석 액센트 확장).
- **C. 조명 자연화**: 전 벽횟불 TorchFlicker base-relative 옵트인 확대 + 층별 존틴트(H3 — 신규 Light 금지, 색만) + 중앙광 부드러운 감쇠.
- **D. 앰비언트 연출**: 먼지 입자(절차, 결정론 — 실내 인공물 없는 유일한 움직임 소스) + F3 물웅덩이 수면 미세 반사.
- **E. 소품 밀도**: 상자/노드 주변 잔석·해골촛불 배치 보강 + 벽 기단 AO 밴드.
- 각 항목 독립 적용 가능 — 사용자가 선택한 항목만 위임. 캡처 비교 Play 판정 게이트 유지.

## C. 동굴 맵 풀 20종 + 존(영지)별 배정·순서 변화 (대작업 — 핵심)

- **C-0 운영 설계(권장안)**: 슬롯별 테마 풀 — 입구형/갱도형/습지형/대홀형/유적형 각 5종(기존 1+신규 4) × 5슬롯 = **25종 풀**.
  - 배정: `caveSeed = 해시(territoryId)` → 슬롯별 `pool[(caveSeed + slot*k) % 5]` 결정론 선택 → **같은 동굴은 재진입해도 동일 시퀀스(세이브 일치), 동굴마다 다른 조합**(5⁵=3,125 조합).
  - 순서 변화: 슬롯 테마 순서 자체를 caveSeed로 셔플(사용자 "순서를 다르게" 충족) — 단, 입구형은 1층 고정 권장(입구/스폰 계약 단순화). 셔플 범위는 사용자 답변으로 확정.
  - 기본 보존: territoryId "test"/"cave_test" → 슬롯 0(현행 F1~F5) 고정 — **기존 계약테스트·Cave156LevelProbe 무영향**.
- **C-1 도면 20종 제작**: F1~F5 문법 준수(직각 꺽임만·대형 홀+부속 구역·개구부 폭 4m·얇은 벽 가정) — 테마별 변주(입구형=홀+통로 중심, 갱도형=복도 네트워크, 습지형=w 수역 포함, 대홀형=단일 대공간+기둥 열, 유적형=링+볼트). 각 도면 ASCII → 사용자 일괄 승인 게이트(도면은 구현 전 제출).
- **C-2 검증기 계약테스트 신설** (신규 도면 전수 자동 검증): ①연결성 flood-fill(모든 바닥 셀 단일 연결 요소) ②면적 4,300~5,000m² ③포탈/스폰/화로 앵커 존재+바닥 셀 위 ④스폰-포탈 ≥2.2m ⑤횟불 t ≤9(화로 있으면 8+1) ⑥보석상자/노드 마커 계약 수 ⑦Random 0건. 검증 실패 도면은 출고 불가.
- **C-3 구현**: FloorCellmaps → LayoutPool(테마×슬롯 2차원) + SelectLayout(territoryId, floor) 단일소스 + ApplyFloorLayout 시그니처 유지(CaveLevelDirector 무수정). 마커 배치 로직은 기존 재사용(마커 기반 — 도면만 바뀌면 자동 배치).
- **C-4 성능·검증**: 층당 GO 수/드로우콜 실측(암석 액센트 o/v/w는 도면 마커 수준 유지) + EditMode 전수 + 도면 25종 탑다운 캡처 일괄 vision 판독(승인용).
- 리스크: 도면 20종 품질 편차 → C-2 검증기 + 사용자 일괄 도면 승인으로 방어. 계약테스트 좌표 핀은 기본 시퀀스에만 고정되도록 분리.

## D. 획득 빛기둥 셰이더 고급화 (중작업 — 사각형 파티클 → 고급 발광)

- **D-1 신규 셰이더 1종(ShaderLab/HLSL — 프로젝트 관례상 절차·결정론 유지, 에셋 의존 0)**: `Custom/AcquisitionBeam` 핵심 요소:
  ①**에지 소프트 페더**: UV.x 기준 가우시안 근사 smoothstep — 사각형 하드엣지 소멸(현재 불만의 직접 원인)
  ②**세로 그라데이션**: 하단 강조→상단 소멸(빛이 위로 샌다는 시각 문법) + 끝단 부드러운 페이드
  ③**스크롤 노이즈**: 시간 기반 UV.y 스크롤 × 절차 노이즈 텍스처(결정론 캐시 — GetRingTexture 선례) → "흐르는 빛" 질감
  ④**HDR 코어**: 코어 층 인텐시티 배수(HDR 컬러 — 기존 IndoorPostProcess 블룸과 연동해 글로우 발생 — 신규 볼륨 설정 불필요)
  ⑤등급색 틴트만 수신 — RarityShaft 길이/알파 티어 표 계약 무손상(셰이더는 색·알파를 입력받는 구조) → 기존 계약테스트 그대로 GREEN.
- **D-2 스파클 파티클**: 기본 사각 스프라이트 → 절차 방사 그라데이션 원형 텍스처(soft dot)+라이프타임 컬러/사이즈 커브 — "사각형" 소거.
- **D-3 링/웨이브**: 동일 셰이더의 링 변형(UV 반경 기반 페더) — 링 텍스처 교체 없이 셰이더 통일.
- **D-4 검증**: 기존 AcquisitionCinema 테스트 전부 유지+신규 소스계약(셰이더 존재/프로퍼티 바인딩) + 배치 프로브 캡처(등급별 5컷) vision 판독 → Play 판정.
- 대안(경량): URP Particles/Unlit의 Soft Particles 옵션+그라데이션 텍스처 교체만으로 1차 개선 — D-1이 맘에 안 들 때 롤백안.
