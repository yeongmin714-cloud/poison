- 결론: 무번호 5 프리미엄 FX(텔레그래프 셰이더·화이트 프레임·히트스톱)는 **진단 전용 카메라에서만 검증**됐고 실게임 팔로우 카메라에서는 렌더가 깨지거나 미가시 — 사용자 체감("수정된 게 없다")의 뿌리. 신규 FX 제작보다 **실카메라 렌더 수리가 선행**된다.

## Phase A — 실카메라 FX 렌더 근본 진단·수리 (선행 필수)

- A1 TelegraphRing.shader 실카메라 진단: 셰이더 컴파일 에러/URP 폴백(핑크·녹색) 여부, FX 프리팹 머티리얼 바인딩, 실게임 카메라 기준 쿼드 스케일/빌보드/깊이 실측 덤프
- A2 "녹색 띠" 근원 특정: Additive 쿼드 UV/스케일/색 오염 추정 — GlbTextureAudit 선례의 임포트 감사 + 런타임 머티리얼 덤프로 좁히기
- A3 검증 계약 신설: 신규/수정 FX는 **실게임 팔로우 카메라 뷰 캡처**로만 판정(진단 전용 카메라 검증 금지 계약 — 무번호 5 교훈의 제도화)
- A4 패링 창 개방 청색 링(패링D1)·화이트 프레임(ParryFlashFader) 실카메라 가시화 확인

## Phase B — 몬스터 공격 예고 VFX(적색 텔레그래프) 고품질화

- B1 채움형 게이지 링: 원형 → 공격 방향 부채꼴 채움 + 0.5s 동안 채워지는 진행 게이지(타이밍 가독성 — 플레이어가 "언제 맞는지"를 읽게)
- B2 셰이더 효과: 에지 글로우·내부 스캔라인 흐름·시작 확산→수축 펄스 이징·임팩트 순간 플래시 링
- B3 위험도 색 계약: 일반 공격=적색·정예/강공격=주황→적 구분(기존 색 계약과 정합 확인 후 확정)
- B4 경고 SFX(저음 웅성) 동기 — 시각+청각 이중 예고
- B5 지면 프로젝터(데칼) 방식 vs 현재 쿼드 방식 비교 실측 — 곡면 지형 대응에 우수하면 전환(공굴림 없는 지면에서도 그림자처럼 붙는 링)

## Phase C — RTS 병사 지정 링(푸른 링) 고품질화

- C1 회전 세그먼트 링(4~6분할 아크) + 중앙 그라디언트 필 + 선택 순간 확산 펄스(0.15s 이징)
- C2 명령 종류별 색상 계약: 이동=청록·공격=주황·집결=금 — CommandMarker 기존 계약과 정합 확인 후 색 표 확정
- C3 지면 곡면 대응 + 해제 시 알파 페이드 소멸(팝 소멸 금지)
- C4 다중 선택 링 겹침 시 밀도/알파 조절

## Phase D — 패링 FX 실카메라 재검증 + 보강

- D1 Phase A 수리 후 PERFECT(금색 2겹 링+히트스톱)/GOOD(청색 1겹)/화이트 프레임 실카메라 캡처 재판정
- D2 부족분 보강 후보: 패링 성공 스파클 버스트 강화·임팩트 방향 스파크·반격 히트 플래시 — 영상 재판독 후 확정(위조 배선 금지)
