# 계획서: 전투 VFX 품질 도약 — 공격/패망/몬스터/RTS 전용 (무번호 35, 계획 전용 — 2026-11-13)

**사용자 지시**: "공격·패망·몬스터·RTS 관련 VFX가 현재 품질에 만족 못 하겠다 — 인기 게임 수준으로 다시 계획". 참조 방향: BotW 스타일라이즈드(기존 BOTW 팔레트 계약과 일관).

**실측으로 잡은 품질 격차 본체(현재 한계)**:
1. **프리미엄 참격 리본이 꺼져 있다** — AttackArcVFX(검날 3D 스윕 리본, 테이퍼+수명 구현 완료)가 F6 디버그 토글 뒤에 잠겨 기본 OFF. 현재 공격 시각 = TrailRenderer 평면 잔상뿐.
2. **히트 플래시가 구식** — sharedMaterial _Color 틴트(47차 방식). BotW식 "실루엣 화이트아웃" 부재.
3. **RTS 명령 마커가 단일 링 1s** — 방향성/경로감/타겟 식별 부재.
4. 참격/임팩트가 정적 쿼드·링 — 애니메이션 플립북 참격 부재(연기 플립북 D-1 인프라는 있는데 전투에는 미적용).

**계약 유지**: 결정론(외부 난수 0건 — 플립북 해시 FBM 선례) / FXPalette 단일 소스 / 84차·72차 등 기존 잠금 무손상(rg 사전검사 선행) / 컴파일 error CS 0 + EditMode baseline 10건 1:1 / Play·커밋 별도 승인 / VFX Graph 기각 유지.

## 진행 방식/우선순위

- 추천 순서: **S1(리본 활성 — 최고 ROI) → S2(실루엣) → R1·R2(RTS) → P2·P3(패망) → M1(예고) → S3(플립북) → S4·M3(판단 항목)**.
- S1은 구현이 이미 존재 — 활성 전환+머티리얼 고도화만이라 1라운드에서 S1+S2+R1까지 묶어 착지 가능.
- 각 항목: 구현+계약테스트 → 컴파일 error CS 0 → EditMode 전수 baseline 1:1 → Play 판정(강도 상수 트림).
- S4·M3·P1은 판단/Play 항목 — 기본값 보수(미발화 또는 Play 승인 후 확정).
