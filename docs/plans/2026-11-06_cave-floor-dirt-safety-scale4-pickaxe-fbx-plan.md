## Phase P1 — 바닥 흙 단일화 + 고품질 (지시 1·4 후반)

- **P1-2 Concrate 타일 폐기**: `CreateAssetFloorTiles` 레이어 제거 — 회색 콘크리트 타일은 "회색 부분"의 주요원. (대안: 갈색 타일 GLB 종만 사용 — 실측상 전 Floor 타일이 Concrate/Wood뿐이라 갈색 흙 계열 부재 → 폐기가 정답에 가까움. Wood 타일은 "흙"이 아님 — 미채용)
- **P1-3 베이스 바닥을 흙 텍스처로**: `CaveFloor` 머티리얼을 **FarmPlotVisuals 흙 텍스처 팩토리 단일소스 재사용**(153차 절차 흙 텍스처 — 154차 정규화 단위 수리 완료본, 결정론 캐시). UV = 현재 원본 좌표 UV(L378)에 타일링 스케일 파라미터(머티리얼 `_BaseColorMap_ST` 또는 UV 배수 — 실측 후 결정, 목표: 1타일 ≈ 2~3m). 경준선/수분 가시화는 농경 전용 — 동굴 바닥은 일반 흙 톤만.
- **P1-4 고품질 마감**: ①마모 스탬프(H5 계약 — `CreateFloorWearMat` 알파≤0.22) 소량 결정론 산포 ②타일링 반복 티 가시 방지(2옥타브 노이즈 오프셋 — FarmPlot 선례) ③Random API 0건 계약 유지.
- 검증: 집중 Cave 테스트 + 탑다운/플레이어뷰 캡처 vision 판독(회색 요소 0·흙 톤 균일).

## Phase P2 — 나무기둥 제거 + 낙하 봉합 (지시 2·3)

- **P2-1 지보목 완전 폐기**: `CreateEntranceTimbering` 메서드+호출부 폐기(포스트 2 제거) — 계약테스트 `EntranceTimbering_Present_NoColliders` → **부재 단언으로 재편**(계약 진화, 사유 주석).
- **P2-2 문 패널 처리**: P0-2 귀속 결과에 따라 — 문 패널이 "나무 기둥"으로 읽히면 패널 시각 제거(블로커/컴포넌트 계약 유지, 시각만 off) 또는 문 자체 폐기. Arch GLB는 석재라 유지 판단(귀속 결과로 확정).
- **P2-3 낙하 봉합(1차 — 입구)**: `CaveDoorBlocker` 상시 활성 전환(기본 열림 계약 → **상시 봉합으로 명세 변경**, 사유: 사용자 낙하 금지 지시). 시각 패널은 열림 연출 유지 가능(시각과 충돌 분리). 귀환은 기존 상승 포탈(E키) 경로로 불변.
- **P2-4 낙하 봉합(2차 — 안전망)**: `CaveFallGuard` 신설(룸 컴포넌트, 플레이어 y < −3m → 해당 층 스폰으로 무음 텔레포트+로그 1행) — 포탈/문 외 어떤 경로로도 낙하하지 않도록 벨트앤서스펜더. IndoorActive 게이트와 무충돌(텔레포트는 기존 `TeleportPlayerToFloorSpawn` 재사용).
- **P2-5 포탈 주변 재확인**: Arch 포탈은 거리형 판정(콜라이더 없음) — 포탈 위치가 변 가까이 있어 벽 밖으로 밀려 나갈 여지 있으면 P0-1 프로브에서 같이 확인(필요 시 포탈 내부 오프셋 조정 — 146차 스폰-포탈 2.2m 이격 선례 준용).
- 검증: 낙하 재현 프로브 재실행 → 낙하 0 + 전수 EditMode 신규 실패 0.
