## 1. 게임 흐름 (확정)
1. **야생 말 스폰** — 몬스터 배치 파이프라인과 동일하게 월드 배치(비공격성 야생동물)
2. **안장 크래프트** — 크래프트 항목에 "말 안장" 신설: **멧돼지 가죽 5개**(수치 조정 가능)
3. **길들이기 조건** — 말 안장을 **인벤에 소유**한 상태로 말 가까이 접근 → **E키 상호작용 + UTK 상호작용창** 동시 노출
4. **길들이기 미니게임** — **낚시게임과 동일한 UI 형식의 신규 UTK**(HorseTamingUTK — FishingUTK 패턴 승계): 미니게임 **성공 시 길들임 / 실패 시 미길듦(재도전 가능)**
5. **길들여진 말만 탑승 가능** — MountLocomotion(탑승/이동/하차)은 기존 계획 유지

## 2. Phase 분해 (검증 범위 포함)

### P1 — 에셋 수용 계약
- 말 GLB 3종 리소스화(`Resources/Models/UserProvided/말/`) + **glTF 전수 감사**(147차 계약) + 스케일 상수(×2.4)
- 애니 FBX 12종(걷기 포함) Generic 유지 확인 + 말 컨트롤러 배선 배치 스크립트(SpearThrustClipWiring 패턴 재사용)
- 검증: 파서 리포트 + `MountAssetContractTests`(리소스 경로·스케일·4동작 클립 존재)

### P2 — 안장 아이템 + 크래프트
- ItemData `mat_saddle`("말 안장") 신설 + 크래프트 레시피(멧돼지 가죽 ×5) + 크래프트 UI 노출
- 검증: EditMode 레시피 계약 + 크래프트 제작 실측(Play)

### P3 — 야생 말 스폰
- 몬스터 배치 파이프라인 승계 — 비공격성 플래그(어그로 제외), 대기 애니 재생, 말 콜라이더(공격 대상 제외·무해)
- 검증: 배치 프로브(스폰+대기 애니 캡처) + EditMode 계약

### P4 — 말 길들이기 (핵심 신규)
- 근접 + 안장 보유 조건 → E키 + UTK 상호작용창 → **HorseTamingUTK 신설**(FishingUTK 동일 UI 형식 — UTKWindowBase 파생, 게이지 바 미니게임)
- **성공** = 말 상태 → 길들임(소유 귀속) / **실패** = 미길듦 유지(재도전) — 안장은 성공 시 소모
- 검증: EditMode 성공/실패 분기 계약 + Play 프로브(미니게임 캡처)

### P5 — 탑승/이동/하차
- E키(길든 말) → 탑승: 플레이어 말 자식화(안장 오프셋) + PlayerMovement 비활성 + MountLocomotion 활성
- 걷기/질주 속도 곡선 + 애니 속도 게이트 / 하차 복귀 / 카메라 팔로우 무수정
- 검증: EditMode 상태 계약 + Play 프로브 4컷

### P6 — 마필 전환 + 마무리
- 백마/적토마 전환 경로, 앞발 들고 서기 연출(길들이기 실패 리액션에 재활용 가능)
- 보류: 황마(애니 미비), 사운드, 세이브 연동, 말 전투, 앉기 자세 애니
- 검증: EditMode 계약 + Play 육안

## 3. 리스크/주의
