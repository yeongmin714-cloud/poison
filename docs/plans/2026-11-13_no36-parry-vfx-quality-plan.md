# 계획서: 패망 VFX 고품질 — 창/임팩트/반격/위계 4계층 (무번호 36, 계획 전용 — 2026-11-13)

**사용자 지시**: "패링 관련도 확인해보고 더 고품질로 만들 수 있는 계획".

**실측으로 잡은 갭(성공 임팩트는 이미 밀집 — 7요소 시퀀서+림/비네트/수차/라이트/블룸 누적)**:
1. **창 유지 중 시각 0건** — 개방 순간 청색 소형 링 1회(패망D1, 0.3s)뿐. 0.45s 창이 살아있는 동안 화면이 말을 안 함.
2. **만료 시 신호 0건** — EndParryWindow는 로직만(애니 트리거) — "놓쳤다"가 시각적으로 안 읽힘.
3. **PERFECT 타이밍 힌트 없음** — 창 초반 0.15s(PERFECT 구간, 95차 F1)과 이후(GOOD)가 개방 시각에서 동일 — 플레이어가 타이밍을 배울 수 없음.
4. **접촉점 고정** — 흡수점 = 플레이어 앞 1m 고정(L1079) — 공격이 실제 닿는 방향과 어긋나 링/스파크가 공중에 뜨는 체감.
5. **GOOD 톤 박약** — GOOD = 청색 링 1겹+히트스톱 0.03s뿐. "성공했지만 완벽하진 않다"의 중간 톤 부재.

**계약 유지**: 결정론 / FXPalette 단일 소스(ParryGold·MonsterDanger 등 기존 상수) / 95차·159차·23-X1·28·29 잠금 무손상(rg 사전검사 선행) / baseline 1:1 / Play 별도 승인.

## 진행 방식/우선순위

- 추천 순서: **PW1→PW3(창 언어 — 플레이어 학습 곡선 직결) → PW2 → PI1(접촉점) → PG1(GOOD) → PI2·PI3·PS1·PS2**.
- PW1/PW3/PI1은 소형(상수/1~2블록) — 1라운드에 PW 전체+PI1 묶음 착지 가능. PI2/PI3/PS는 다음 라운드.
- 각 항목: 구현+계약테스트 → 컴파일 error CS 0 → EditMode 전수 baseline 1:1 → Play 판정.
- 제외: 참격 플립북(35-S3에서 전투 공통 커버), VFX Graph(기각), PG2(판단 항목 — 기록만).
