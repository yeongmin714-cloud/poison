# 전투 VFX 크기·품질 고도화 계획 (무번호 20 계획서 후보 — 2026-11-12)

## 배경

- 사용자 요구: 이동 VFX·몬스터 공격 VFX·패링 VFX 모두 추가 고품질화. 특히 **몬스터 공격 적색 링이 너무 크다 — 원 크기 축소**.
- 실측 근거(무번호 19 완료 기준):
  - 적색 텔레그래프 링 반경 = `AnimalAI._attackRange` 그대로(기본 2.0m / 종별 2.5m·3.0m — AnimalAI.cs L28/L261/267/273).
  - 링·타격 판정(ConcludeMeleeTelegraph `playerDist <= _attackRange`)·추격 개시 반경(`_attackRange * 1.2f`)이 **동일 값 공유** — 반경 축소 시 3요소 자동 일치.
  - 이동 VFX: F1 트레일(0.55m 싱글 링, 이동 중에만)·F2 진행도 축소(선형 25%)·F3 데칼 링(밴드+백킹+2중 링 베이크) 구현 상태.
  - 패링 VFX: 히트스톱(0.07/0.03s)·슬로우모션·FOV 펀치([95차 F3])·반격 슬롯·지면 링 2겹+아우터(반대 위상)·별섬광·방향성 스파크([95차 F4])·스파클 버스트(무번호 19-G2, 0.5s)·SFX·화이트 프레임(Play 판정 대기) 존재 — **중복 감사로 기존 요소 재구현 배제**.

## 중복 셀프감사 결과

- 부채꼴 게이지/스캔/펄스/플래시 셰이더 기능 = B2에서 구현 완료 → 본 계획은 **사용 확장**(배선)만 수행, 셰이더 중복 구현 없음.
- 패링 아우터 링(반대 위상 154차 패턴)·방향성 스파크·카메라 FOV 펀치 = 기존 구현 → 재구현 항목에서 제외.
- 반격 히트 금색 플래시(G4) = 참조 영상 미표출로 무번호 19에서 미채택 — 본 계획에서도 부활하지 않음(위조 배선 금지 유지).

## Phase H — 몬스터 공격 텔레그래프 크기·품질

- **H1 링 반경 축소(판정 동시 축소 — 1:1 일치 유지)**: `_attackRange` 2.0/2.5/3.0 → **1.6/2.0/2.4m(×0.8)**. 링·타격 판정·추격 개시(1.2×)가 같은 값을 공유하므로 단일 변경으로 3요소 일치 유지. ⚠️ 밸런스 영향: 몬스터가 더 가까이 접근해야 공격 가능(위험권 진짜 축소). 시각만 축소(판정 유지)는 링 밖 피격=억울 피격을 만들므로 **비권장**으로 명시하고 판단 항목으로 남김.
- **H2 시각 부담 완화**: TelegraphRing 셰이더 글로우/에지 두께 축소(현재 링 가장자리 광원 확산이 실반경보다 크게 보이는 요인) — B2 상수 계약(T1~T7) 범위 내 파라미터 조정, 테스트 기대값 갱신.
- **H3 발동 순간 공격 방향 부채꼴 플래시**: 텔레그래프 완료 순간 실제 공격 방향으로 부채꼴 1회 플래시(B2 `_Flash`+부채꼴 파이프라인 사용 배선) — "링 전체가 위험"이 아니라 "이쪽이 스윙된다"는 정직한 예고.
- **H4 원형→부채꼴 전환 판단(사용자 선택)**: 몬스터 근접 스윙을 원형 대신 부채꼴(useWedge)로 표시 — 원반 대비 면적 축소로 "크다" 느낌 추가 완화. 단, 스윙 판정이 원형(거리만)이면 부채꼴은 신규 불일치를 만드므로 **H1 축소 후 Play 체감으로 판단**.

## Phase I — 이동 VFX 고도화

- **I1 트레일 연속 자취**: 현재 1회성 발밑 링 → 이동 중 일정 간격(거리 0.6m 기준) 연속 스폰으로 "먼지 자취" 연출. SpawnMoveTrailDust 재사용(선례), 스폰 간격 상수화, GuardPlaceholder StepToward 내 배선 확장(도착 early-return 이후 = 기존 계약 유지).
- **I2 도착 먼지 퍼프(신규 1회성)**: 도착 순간 발밑 소형 확산 1회 — F1 "이동 중에만" 계약은 트레일에만 적용되는 것으로 명시하고 퍼프는 별도 신규 FX(도착 분기 지점 배선).
- **I3 진행도 이징+도착 임박 신호**: F2 축소(선형 25%) → easeOut 이징 + 진행도 ≥ 0.8 구간에서 링 밝기(fadeFactor) 소폭 상승 — "거의 도착" 직관 신호. [72차] 1s 규약·도착 소멸 금지 계약 불변.
- **I4 데칼 링 세그먼트 룩**: 쿼드 시절 SelectionRing의 회전 세그먼트 룩을 데칼 텍스처 베이크에 반영(BuildTintedRingTexture 확장) — 데칼 전환으로 잃은 룩 패리티 회복. 알파 펄스는 스케일 펄스와 중복되므로 미채택.

## Phase J — 패링 VFX 고도화

- **J1 PERFECT 방패 아크 잔상**: 패링 성공 순간 방패 궤적 금색 아크(0.25s) — AttackArcVFX.SetPremium(프리미엄 아크) 선례 재사용, 패링 경로 신설 배선(공격 아크와 별개 인스턴스 — 중복 없음).
- **J2 등급 위계 강화**: GOOD은 스파클 버스트 6방향(12의 절반)+링 알파 완화, PERFECT는 현행 12방향 유지 — 등급 체감 차등 신설(현재 양쪽 동일 스폰).
- **J3 히트스톱-링 동기**: PERFECT 히트스톱 0.07s 동안 지면 링 확산 동결 → 종료 후 확산 가속(easeOut) — 프리징과 FX가 한 박자로 터지는 타격감. ShockwaveRingFX 트윈에 timescale 인자 전달 방식 검토.
- **J4 화이트 프레임 후속**: Play 판정(실체감) 결과를 받아서만 행동 — 체감 OK면 유지, 미체감 시에만 재설계 논의. 선구현 금지(무번호 19 구조적 결론 존중).

## 진행 방식

- 기존 계약 동일: 각 Phase 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 10건 1:1 → 실카메라 캡처 비전 판독 → 사용자 Play 판정(별도 승인).
- Play·커밋은 항상 별도 승인 게이트. 위조 배선 금지 — 참조/실측 근거 없는 신규 FX 불허.
- H1은 게임 밸런스 변경을 수반하므로 **착수 전 사용자 수치 확정 필요**(1.6/2.0/2.4 제안안 or 다른 배율).

## 판단 항목(사용자 선택 대기)

1. H1 축소 배율 확정(제안 ×0.8 = 1.6/2.0/2.4m) — 시각만 축소(판정 불일치)는 비권장.
2. H4 원형→부채꼴 전환 여부(H1 후 Play 체감 기반 판단 권장).
