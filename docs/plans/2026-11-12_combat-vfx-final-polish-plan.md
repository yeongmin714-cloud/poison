# 전투 VFX 최종 폴리시 계획 — 모션·노이즈·개별 레이어 심화 (무번호 22 계획서 후보 — 2026-11-12)

## 배경

- 사용자 지시: 무번호 19~21을 거쳐도 만족스럽지 않다 — 패링·몬스터 공격·병사 이동 VFX를 **다시 한 번 더 깊게** 고품질화.
- 무번호 21 완료 기준 잔존 한계 실측(무엇이 여전히 "절차적/기계적"으로 보이는가):
  1. **링이 기계적** — 밴드 텍스처는 적용됐지만 링 자체가 균일 속도로 뻗어나가는 정적 원. 노이즈가 시간에 따라 흐르지 않고, 단일 파동.
  2. **먼지가 매끈함** — 소프트 서클 텍스처 = 매끈한 원. 실제 먼지/연기는 프랙탈 노이즈로 흐느적거린다. 터블런스(난류) 모듈 미사용.
  3. **패링이 "폭발"만 있다** — 팬(직선 6본)·버스트(방사)·링이 동시에 퍼지지만 **동작의 흐름(궤적 잔상)**이 없다. 방어 동작의 스윙이 그려지지 않음.
  4. **windup이 한 결손** — 수렴 링 1겹만 존재, 응축 클라이맥스(직전 플래시) 없음, 스윙 순간 방향성 지면 파동 없음.
  5. **전투 흔적이 정적** — 스콜치 데칼이 깔리지만 불티가 튀지 않아 "죽은 흔적".
  6. **링이 라이팅에 종속** — URP/Lit라 그늘에서 어두워짐 — 에너지 FX는 자체 발광이 원칙.

## 중복 셀프감사 결과

- 이중 웨이브 echo vs 패링 아우터 링(반대 위상) = 다른 연출(동일 반경대 속도차 vs 확대 반경) — 병행 가능, 내부 Runner 구현으로 API 무변경.
- 스윙 지면 파동(FanRunner 파라미터 확장) = 디플렉트 팬과 같은 패밀리의 용도 확장(중복 구현 아님).
- FOV 펀치/슬로우모션/히트스톱/방향성 스파크/별섬광 = 기존 구현 — 제외.
- 화이트 프레임 = Play 판정 대기 유지(선구현 금지).
- 시작 먼지 킥 = 도착 퍼프의 대칭 신규(이동 시작 지점 1회).

## Phase P — 공통 링 모션·광원 (전 전투 링 동시 수혜)

- **P1 노이즈 워블 스크롤**: RingRunner가 머티리얼 `mainTextureOffset`를 수명 동안 스크롤(0.35/s) + 밴드 텍스처 u축 노이즈 16→24셀+2차 옥타브 — 링 가장자리가 확장하면서 유기적으로 흔들림(에너지 요동). API 무변경.
- **P2 이중 웨이브 echo**: maxRadius ≥ 1.0m 링에 한해 RingRunner가 수명 25% 시점 자체 echo 링 1겹 자체 스폰(속도 0.6배·알파 0.4배·반경 1.12배) — 큰 링에만 깊이 파동, 트레일/퍼프 소형 링은 제외(스팸 방지). API 무변경.
- **P3 에너지 자체 발광 전환(판단 항목)**: 링 머티리얼 URP/Lit → Unlit 투명(또는 HDR 강도 상향으로 블룸 흡수) — 그늘에서도 빛나는 에너지 룩. **전 링 외형 변화가 커서 Play 비교 후 확정** — 프로브 컷으로 Lit/Unlit 병렬 캡처해 판단 자료 제공.

## Phase Q — 병사 이동 VFX

- **Q1 빌보우 노이즈 먼지 텍스처**: 퍼프 텍스처 64×64 smoothstep 원 → **128×128 3옥타브 value noise**(프랙탈 구름 프로파일) × 방사 마스크 — 매끈한 원이 실제 연기처럼 흐느적거림 + ParticleSystem 노이즈 모듈(강도 0.1 — 입자 난류 흔들림).
- **Q2 이동 시작 킥**: 이동 명령 발행 지점(SetCommandTarget, GuardPlaceholder L1051)에서 발밑 소형 킥 퍼프 1회 — 도착 퍼프(20-I2)와 대칭. 출발/도착 먼지 프레임 완성.
- **Q3 트레일 밀도 튜닝**: 먼지 입자 크기 편차 확대(0.08~0.22m — 균일감 제거) + 수명 편차(0.4~0.75s) — 이미 게이팅된 스폰 수 유지.

## Phase S — 몬스터 공격 VFX

- **S1 수렴 링 2겹+응축 플래시**: 수렴 링을 바깥(빠른 밝은 링)+안쪽(느린 희미한 링) 2겹으로 — 종료 0.15s 전 중심에 소형 발밑 플래시 링(0.25m, 0.15s) 1회 — "에너지 응축 완료" 클라이맥스. 인디케이터 자체 발화 경로 유지(몬스터 배선 추가 없음).
- **S2 스윙 방향 지면 파동**: 임팩트 순간 공격 방향으로 좁게(±15°) 길게(1.2m) 뻗는 지면 스트릭 3본 — FanRunner 파라미터 확장(count/halfAngle/streak 범위 인자화, 기본값 = 기존 팬 계약 유지) 재사용 — "스윙이 바람처럼 스치는" 방향성.
- **S3 불티 파편**: 스콜치 데칼 생성 직후 타격 지점에서 주황 불티 입자 5개(0.8s, 위로 튀고 중력으로 낙하 — 랜덤 허용 경로, 프로브 미경유 명시) — 죽은 흔적이 아니라 "방금 일어난 일"의 흔적.
- **S4 텔레그래프 에지 순회 에너지**: TelegraphRing 셰이더 — `_Scan` 재활용, 링 밴드 위를 도는 밝은 순회 스팟(각도 = _Scan×2π, 좁은 각 가우시안) — 위험 에너지가 경계를 도는 가동감.

## Phase T — 패링 VFX

- **T1 곡선 위스프 아크**: 패링 순간 방패 궤적을 따라가는 곡선 잔상 3호(2차 베지어 — origin→중간 오프셋→끝, LineRenderer 8포인트, 금색, 0.3s) — 직선 팬(20-J1)과 병행, "방어 스윙의 흐름" 시각화. FanRunner 곡선 모드 확장(결정론 유지).
- **T2 등급별 버스트 물성 차등**: PERFECT=굵고 빠름(속도 6~9·두께 유지), GOOD=얇고 느림(속도 4~6·라인 두께 ×0.7) — 방향 수 위계(12/6)에 물성 위계 추가.
- **T3 화이트 프레임**: Play 판정 결과 반영(유지/재설계) — 기존 계약 유지.

## 진행 방식

- 우선순위: **P 선행(전 링 모션 부여) → Q/S 병렬 → T**.
- 각 Phase: 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 10건 1:1 → 실카메라 캡처 비전 판독 → 사용자 Play 판정(별도 승인).
- 결정론: 신규 로직(위스프/순회/수렴 2겹) 랜덤 0건 — 불티만 런타임 전용 랜덤(프로브 미경유 명시).
- Play·커밋 별도 승인 게이트 유지.

## 판단 항목(사용자 선택 대기)

1. **P3 에너지 자체 발광 전환** — Lit(현재) 유지 vs Unlit/HDR 전환: 프로브 병렬 비교 컷으로 판단 자료 제공 후 확정.
2. **Q1 먼지 텍스처 교체** — smoothstep 원(현재) 유지 vs 프랙탈 노이즈 교체: 교체 시 텍스처 생성 비용 1회(캐시) — 성능 무영향, 룩 변화 있음.
