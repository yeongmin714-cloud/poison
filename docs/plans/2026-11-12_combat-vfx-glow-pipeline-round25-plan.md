# 전투 VFX 발광 파이프라인 + 무기 휘적 트레일 + 잔존 이관 계획 (무번호 25 계획서 후보 — 2026-11-12)

  - **무번호 19~23 대부분 구현 완료**: 20 H/I/J(사이즈/품질), 21 R/K/L(밴드 텍스처·먼지 파티클·수렴 링·스콜치), 22 P1/P2/Q1~Q3/S1~S3/T1/T2, 23 U2(서브 밴드)/V(비네트)/W1·W3(패러독스 시각 언어)/X1(시퀀서)/X2(예산 가드)/X3(스윙 아크). P3는 **대형 링 HDR 부스트만 부분 적용** — 전면 Unlit 전환은 Play 비교 대기 이월.
  - **무번호 24 부분 구현**: CA(피격/크리티컬/무기별 카메라 셰이크+히트스톱 — 계획보다 확장됨), FA1(데칼 페이드아웃 2s — 마커 없이 구현됨). **DA(날씨 반응)/EA(몬스터 개성)/FA2(스콜치 고도화)는 미착수** — 코드 실측: ShockwaveRingFX에 CurrentWeather 소비 0건, AttackTelegraphIndicator에 gizmoColor 사용 0건.

  1. **빛의 계층** — FX가 글로벌 Bloom(PhaseG2: Intensity 1.0/Threshold 0.9)에 실제로 걸리는 픽셀이 거의 없다(Lit 알베도 틴트 = threshold 미달). 젤다식 "발광 에너지"의 마지막 관문.

  3. **23/24 미착수 항목** — 깊이 페이드(U1)·날씨(DA)·개성(EA)·스콜치 고도화(FA2).

## 중복 셀프감사 결과

- **Bloom 볼륨 구축 = 기존 존재(PhaseG2_PostProcessingSetup, 실내 IndoorsPostProcess 별도)** — 신규 구축 금지. 본 계획은 "Bloom에 걸리게 만들기"만.
- **몬스터 히트 플래시 = 기존**(CombatVFXController.PlayHitFlush — AnimalAI 단일 발화 계약) — 제외.
- **카메라 셰이크/히트스톱/FOV 펀치/비네트/시퀀서/예산 가드/수렴 링/echo/스윙 아크/위스프 = 기존 구현** — 전부 제외.
- **무기 휘적 리본 = 신규**(rg 0건 실측).
- **FX 실시간 라이트 펄스 = 비권장** — 신규 라이트 추가 없음 비용 게이트 선례([F4], 캔들라브라 주석) — 발광+블룸으로 대체.
- **날씨/개성/스콜치 고도화 = 24-DA/EA/FA2 정의 그대로 이관** — 재정의 금지(중복 정의 방지).
- 화이트 프레임 = 여전히 Play 판정 대기(선구현 금지 유지).

## Phase BL — 발광 파이프라인(22-P3의 완성형 — 최우선)

- **BL1 발광 이중화**: 링/버스트/먼지 패밀리 머티리얼 생성부에 `_EmissionColor = tint × 강도` 추가(URP/Lit — GI 비활성). P3의 대형 링 한정 부스트를 패밀리 전반으로 일반화. **Unlit 전환 불요** — Lit 유지로 22-P3 판정 지연을 구조적으로 해소(발광 항은 무광 기여라 그늘 어두움도 완화).
- **BL2 강도 등급화(판단 항목)**: PERFECT/정예 임팩트 = 높은 강도(제안 ×2.5), 일반 = ×1.5 — 등급 위계 계약(20-J 방향 수 12/6)과 같은 방향의 "물성" 위계.
- **BL3 색 계약 무손상**: 알베도 틴트 경로(color 승수) 전혀 변경 없음 — 패링 금(1,0.85,0.3)/청(0.65,0.9,1)·위험도 적/주황(16-B3)·등급색 전부 기존값 유지, Emission은 추가 항. 문자열 계약 테스트 파손 방지 — 수정 전 `rg "<변경 문자열>" Assets/Scripts/Tests/` 선행검사(플레이북 규칙).
- **BL4 기존 P3 부스트 통합**: 대형 링 한정 부스트 상수를 BL 강도 체계로 흡수(이중 부스트 방지).
- 수혜: 전 링·버스트·먼지·수렴 링 — threshold 0.9 초과 픽셀 발생 → 기존 Bloom이 그대로 발광 번짐을 만든다. 신규 포스트 0건.

## Phase WT — 무기 휘적 리본(신규 레이어)

- **WT1 팁 경로 트래킹**: 근접 스윙의 무기/손 본 트랜스폼을 스윙 구간 동안 샘플링 → TrailRenderer(수명 0.15~0.25s, 라인 폭 테이퍼). 색 = 소속 국가색 계약(병사 파랑/적 계열 유지 — 색 신규 정의 금지). **결정론**(랜덤 0건 — 팬/버스트 선례).
- **WT2 배선**: 기존 공격 발화 게이트(TriggerAttack/CombatVFXGate 배선 선례)에서 스윙 활성 1회 — **애니/클립 수정 0건**, 배선만. 병사+플레이어 양쪽. ⚠️ 방패병사 앵커는 방패 본(휘두르는 물체) 실측 후 확정 — GLB 본 구조 실측 선행.
- **WT3 예산 등록**: 패밀리 카운터(23-X2)에 리본 등록 — 대규모 전투 안전망 공유.

## Phase DP — 지면 통합 완성(23-U1 재기동 — 선행 검증 고정)

- **DP1 검증**: URP Asset `_CameraDepthTexture` 활성 여부 실측 → 활성 시 링/데칼에 깊이 페이드(소프트 파티클 방식) 추가안 보고, 비활성 시 (a)카메라 depth 모드 vs (b)FullScreenPassRendererFeature(156차 선례) 최소 침습안 비교 보고. **전역 렌더 설정 무단 변경 금지** — 검증 보고 후 사용자 선택.
- 이번 라운드에서 DP는 **검증+보고만** 고정(구현은 다음 라운드 분리 가능).

## Phase IN — 무번호 24 잔존 이관(정의 재사용 — 재정의 금지)

- **IN1 = 24-DA1**: 날씨 반응 트레일 — Rain: 청백 물 스플래시(작은 링+상승 미스트), Snow: 흰 파우더. 기존 SpawnMoveTrailDust/Puff 유지+선택 분기만(구조 무변경). 결정론 유지.
- **IN2 = 24-EA1/EA2**: 몬스터 개성 틴트(제안: 위험도는 채도로 유지+hue 시프트 — B3 위험도 색 계약 병존) + `deathEffectPrefab` 배선 상태 확인(미배선 시 배선, 배선済면 제외).
- **IN3 = 24-FA2**: 스콜치 텍스처 고도화 — 크랙 두께 변주(중심 두껍→끝 가늘)+블롯 비대칭 오프셋(결정론 해시).

## 진행 방식

- 권장 순서: **BL(발광) → WT(리본) → IN(이관) 병렬 → DP(검증만 선행 가능)**.
- ⚠️ 무번호 23 권장 사항 계속 유효: Play 체감 판정이 누적 대기(화이트 프레임/P3 병렬 비교/CA2 강도/V3 수차) — **BL/WT 구현 전 1회 Play로 강도 기준선 확보 권장**(과잉 개선 방지 + BL2 수치를 체감 기준으로 확정).
- 검증 흐름 불변: 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 10건 1:1(Melee 2건 플래키 = 12 실패 가능) → 실카메라 캡처 비전 판독 → Play 판정(별도 승인).
- 위임: 구현/QA 서브에이전트 분리(docs/AGENT_DELEGATION_POLICY.md). Play·커밋은 별도 승인 게이트. 위조 배선 금지.
- 결정론: BL/WT/DP 랜덤 0건 — IN3 해시 기반, IN1 물튀김은 프로브 미경유 시 명시.
