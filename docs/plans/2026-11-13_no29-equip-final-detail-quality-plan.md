## 0. 근거 (Play 로그 11-13 12:24 — 28-P4b2 수리 후 첫 Play)

### 0-1. 결정적 3수치 — "화면은 정상, 측정만 파손"
```
[28-P4b2] SMR 매핑 정합 — input: transformSpan=2.43m  rootBoneSpan=1.32m  refBounds=1.88m  채택=A(rootBone=Hips)
[ArmorVisual] 바디 측정 진단: fullBody=(1.65, 2.43, 1.21) ... parts h=(1.44,1.46,1.06) ... Head본=1.01m(상대)
[28-P4b2] 재피팅 — fullBody 2.43m(계약 2.16m 초과) → 1.0s 후 재피팅 → [28-P4b2] 재피팅 후에도 fullBody 2.55m — 세션 1회 소진
⚠️ Helmet 비주얼 중심이 본에서 0.54m 이상 벗어남 — 포즈 튜닝 필요(3차 부착, 본↔중심 0.97m)
```
- **refBounds=1.88m** = Unity 자체 스킨ned AABB — 캐릭터 **시각적으로는 1.8m 계약의 +4.4%로 사실상 정상**. 사용자가 보는 "부착 불량"은 캐릭터 크기가 아니라 **허측 2.43m로 계산된 피팅 값**(투구 본↔중심 0.40m→재피팅 후 0.97m 악화).
- 측정 후보 A(transform L2W)=2.43m 과대 / 후보B(rootBone L2W)=1.32m 과소 — **BakeMesh 정점+행렬 매핑은 이 리그(rootBone=Hips+휴머노이드 애니)에서 근본 신뢰 불가**. 심판이 둘 중 "덜 틀린" A를 0.55 vs 0.56 근소 차로 채택한 것까지 로그로 확인.
- **본(skeleton)은 정확** — Head본 절대 y≈1.81m 등 1.8m 비율(27 라운드 때 판독, 재확인). 즉 신뢰 가능한 데이터 = ①r.bounds ②본 위치 ③계약 상수(105차 폴백 경로 — 이미 존재·검증).
- 결론: 정점 기반 측정을 "교차검증 실패 시 폐기"하고 검증된 경로로 강제 전환하는 것이 종결책. 추가 행렬 후보(C) 시도는 referee 확장으로 저비용 시도 가능하나, 폴백 강제가 정답에 가까움(둘 다 넣음).

### 0-2. 품질 현황(28 착지분)과 "더 다듬기"의 실제 갭
- 몬스터: 충전 글로우(M1)·정예 오라(M4)·사망 링(M3) 착지 — 단 **단색 발광/단순 파티클**(프레넬 림·플립북 연기·소프트 파티클 없음 = "기본 파티클" 느낌의 잔여)
- 병사 발자국: 좌우 교차(S1)+4옥타브 먼지(U-2) — 단 **스텝 애니와 무동기**(거리 게이팅만), Sprites/Default 파티클(깊이 무관 — 지면 관통 룩), 착지/기동 커브 단조
- 패망: 무기 플래시(P1)·리플렉(P2)·공격자 플래시(P3) — 단 **림 없는 단색 발광**, 불티/스파크 Sprites/Default, 등급별 궤적 차등은 개수 위주(궤적 곡선 차등 없음)

## 1. Phase 0 — 장비 부착 최종 종결 (P5 — 최우선 선행봉합)

### P5-a — 측정 후보 C 추가(저비용 시도)
- PlayerBodyMeasure SMR 경로에 후보 C 추가: `BakeMesh(tmp, useScale: true)`(스케일 내장 베이크) + **무스케일 행렬**(transform position+rotation만 — lossyScale 배제) 매핑.
- referee 확장: A/B/C 3후보 × r.bounds 오차 최소 채택 — 로그에 3후보 전부 기록([29-P5] 매핑 정합 확장).

### P5-b — r.bounds 교차검증 게이트(종결책)
- 채택 후보의 fullBody가 **r.bounds fullBody와 ±10% 초과 괴차**하면 → **정점 측정 무효 판정**:
  - fullBody = r.bounds 값 사용(1.88m — 실측 정상치)
  - 부위 분류는 정점 샘플 폐기 → **기존 폴백 상수 경로 강제**(105차 F2/F3 — IsPartPlausible 실패 시 폴백 상수+본 앵커 — 이미 존재·검증된 계약 경로)
  - 로그: `[29-P5] 정점 측정 무효 — vertexSpan={x}m vs refBounds={y}m 괴차 {z}% > 10% → 폴백 상수+본 앵커 경로 강제` (WarnOnce `measure-unreliable:{scene}`)
- 근거: 본 위치는 정확(0-1), 폴백 경로는 계약 설계(105차) — "신뢰 불가 측정으로 계약을 깨는 것"보다 "검증된 상수 경로"가 정답.
- 기대: 투구/갑옷/장갑/신발이 계약 비율 앵커로 부착 → 본↔중심 ≤0.25m 수렴.

### P5-c — 재피팅 게이트 보정
- 기존 [28-P4b2] 재피팅(2.16m 초과→1회) 유지하되, 재피팅 후에도 이탈 시의 로그만 남기던 현재 동작에 **P5-b 무효 판정 연동** — 무효 판정 후 재측정은 r.bounds 기준값으로 판정(폴백 경로 부착 상태에서 재피팅 불필요 — 조기 종결).
- Play 판정 기준(현실화): fullBody r.bounds 기준 1.8m ±8% 밴드 수렴 + 투구 본↔중심 ≤0.25m + ⚠ 경고 0건.
