# 전투 VFX 심화 계획 — 환경·개성·카메라·흔적 생명력 (무번호 24 계획서 후보 — 2026-11-12)

## 배경

- 사용자 지시: 추가 고품질화 계획 요청.
- 무번호 19~23 (5세트)까지 완성된 계층: 월드 물체(형태/질감/모션)·화면(비네트)·시간(패러독스 언어)·타이밍(시퀀서/예산).
- 이번 라운드의 대상 = 여전히 손대지 않은 4영역 — 실측 근거:
  1. **환경 무관성**: 날씨가 무엇이든 똑같은 먼지 — WeatherManager 존재 + `CurrentWeather` 쿼리 가능 + `OnWeatherChanged` 이벤트 실측(연동 가능 확인).
  2. **개성 부재**: 24종 몬스터가 전부 동일한 적색 링 — 몬스터별 색 데이터(`def.gizmoColor`) 존재 실측(AnimalAI.ApplyColor가 사용).
  3. **카메라 미반응**: 피격/임팩트에 카메라 트랜스폼 반응 부재 — FOV 펀치([95차 F3], 패링 전용) 선례만 존재. 타격감의 절반은 카메라가 만든다.
  4. **흔적이 팝으로 죽음**: 데칼 수명 종료 시 즉시 파괴 실측(DestroyDecal — 페이드아웃 부재).

## 중복 셀프감사 결과

- 카메라 셰이크 = 신규(FOV 펀치는 포인트 조작 — 셰이크는 트랜스폼 오프셋, 패턴만 재사용).
- 환경 반응 FX = 신규(WeatherManager는 날씨 자체만 구현 — FX 연동 0건).
- 몬스터 개성 틴트 = 신규(현재 고정 팔레트 — B3 위험도 색 계약과 병존 설계 필요).
- 데칼 페이드아웃 = 신규(즉시 파괴 실측).
- 비네트/시퀀서/예산 가드/수렴 링/스콜치/발자국 = 기존 구현 — 제외.

## Phase CA — 카메라 계층(최우선 — 타격감의 절반)

- **CA1 피격 카메라 마이크로 셰이크**: 피격 시 0.15s 소형 트랜스폼 셰이크 — [95차 F3] FOV 펀치 선례(코루틴+원복 보장) 패턴 재사용, 강도는 패링 FOV 펀치의 약 0.5배. 원복 보장 계약(OnDisable 포함 — 기존 RestoreParryCameraFov 선례 준용).
- **CA2 몬스터 임팩트 소형 킥**: 몬스터가 플레이어를 명중한 순간 동일 시스템 1회(강도는 CA1과 상한 공유 — 남발 방지). 판단 항목: 강도(기본 제안 0.5×).
- 주의: 패링 시퀀서/히트스톱과의 상호간섭 없음(다른 소유자 — 카메라 트랜스폼만).

## Phase DA — 환경 계층

- **DA1 강수 반응 먼지→물튀김**: `WeatherManager.CurrentWeather` 쿼리로 분기 — Rain/폭우: 이동 트레일 먼지(링+퍼프) → 청백색 물 스플래시(작은 링+상승 미스트, 색·수명 변주). Snow: 흰색 파우더. 기존 SpawnMoveTrailDust/Puff는 유지하고 **선택 분기**만 추가(구조 무변경).
- **DA2 날씨 전환 첫 히트 강조(판단 항목)**: OnWeatherChanged 직후 첫 트레일에서 전환 피드백 — 과할 수 있어 Play 판단 권장.

## Phase EA — 개성 계층(판단 항목 포함)

- **EA1 몬스터 개성 틴트**: 몬스터 공격 텔레그래프·임팩트 링 색을 몬스터 `gizmoColor` 기반으로 변주. ⚠️ **B3 위험도 색 계약(일반=적색·정예=주황)과 병존 설계 필요** — 제안: 위험도는 채도/형태로 유지(일반=저채도, 정예=고채도), 색조만 개성 반영(적색 톤 유지 범위 내 hue 시프트) — 완전 색 교체는 위험 가독성 훼손으로 비권장. Play 비교 후 확정.
- **EA2 몬스터 사망 FX 확인**: `def.deathEffectPrefab` 존재 — 배선 상태 확인 후 미배선이면 배선(확인 단계 — 이미 배선이면 제외).

## Phase FA — 흔적 생명력

- **FA1 데칼 페이드아웃**: 수명 말미 2s 알파 램프다운(DecalSpawner에 per-instance 머티리얼 알파 페이드 추가 — 현재 공유 머티리얼 즉시 파괴 → 마지막 2s 인스턴스 전환 후 페이드) — **팝 소멸 금지 선례(C3)의 데칼 확장**.
- **FA2 스콜치 텍스처 고도화**: 크랙 두께 변주(중심 두껍게→끝 가늘게)+블롯 비대칭(해시 기반 오프셋 — 결정론) — 기계적 대칭 소멸.

## 진행 방식

- 우선순위: **CA(카메라) → FA(흔적) → DA(환경) → EA(개성 — 판단 항목 포함)**.
- 각 Phase: 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 10건 1:1 → 실카메라 캡처 비전 판독 → 사용자 Play 판정.
- 결정론/Play·커밋 별도 승인/위조 배선 금지 유지.

## 솔직한 기술 노트

- 무번호 19~23까지의 개선은 "기초 도형 → 절차 고품질"이라는 명확한 격차를 메웠다. 본 라운드(24) 이후에는 **체감 이득이 점점 작아지는 구간**에 진입한다 — 가장 효율이 큰 다음 단계는 코드가 아니라 **Play에서 직접 보고 밸런스(강도/타이밍/색)를 잡는 것**이다. 본 계획은 그 전에 마지막으로 채울 수 있는 구조적 공백(카메라/환경/개성/흔적)만 정의했다.

## 판단 항목(사용자 선택 대기)

1. **CA2 몬스터 임팩트 킥 채택 + 강도**(기본 0.5×).
2. **EA1 몬스터 개성 색 방식** — 위험도 유지+hue 시프트(제안) / 완전 교체(비권장) / 미채택.
3. **DA2 전환 피드백** — 채택 여부.
