# 전투 VFX 고품질화 계획 — 몬스터 발견 + 이동 + 패링 (2026-11-10 기안)

## 0. 판독 근거 (코드 실측 — 2026-11-10)

- **발견 FX**: 몬스터 어그로 시스템(`AnimalAI.SetAggroTarget`, `MonsterAggroSystem.NotifyAttack`)은 `Idle → Alert(3초) → Combat` 전이만 처리. **Alert 상태에서 시각/청각 시그널이 전혀 없음** — 사용자가 "몬스터가 나를 발견했다"는 것을 체감할 수단 부재(모든 몬스터가 갑자기 공격하는 체감).
- **이동 FX**: 이동 명령 링은 CommandMarker 지속형(셰이더 기반, C2 청록)으로 존재하나, **이동 병사 자체의 이동 이펙트(트레일/먼지)와 도착 진행도 시각화 없음** — 이동 중인 병사가 링만 남기고 어떤 상태인지 체감 불가.
- **패링 FX**: Phase D(무번호 19) 재판정에서 화이트 프레임이 캡처 카메라 불일치로 미노출 확인됐고, D2 보강 후보(스파클 버스트/임팩트 스파크/반격 히트 플래시) 확정 대기 — 별섬광(Sprites/Default 수리)·금색 2겹 링·히트스톱은 정상.

## Phase E — 몬스터 발견 VFX(Alert 상태 시각/청각 시그널)

- **E1 발견 시각 시그널**: Alert 상태 진입 시 몬스터 머리 위에 **발견 인디케이터(적색 ! 링)** 표시 — AttackTelegraphIndicator.Spawn(부채꼴 게이지, 0.5s) 선례 재사용. 발견(0.5s)→Combat(3초 후) 전이 게이지.
- **E2 발견 SFX**: Alert 상태 진입 시 몬스터 발견 응시음(저음 웅성+짧은 경계음) 추가 — SFXType.Monster_Alert 신설 + Resources/Audio/SFX 절차 생성.
- **E3 발견 응시 애니메이션**: Alert 상태에서 몬스터가 대상 방향 응시+짧은 정지(0.5s) 동작 — AnimalAI.Alert 분기에서 애니메이션/회전 보강.

## Phase F — 이동 VFX(이동 트레일 + 도착 진행도)

- **F1 이동 트레일**: 이동 병사가 지면에 먼지/발자국 트레일(2~3s 잔광) — ShockwaveRingFX.SpawnDirectionalSpark(부채꼴 스파크) 선례 재사용, 이동 방향으로 잔광.
- **F2 이동 링 도착 진행도**: 지속형 이동 링(청록)이 **도착 진행도**를 시각화 — 병사가 목적지에 가까워지면 링이 축소(스케일) → 도착 시 확산 펄스 소멸(0.3s).
- **F3 이동 링 부착**: 이동 링이 목적지 지면에 부착(곡면 밀착) — B5 데칼 방식(곡면 밀착 실측 근거) 판정 후 확정.

## Phase G — 패링 VFX 보강(D2 후보 확정)

- **G1 화이트 프레임 수리**: SpawnParryScreenFlash 쿼드가 실카메라(원점 고정)가 아닌 **팔로우 카메라**에 부모 고정되도록 수리 — Phase D 프로브 캡처 카메라 불일치 근원 해결.
- **G2 스파클 버스트 강화**: 패링 성공 시 흡수점에서 **스파클 버스트**(0.5s, 8~12 방향) — SpawnDirectionalSpark(부채꼴 스파크) 선례 재사용, 8~12 방향.
- **G3 임팩트 방향 스파크**: 패링 성공 시 공격자 방향으로 **임팩트 스파크**(0.3s, 단일 방향) — 공격자 방향(반격 히트 플래시) 스파크.
- **G4 반격 히트 플래시**: 패링 성공 후 즉시 반격 히트(기존 공격) 시 **반격 히트 플래시**(0.2s, 금색) — AttackArcVFX.SetPremium(프리미엄 아크) 선례 재사용.

## 진행 방식

- 각 Phase: 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 1:1 → 실카메라 캡처 vision 판독 → 사용자 Play 판정(별도 승인)
- Play·커밋은 항상 별도 승인 게이트
- A3 계약 유지: 신규·수정 FX는 실게임 팔로우 카메라(Tag MainCamera) 또는 등가 복제 카메라 캡처로만 판정(진단 전용 카메라 금지)
- 위조 배선 금지 — 영상 재판독 후 확정
