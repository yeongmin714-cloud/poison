## P1 — 적색 텔레그래프 링 프리미엄화 (AttackTelegraphIndicator 재작성)
현재: 64px 절차 링 텍스처 + URP Unlit 투명 + 순수 적색(1, 0.15, 0.1)@0.45 + 알파 펄스만. "스티커" 느낌의 원인 4가지(저해상도/무발광/무채움/원색)를 전부 해소:
- **A 512² 이중 레이어 절차 텍스처**: ①외곽 경계 링(날카로운 AA 에지 + 밝은 에지 라인 — 16× 슈퍼샘플 후 다운샘플) ②내부 채움 디스크(저알파). 기존 64px 단일 링 폐기.
- **B 방사형 채움(fill) 진행**: 예고 0.5s 동안 중심→외곽으로 위험 영역이 차오르는 표준 텔레그래프(타이밍 가독성 = 고품질 체감의 핵심). 구현: 커스텀 URP 셰이더 신설(`Assets/Shaders/TelegraphRing.shader` — AcquisitionBeam.shader 157차 선례 계약: HLSL/HDR/폴백 경로) — `_Fill01` 파라미터로 원형 스윕.
- **C 발광 연동**: 에지 HDR 컬러 → 기존 블룸 체인 흡수(인테리어 포스트 선례) + 에지 밝기 맥동(기존 알파 펄스 대체).
- **D 타격 순간 임팩트**: 예고 종료 순간 링 화이트 플래시 1프레임 + 반경 1.15× 확산 소멸(159차 P4 명중 지면 링과 이중 노출 방지 — 기존 링과 역할 분담 명시).
- **E 팔레트 조화**: 순수 적색(1, 0.15, 0.1) → 경고 톤(주황-적, 예: 1.0, 0.30, 0.16) 옵션 — 주변 환경 톤과의 조화. 기본안 적용 후 사용자 판정.
- **F 계약 유지**: 수평 쿼드+지면 래프팅 0.06m/z-fight 방지/자가 파괴/폴백 경로(셰이더 부재 시 기존 Unlit 폴백 유지)/결정론(Random 0건).
- 적용 대상: AttackTelegraphIndicator(공용 — AnimalAI/AfterlifeEnemy 양쪽 자동 적용), 별도 시각 조정 불요.

## P3 — Time Paradox 에셋 활용 (쓸만한 폴더)

- **A 선감사(계획 단계)**: zip 해제 → unitypackage 내용물 전수 감사(147차 신규 에셋팩 glTF 전수 감사 선례 — 스크립트/셰이더/프리팹 구성, asmdef, 6000.5 의존성) → 충돌 가능성 목록화.

- **C 자체 시간계 공존 계약**: 기존 PlayerCombat 로컬 슬로우(0.10×)/HitStopManager(자가부트)는 **판정용 로컬 타임**, Time Paradox는 **연출용 글로벌 타임**으로 역할 분리. PERFECT 패링 시 양쪽이 동시에 timescale을 건드리지 않게 소유권 표 정의(누가 Set/Restore를 부르나).
- **D 적용 시나리오(제안)**: ①**PERFECT 패링 → 타임 정지 연출**(주변 몬스터·파티클 정지, 플레이어만 움직임 — 고품질 시그니처 모먼트) ②몬스터 특수기/대형 예고 → bullet-time ③적 사망 순간 → 0.3s 슬로우 ④화살 회피 순간 슬로우. 1차 범위는 ①만(패링과 직결 — 사용자 지시 정합).
- **E 임포트/통합 절차**: unitypackage 임포트(에디터) → 데모 씬 동작 확인 → API 감사 → **Test_10 한정 opt-in 통합**(PERFECT 패링 트리거에만 연결) → 별도 Play 승인. 임포트 자체가 에셋 대량 추가라 컴파일/테스트 회귀 가능성 있음 — P0~P2와 **분리 단계**로 실행(롤백 용이성).
