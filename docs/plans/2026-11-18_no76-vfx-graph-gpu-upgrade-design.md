# 설계도: 임팩트 파티클 GPU·고품질 승격 (무번호 76 설계 — VFX Graph 트랙 A/B 비교 + 권장 구현안)

**작성**: 2026-11-18. 상태 = **설계도(구현 미착지)** — 승인 후 착지. 74(행동 인터페이스)·75(본 플린치) 이후 원장.

---

## 1. 목표

공격·피격 임팩트의 "한 순간 밀도"를 상향 — 현재 CPU ParticleSystem 프리팹 + 라인 기반 파티클을 GPU급 파티클(수백 입자·커스텀 커브·텍스처 시트 애니메이션)로 승격. 강타격(≥15)/크리티컬 체감이 최대 목표.

## 2. 현황 실측 (이 설계의 근거)

- **VFX Graph 패키지 존재**: `com.unity.visualeffectgraph 17.4.0` (Packages/manifest.json L12 — 모듈 설치 완료, 활용 0)
- **기성 .vfx 에셋 보유**: `Assets/Resources/FX/Slash/StylizedSlashVFX.vfx` + `Assets/slash5-HungNguyen/slash 5 visual vfx profiles/` 변종 다수 — **slash5 슬래시는 이미 통합 배선 완료**(47차 — PlaySlashStage 콤보 아크). 즉 VFX Graph 런타임 통합·파라미터 바인딩 경로는 이 프로젝트에서 이미 검증됨
- **절차 텍스처 인프라**: FxFlipbookGenerator(37-S3 참격 플립북 6프레임 절차 생성) — 시트 애니메이션 소스를 코드로 만드는 선례 존재
- **CPU 파티클 현황**: 먼지(EnsurePuffTexture 4옥타브)·임팩트 스파크(SpawnDirectionalSpark 라인 3본)·물튀김(74) — 전부 소수 입자·라인 위주

## 3. 트랙 비교

### 트랙 A — VFX Graph(.vfx) 통합
- **장면**: 크리/강타격에 GPU 그래프 스파크 버스트(수백 입자, 텍스처 시트, 커스텀 커브). 런타임 배선은 `VisualEffect.SetVector/SetFloat` — slash5 선례로 기술 검증 완료
- **제약(정직 평가)**: .vfx 그래프 자체는 Unity 공식 런타임/스크립트 생성 API가 없다 — 그래프 편집은 에디터 작업. 이 프로젝트의 에이전트 파이프라인(코드+배치 QA)으로 **에셋 제작 단계는 자동화 불가**
- **실현 경로**: ①기성 에셋팩 추가 도입(폴리포크처럼 라이선스·퀄리티 전수 감사 → 147차 선례 절차) ②사용자가 에디터에서 제작(에이전트가 파라미터 스펙·그래프 구조 명세 제공) ③에이전트는 통합 코드(스폰·풀·예산·바인딩) 담당

### 트랙 B — 코드 전용 고품질 파티클 승격 (권장 선행)
- **장면**: CPU ParticleSystem이지만 품질 계층을 상향:
  1. **텍스처 시트 애니메이션 스파크** — FxFlipbookGenerator 선례로 절차 생성한 임팩트 스파크 시트(단계별: 점화→방사→소멸)를 파티클 시트애니로 재생 (현재: 라인 3본 → 확산 스파크 폭발)
  2. **충격 먼지 컬럼** — 강타격 지점에서 위로 솟는 절차 노이즈 먼지 기둥(EnsurePuffTexture 재사용, 커브: 가속 상승→감쇠 확산)
  3. **크리 전용 파장 잔광** — 기존 디스토션 웨이브(71-L2) 뒤 2차 저강도 리플
- **장점**: 에이전트 단독 착지 가능(에셋 무변경·코드만), 절차 텍스처 계약(결정론·사각 금지)과 완전 정합, 74/75 인프라 그대로 재사용
- **한계**: GPU의 성능 여유(수백→수천 입자)까지는 못 미침 — 다만 현재 프레임 예산에서 체감 밀도 목표는 CPU로 충분히 달성 가능한 범위

## 4. 권장: B 먼저(무번호 76), A는 병행 준비(무번호 77 후보)

- **76(트랙 B)**: 스파크 시트애니+먼지 컬럼+크리 리플 — 에이전트 단독 라운드(1회 컴파일+EditMode 게이트). 소요: 구현 1위임+QA 1런
- **77(트랙 A, 후보)**: 사용자가 원하는 방향 확정 후 — 기성 에셋팩 감사 도입 또는 에디터 제작 협업. 에이전트는 스폰 연동·예산 가드·계약 테스트 담당

## 5. 공통 계약 (트랙 무관)

- **MagicHit 룩 무변경**(38-F1R 사용자 재판정 계약) — GPU/고품질 레이어는 기존 위 **추가 레이어**만 허용

- **결정론**(Random 0건 — 절차 해시만)·**EditMode 무동작 가드**
- 대상 게이트: 크리/강타격(피해≥15 — 33-D1·37-H1과 동일 밴드 상수 공유)
