# 전투 VFX 미계층 고도화 계획 — 화면/공간/시간/타이밍 (무번호 23 계획서 후보 — 2026-11-12)

## 배경

- 사용자 지시: 누적 피드백 이후에도 만족스럽지 않다 — 패링·몬스터 공격·병사 이동 VFX를 **더** 고품질로.
- 무번호 19~22까지의 개선은 모두 **"월드 공간 물체(링/파티클/데칼)"의 형태·질감·모션**이었다. 이제 절차 FX로 만들 수 있는 물체 품질은 상당 수준에 도달했다.
- 다음 품질 점프는 물체가 아니라 **빠진 계층**에 있다 — AAA가 체감되는 이유:
  1. **화면 계층**: 히트/판정 순간 포스트 프로세스 반응(비네트/수차) — 전무
  2. **공간 계층**: FX가 지면과 **하드로 교차**(깊이 페이드 부재 — AAA 소프트 파티클의 부재)
  3. **시간 계층**: **ParadoxTimeStop(PERFECT 패링 시간 정지)이 존재하는데 시각 언어가 0건**(실측 — 시간이 멈춰도 화면은 그대로, 플레이어가 기능을 인지 불가) — 최대 기회
  4. **타이밍 계층**: 패링 7요소가 전부 동시 발화 — 설계된 타임라인(계층적 파열) 부재
- 실측 근거: ParadoxTimeStop.cs(6.3KB) 전수 — Visual/Overlay/Vignette/Color 계열 매치 0건. Footprint 발자국 데칼은 DecalSpawnerIntegration에서 이미 배선(제외). 포스트 인프라 존재(Systems/VolumeOverrides/PhaseG2_PostProcessingSetup.cs — 연동 검증 선행).

## 중복 셀프감사 결과

- 시간 정지 시각 언어 = 신규(ParadoxTimeStop에 시각 요소 0건 실측).
- 깊이 페이드 = 신규(모든 링이 하드 교차).
- 비네트/수차 = 신규(FOV 펀치는 카메라 트랜스폼 계열 — 포스트와 별개).
- FxSequencer = 신규(현재 동시 발화).
- FX 예산 가드 = 신규(스폰 무제한).
- FOV 펀치/슬로우모션/히트스톱/아우터 링/디플렉트 팬/위스프/순회 에너지 = 기존 — 제외.
- 22-P3 Unlit 전환 = 이월 항목(Play 비교 대기 유지).

## Phase U — 공간 계층: 링의 지면 통합

- **U1 깊이 페이드(소프트 교차)**: 링 밴드가 지형/장애물과 만나는 지점에서 알파가 소프트하게 소멸(AAA 소프트 파티클 방식) — 텔레그래프/충격파 링 셰이더에 `_CameraDepthTexture` 기반 페이드 추가. **선행 검증**: 프로젝트 DepthTexture 활성 여부 확인 — 미활성 시 (a)카메라 depth 모드 검토 또는 (b)URP FullScreenPassRendererFeature 대안(156차 FullScreenPass 선례 존재) 중 최소 침습안 확정.
- **U2 밴드 서브 디테일**: 링 밴드 내부에 얇은 2차 서브 밴드(밴드 텍스처에 추가 — 트리플 레이어 밴드) — 근거리에서 링이 "그려진 것"이 아니라 "에너지 구조"로 읽힘. 비용 0(텍스처 내부 수정).

## Phase V — 화면 계층: 판정 피드백 포스트

- **V1 피격 비네트 펄스**: 피해 입을 때 화면 가장자리 적색 비네트 0.25s 펄스(피해량 비례 강도 상한) — Volume 기반(PhaseG2_PostProcessingSetup 인프라 재사용 검증 선행 — 포스트 자체 신규 구축 금지).
- **V2 패링 PERFECT 골드 비네트**: PERFECT 순간 금색 가장자리 0.3s — 판정 피드백의 "화면 언어" 신설(월드 FX와 별개 — 카메라가 말해준다).
- **V3 크로매틱 수차 스파이크(판단 항목)**: 임팩트 순간 0.1s 수차 — 과자극 리스크로 Play 체감 판단 권장.

## Phase W — 시간 계층: 패러독스 시각 언어(최대 기회)

- **W1 정지 진입 연출**: PERFECT 패러독스 발동 0.15s — 화면 청록 역색/채도 시프트 진입 이징 — "시간이 멈췄다"를 화면이 말한다(현재는 시스템만 있고 신호 없음).
- **W2 정지 중 동결 프레임 확인**: 정지된 몬스터 주변 FX(텔레그래프 등)가 시간과 함께 동결하는지 확인 — ParadoxTimeStop이 LocalTimeScale만 제어하면 FX는 동결 안 됨 → 필요 시 게이트 확장 판단(무리한 구조 변경 금지 — 확인 후 보고).
- **W3 정지 해제 릴**: 진입 역색의 해제 이징(0.2s) — 진입/유지/해제 3박자 완성.
- **전제**: Test_10 opt-in 계약 존중(타 씬 무동작 — 기존 계약 유지).

## Phase X — 타이밍/예산 계층

- **X1 FxSequencer 마이크로 스태거**: 패링 임팩트 7요소를 설계 타임라인으로 분산 — t=0(코어/플래시)→+0.02s(지면 링)→+0.04s(디플렉트 팬)→+0.06s(위스프)→+0.08s(버스트) — 동시 폭발이 "계층적으로 파열"되는 리듬(PlayerCombat 코루틴 선례, 상수화).
- **X2 FX 예산 가드**: ShockwaveRingFX 정적 카운터 — 패밀리 동시 스폰 상한(초과 시 최오래된 것부터 자동 교체) — 몰림 상황(대규모 전투) 저사양 안전망.
- **X3 몬스터 스윙 아크**: 몬스터 임팩트에 곡선 아크 1호(위스프 몬스터 버전 — 적색/주황, WispRunner 파라미터 재사용) — 몬스터 공격에도 "스윙의 흐름".

## 진행 방식

- 우선순위: **W(시각 언어 0→1 — 최대 체감) → V → U → X**. 단, U1은 DepthTexture 검증 결과에 따라 방식 확정.
- 각 Phase: 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 10건 1:1 → 실카메라 캡처 비전 판독 → 사용자 Play 판정(별도 승인).
- 결정론/Play·커밋 별도 승인/위조 배선 금지 계약 전부 유지.
