# 전투 VFX 최종 고품질화 계획 — 공통 링 렌더 기반 + 이동/몬스터/패링 (무번호 21 계획서 후보 — 2026-11-12)

## 배경

- 사용자 지시: 병사 이동·몬스터 공격·패링 VFX를 **완전히 고품질로 더 다듬기** — "기초적인 도형이 아니라 젤다의 전설 같은 3D 고품질 RPG의 VFX".
- 무번호 20 완료 기준 잔존 "기초 도형" 실측:
  - **ShockwaveRingFX = Cylinder 프리미티브 + URP/Lit 단색 머티리얼** — 밴드 단면이 하드한 단색 튜브. 패링 지면 링 2겹/아우터/흡수점 확산링·몬스터 임팩트 링·이동 트레일 먼지·도착 퍼프·획득 링(158차 패턴)이 **전부 이 단일 경로**를 거친다 — 현재 가장 큰 품질 병목이자 최대 수혜 지점.
  - 트레일 = 링만 존재(공기 입자 없음) — 지면 스윕 한 레이어뿐.
  - 텔레그래프 = 확산(중심→외곽)만 존재, "에너지가 모이는" 수렴 연출 부재.
  - 전투 흔적(데칼) 부재 — 타격이 지면에 아무 흔적을 남기지 않음.
- 무번호 19/20에서 이미 구축된 고품질 자산(텔레그래프 셰이더 그라디언트/램프/셔머, 데칼 프로젝터 전역 활성, 절차 텍스처 생성기 3종 선례)을 **재사용 배선**으로 연결 — 중복 구현 금지.

## 중복 셀프감사 결과

- 수렴 링 = 신규(ShockwaveRingFX는 확산만 구현 — 수축 트윈 부재).
- 스콜치 데칼 = 신규(DecalSpawner는 BloodSplat/PoisonPuddle/Footprint 3타입).
- 먼지 파티클 = 신규(트레일은 지면 링만 — 공기 입자 레이어 부재).
- 방패 에미션 펄스 = 신규(방패 관련 FX 전무).
- 카메라 FOV 펀치/슬로우모션/아우터 링/디플렉트 팬/버스트 = 기존 구현 존재 — 재구현 항목에서 제외.
- 화이트 프레임 = 기존(Play 판정 대기 — 선구현 금지 유지).

## Phase R — 공통 링 렌더 고품질화(최우선 선행 — 전 전투 FX 동시 수혜)

- **R1 절차 밴드 텍스처**: 64×16 RGBA — v축(밴드 높이) 가우시안 글로우(중심 최밝→상하 소프트 페더 — 하드 실린더 단면 소멸) + u축 미세 노이즈 변조(유기적 에너지 요동 — 결정론 해시) + u=0/1 시임 랩 블렌드(이음새 없음).
- **R2 _BaseMap 할당**: URP/Lit 투명 머티리얼에 절차 텍스처 할당 — 최종색 = 텍스처 × 머티리얼 color 승수 구조 유지.
- **R3 색 계약 무손상**: 틴트는 기존 color 경로 그대로 — 패링 금(1,0.85,0.3)/청(0.65,0.9,1)·몬스터 적(1,0.25,0.2)·먼지 흙색·획득 등급색 전부 무변경(텍스처는 명도/알파 변조만).
- **R4 시그니처 전수 불변**: Spawn·SpawnMoveTrailDust·SpawnArrivalPuff·SpawnDirectionalSpark·SpawnParryDeflectFan·SpawnCritBurst 시그니처/호출처 무수정 — 내부 렌더 품질만 교체.
- 수혜: 패링(지면 2겹+아우터+확산링)·몬스터 임팩트 링·이동(트레일+도착 퍼프)·획득 링 — 한 번의 교체로 전 전투 링이 "빛나는 에너지 밴드"로 상승.

## Phase K — 병사 이동 VFX

- **K1 먼지 파티클 퍼프**: ParticleSystem 기반(CombatVFXController 절차 선례) — 소프트 서클 절차 텍스처 64×64(방사 펄스 감쇠 — **사각 금지 계약**, 156차 GetStarTexture 선례 준용), 트레일 지점당 5입자, 미세 상승+확산+0.6s 페이드.
- **K2 트레일 레이어드**: 지면 링(R 수혜) + K1 공기 입자 동시 발화 — 지면 스윕+부양 먼지 2레이어(0.6m 간격 게이팅 계약 유지 — 스폰 수 증가 없음, 입자는 링당 5개로 한정).
- **K3 이동 링 고정밀**: BuildTintedRingTexture 이중 톤 밴드(외곽 밝은 코어 에지 라인+내측 딥 톤)+AA 강화 — 데칼 링 정밀도 상향(세그먼트/중앙 필 유지).

## Phase L — 몬스터 공격 VFX

- **L1 수렴 링(에너지 수집)**: AttackTelegraphIndicator가 fill ≥ 0.75 시점 **1회 자체 발화** — 외곽→중심 수축 링(ShockwaveRingFX.SpawnConvergingRing 신설 — RingRunner 수축 모드: radius max→start easeIn, 알파 상승 후 컷). 남은 windup 시간 = 수축 시간 — "공격이 모인다" 젤다식 예고. 인디케이터가 스스로 발화하므로 몬스터 배선 추가 없음.
- **L2 스콜치 데칼(전투 흔적)**: DecalSpawner 4번째 타입 ScorchMark — 절차 텍스처(방사 크랙 라인+그을음 블롯, DarkBlend), randomRotation=true, lifetime 10s(풀링/maxDecals 50 선례). 배선: AnimalAI 명중 시 기존 임팩트 지점(P4 흡수점 지면) 1회 — **빈 스윙은 미배치**(판정 정직성).
- **L3 (R 수혜)**: 임팩트 링 품질 자동 상승 — 별도 작업 없음.
- **L4 피격 FOV 킥(판단 항목)**: 피격 시 소형 FOV 킥 — 패링 FOV 펀치([95차 F3]) 선례의 약 0.5배 강도. 빈도가 높은 이벤트라 과도 자극 리스크 — **Play 체감 기반 판단 권장**.

## Phase M — 패링 VFX

- **M1 방패 에미션 펄스(조건부)**: 패링 성공 0.3s 방패 금색 rim 발광. ⚠️ 선행 검토 필수: 방패 머티리얼 **인스턴스 분리**(공유 머티리얼 조작 금지 — 텍스처 원본 해상도/BC7 계약 무손상) 확인 후 구현 — 검토 실패 시 미채택.
- **M2 화이트 프레임**: Play 판정 결과 반영 — 체감 OK=유지 확정, 미체감=재설계 논의. 선구현 금지(무번호 19 구조적 결론 존중).
- **M3 (R 수혜)**: 지면 링 2겹/아우터(반대 위상)/흡수점 확산링 품질 자동 상승 — 별도 작업 없음.

## 진행 방식

- 우선순위: **R 선행(공통 수혜 극대화) → K/L 병렬 → M(조건부 검토 포함)**.
- 각 Phase: 구현+계약테스트 → 컴파일 error CS 0 + EditMode baseline 10건 1:1 → 실카메라 캡처 비전 판독 → 사용자 Play 판정(별도 승인).
- Play·커밋은 항상 별도 승인 게이트. 위조 배선 금지 — 참조/실측 근거 없는 신규 FX 불허.
- 결정론 계약: 신규 FX(수렴 링/파티클/데칼)에서 Random 사용 시 프로브 판정 경로와 겹치지 않도록 호출 지점 문서화(FanRunner 랜덤 0건 선례).

## 판단 항목(사용자 선택 대기)

1. **L4 피격 FOV 킥** — 채택 시 [95차 F3] 선례 ×0.5 강도로 구현 / 미채택 시 제외.
2. **M1 방패 에미션 펄스** — 머티리얼 인스턴스 계약 검토 통과 시 구현 / 리스크 있으면 제외.
